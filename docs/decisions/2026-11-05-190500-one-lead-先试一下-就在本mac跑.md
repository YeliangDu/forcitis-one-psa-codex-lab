## 落点

Trial (pilot) of delivering along the golden-sample mainline, one slice at a time. A slice is a run of consecutive mainline nodes; it is done when the backend scenario test is green for those nodes and a real role can complete each node in the UI of the client that role uses, against the real API, grants and data scope. The UI in a slice is usable, not polished; a later pass polishes it. Pilot slice S1: nodes HCM-LIFE-007, 009, 016, 022, 023 (cards #1478, #1479). Testing runs on the user's Mac in local containers, not in the dev environment. Pack expected values stay NOT_REVIEWED until the user reviews them per slice. After the pilot the user decides whether to adopt the approach.
