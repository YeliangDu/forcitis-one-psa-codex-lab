2. (a) Codex (`docs/rules/codex-preamble.md`) drafts the code, the failing unit test first, unit tests and migrations, once the data design is signed and acceptance tests are on main or released. (b) Codex drafts the acceptance tests from the card's done-when; one-test owns the contract: writes the prompt, checks each done-when line, adds edges, breaks the implementation to show red, runs the checks.
3. PR body: one line per run (the id Codex prints), plus the verbatim prompt, tokens, reasoning effort and each hand edit. (a) `Codex: <session-id>`. (b) `Codex-Acceptance: <session-id>` in one-test's acceptance PR or branch description, copied unchanged into the implementation PR that carries those commits. The two are judged apart.
4. Skips, nothing else, per key: `<key>: skip small` (under 20 lines added plus deleted in that part: `backend/src/main/**` for (a), the acceptance files of one-test commits for (b)), or `<key>: skip <reason>` with a lead comment `lead 准许跳过 Codex` posted after it.
