# 评审模板 4：生产变更（部署、云上资源、数据库账号与权限、运维命令）

通用做法、输出格式、七条通用盲区 B1–B7 见 [README.md](README.md)。本类评审只读材料，**不连生产、不执行任何命令**。

## 出题人填（只填这一栏）

- 产出：运行手册 / 剧本路径（`phase1a/infra/runbooks/…`）或变更清单、PR 号 / 提交、基线提交；若是已执行的变更，另给云助手任务号、回读输出文件的路径。
- 不填：「已在 dev 验证」之类结论。

## 必读材料（自己读）

1. 产出本身（剧本、命令、参数、回读与回滚步骤）。
2. `docs/ops/infra-runbook.md` 相关章节与 `runbooks/` 里相邻剧本的写法；`PREDEPLOY_CHECKLIST.md`（A–D 节）；`runbooks/prod-approvals.txt`；`docs/ops/resources.md`。
3. 授权依据：用户原话 intent 片段，或待决定收件箱里已答复的事项（用 ArtifactData 读回，不信转述）。–94（必须由用户决定的事）。
4. 涉及取证账号 / 外部库时：ADR-0037；涉及依赖、runner、CI 时：`SUPPLY_CHAIN.md`、`CI_RUNNERS.md`。
5. 相关 ADR 原文（B4）；`CLAUDE.md` 第 8、9 条（密钥、起容器与常驻环境先问）。

## 必查项

| # | 查什么 | 判过 | 判不过 |
|---|---|---|---|
| P1 | **授权可追溯** | 每个写操作、每个新建资源对应一条用户原话或收件箱答复；评审员读到了原文 | 授权是转述；范围比授权大 |
| P2 | **剧本要素齐全** | 前置检查、精确命令与参数、预期输出、回读命令、失败时怎么停、回滚、清理 | 缺回读、缺回滚、命令里有占位符未说明 |
| P3 | **幂等与失败关闭** | 重跑安全（已存在则不破坏）；任一步失败整体停止，不「继续看看」 | 重跑会重复创建或覆盖；失败后继续 |
| P4 | **不泄露凭据** | 命令、日志、回读输出、PR 里没有凭据值；会返回密钥的接口（如返回 SSL 私钥的 describe 类接口）不打印原始输出，只取非敏感字段 | 原样打印或落仓库 |
| P5 | **影响面与共享资源** | 写明会影响谁：共享的 RDS 实例上的其他系统、其他 runner、其他环境；对共享实例的参数改动写明回退命令 | 只考虑本系统 |
| P6 | **登记**（B7） | 新建 / 修改的持久资源已在 `RESOURCES.md` 登记一行，写明清理方法；取证读取已登记（`legacy-read/` 片段，见 README B7）| 做了没登记；登记里没有清理方法 |
| P7 | **门禁口径** | 涉及部署：`PREDEPLOY_CHECKLIST` D 节行数不少于门禁要求，C-9 与 C-15 状态**精确等于 ✅**，状态带多余文字不算完成（`scripts/release/deploy_gate.py`） | 把「进行中」写成 ✅；少行 |
| P8 | **版本与架构前提**（B2、B3） | 剧本写明目标环境的 OS / 架构 / 运行时版本，镜像与二进制架构与目标一致 | 默认为「和本机一样」 |
| P9 | **证据状态** | 已执行的变更：云助手任务号、回读输出、查询结果齐全，评审员读到了；读不到的标「未核实」 | 只有「已完成」三个字 |
| P10 | **常驻环境与容器先问**（CLAUDE.md 第 9 条） | 新增的常驻进程、容器、账号，有用户同意的记录；Testcontainers 临时容器按长期授权 | 未经同意起了常驻服务 |

## 本类特有的盲区（主动找）

- **B3 镜像架构**：SQL Server 等单架构镜像在目标环境能否运行（今晚 Colima 无 Rosetta 的教训）；回退判据写的是速率而不是累计量。
- **试验类变更先过兼容性预检**：镜像架构、依赖前提、回退判据、对其他 runner 的影响（见 `../../sessions/one-quality.md` 工作守则）。
- **B1**：对用户或运维可见的告警文字、提示用语是否符合 `terms.yaml`。
- **B6**：变更改变了状态（如部署状态、门禁状态），文档、`STATUS`、清单是否同步。
- **B5**：「已回读确认」的说法，评审员核对回读输出里的具体值。
- 时区：云上定时器、cron 写的是 UTC 还是本地，剧本里是否写明。

## 输出

按 README 的「通用输出格式」。生产变更类的「证据」必须逐条标 已核实 / 已抽查 / 未核实。字数不超过 450。
