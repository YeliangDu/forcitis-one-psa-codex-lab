# 法人归属规则卡（organization.workforce）

## RULE-385 已关闭的归属期间不改写，结束日写错用更正记录更正

依据：ADR-0026 §2.5；T1「只追加」；用户 2026-10-14「单独的更正记录表 (Recommended)」（intent/2026-10-14-194857）。

```
Given 部门或员工的一段法人归属期间已关闭
When  组织数据管理员发现结束日写错
Then  期间表中的原行不变
 And  追加一条更正记录：被更正的期间、新的结束日、原因、操作人
 And  发出 LegalEntityAttributionCorrected，审计记一条
 And  此后按日期解析法人时，以更正后的结束日为准
 And  已写入单据的法人不变；需改单据法人的，按冲销重做处理

Given 操作人不是组织数据管理员
When  提交更正
Then  拒绝并审计

Given 更正后的期间与同一对象的其他期间重叠
When  提交更正
Then  拒绝（422），不写任何记录
```

实现：只追加表（触发器拒绝改、删、清空），独立用例与权限；测试以 RULE-385 命名。
