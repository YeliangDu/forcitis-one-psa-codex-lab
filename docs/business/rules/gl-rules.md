## 一、期末自动转账

#### GL-001：自动转账模板的取数函数与方向标记
**Category:** Calculation
**Priority:** P1
**Source:** U8C 两套账 `gl_transferdetail` 全部模板（权责 `u8cloud_QZ` 5 个账簿 20 个模板；收付 `u8cloud` 47 个账簿 262 个模板）；`U8C_GL_PRACTICE.md` §4.1
**规则说明:** 每个模板行 = 方向（Y 借 / N 贷 / 空 = 由差额定方向）+ 科目 + 金额公式。`FS(科目,…,"借"/"贷")` 取本期该方向发生额；`QM(科目,…,"借"/"贷")` 取期末余额；`CE()` 取本凭证借贷差额，`CE(DOWN)` / `CE(UP)` 指定差额落在哪一方。科目后带 `*` 表示含全部下级，不带 `*` 只取该科目本身。
**Specification:**
  Given 模板行「N 6602 管理费用 FS("6602*",…,"借")」
  When 期末执行该模板
  Then 生成一行贷 6602（含全部下级明细），金额 = 6602 及下级本期借方发生额
  Given 模板行「空 4103 本年利润 CE()」
  Then 4103 行金额 = 其余各行借贷差额，方向由差额决定
**置信度:** High（函数名与参数位置在 262 个模板中一致；`CE(DOWN)` / `CE(UP)` 的方向含义按 U8C 惯例推定）
**疑点 / 需财务确认:** 无
**新系统建议:** 不迁移函数本身。新系统的期末结转写成按科目范围（含下级）取余额或发生额的规则，必须显式声明「是否含下级」，避免 GL-006 那类漏取。
