# 评审模板 5：决策页（给用户点选的在线页、待决定收件箱条目）

通用做法、输出格式、七条通用盲区 B1–B7 见 [README.md](README.md)。决策页的读者是业务用户，不是工程师；评审员要站在「一个不看代码的人，只凭这一页能不能做对决定」的角度判。

## 出题人填（只填这一栏）

- 产出：页面的 Artifact 链接（评审员用 Artifact 读回 HTML，用 ArtifactData 读回它的数据集合）或收件箱条目 id，页面所依据的材料路径（只给路径）。
- 不填：「选项已穷尽」「推荐理由充分」之类结论，也不写想让用户选哪个。

## 必读材料（自己读）

1. 页面本身：每个问题、每个选项、每处数字与日期、页面脚本如何保存与读回答案。
2. 页上每个选项所依据的原文：ADR、规则卡、规范条款、证据文件或查询结果。**事实性的话（口径、金额、影响条数、日期）逐个回到原文核。**
3.–94（必须由用户决定的事）与 METHODS M3「规则调整三类」。
4. 页面所属流程的约定：待决定收件箱的字段说明（`rules/decide/inbox/README.md`，若已合入）；词表小决策页的约定（METHODS.md 里 one-glossary 部分）。
5. `glossary/terms.yaml`（页面用语）。

## 必查项

| # | 查什么 | 判过 | 判不过 |
|---|---|---|---|
| D1 | **是否预选答案，且符合所属流程** | 先判页面属于哪个流程：待决定收件箱——**不预选**；词表小决策页（one-glossary 流程）——推荐项预选、用户点选。同一页不混用；说不清属于哪个流程的，不过 | 收件箱页预选了答案；约定不清 |
| D2 | **选项互斥、穷尽、含「暂缓 / 都不是」**，且每个选项写明选了之后会发生什么（谁做什么、改哪里）和不选的代价 | 读完每个选项，能说出后果；评审员想不出一个页面上没有、而用户合理会想选的选项（想得出就不过） | 选项重叠；只有一个可行选项却装成多选；后果没写 |
| D3 | **事实可核**（B5） | 页上每个数字、日期、条数、影响范围，评审员在原文里找到并一致 | 数字与原文不符，或找不到出处 |
| D4 | **不替用户决定** | 建议与事实分开写（词表流程里预选只代表推荐，选项文字本身不暗示答案）；反对意见和风险没被省略；没有用「默认」「一般」之类措辞暗示答案 | 建议写成了事实；省略了关键代价 |
| D5 | **一页一个决定，量可控** | 一次要答的问题数量合理，每个问题可以单独回答 | 把多个互相依赖的决定塞进一个选项 |
| D6 | **用语对业务人员友好且正确**（B1） | 用 `terms.yaml` 的正式用语；技术词配白话；不出现内部会话名、提交号当作选项文字 | 方言、缩写不解释 |
| D7 | **页面可用且答案可读回** | 手机宽度**实际打开**验证（评审员或出题人用手机宽度截图 / 读回内容，不凭推测）；页面声明的运行时 / 契约版本在目标设备上可用（B2：曾有页面在新版本下打不开或手机上只显示标题）；不引用外部字体或外链资源（用户 2026-10-16 决定「不要引用外部字体」）；答案自动保存；会话用 ArtifactData 能读回答案并带时间 | 需要导出文件；依赖外部资源；答案读不回 |
| D8 | **答复之后的落点写明** | 写明用户答复后由谁、在哪里落地（intent 片段、ADR、卡、配置），并且是约定的人 | 没人接 |
| D9 | **只经该流程的入口**（B7） | 属于收件箱流程的，要用户定的事进了待决定收件箱，不在各会话回复里重复附提醒；属于词表流程的，经 one-glossary 收集；页面没有同时走两个入口 | 同一件事多处发问 |
| D10 | **已对照现行决定页**（） | 题中引用了相关 intent 条目（`CURRENT_DECISIONS.md` 的条目标识，即 intent 文件名前缀）；与已定决定相悖的题已说明为何重问或列入「待用户裁定」 | 没对照就重问用户已答过的事 |

## 本类特有的盲区（主动找）

- **B3 / B2**：决策涉及技术前提（镜像、版本、环境）时，页上写的前提是否真的成立，评审员自己查。
- **B6**：页上描述的流程、状态名与实际流程（ADR、状态机）一致。
- **B4**：页上引用 ADR 条款的话，与 ADR 字面不同。
- 价格、期限、人数等数字的单位与口径（含税 / 不含税，月 / 年）。
- 选项里的「推荐」是否偷换了问题：用户被问的是 A 还是 B，页上论证的却是 C。

## 输出

按 README 的「通用输出格式」；每条问题给页面里的位置（问题序号 / 选项名）而不是文件行号。字数不超过 350。
