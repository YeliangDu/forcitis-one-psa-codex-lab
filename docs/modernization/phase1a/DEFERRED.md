# Phase 1a 推迟项与理由

日期：2026-10-14 · 会话：psa-1a-platform-bridge-reimagine

判断原则（用户 2026-10-14）：「能从一开始就做对的，就不要留在后续阶段，除非后续做更有价值」。下表中的每一项都写明了「后做更有价值」的理由。用户对「改为现在做」的清单选择了「同意，全部在 1a 做 (Recommended)」。

## 改在 1a 完成

G-1（字段缺失或无效时失败并告警）、G-2 会签（RULE-248/273）、RULE-302（同一实例重复审批人自动通过）、RULE-268/269/309（撤回、撤销、截止点）、RULE-285（转交）、RULE-300 剩余部分、H5（企业微信静默登录、待办、审批详情）、TIMESHEET 改用统一新格式编号。
