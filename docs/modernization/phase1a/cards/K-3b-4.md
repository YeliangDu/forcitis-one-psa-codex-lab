## 5. 契约变化（契约先行，CS-1.10：先改 OpenAPI 导出，再改实现）
1. **`GET /audit-entries`**：请求与响应形状不变（已是 `{items, nextCursor}`）。差异只有：校验失败的错误码由 `PLATFORM_AUDIT_QUERY_INVALID` 改为 `PLATFORM_WEB_REQUEST_INVALID`（400，`detail` 带原因）；`limit` 越界仍 400（来自 `PageRequest`，`PLATFORM_WEB_REQUEST_INVALID`）。无 `sort` 参数：顺序固定为 `created_at desc, id desc`，A-4 的 `sort` 白名单对本列表不适用（不提供即不需要白名单，见第 13 节裁定 1）。
2. **`GET /audit-entries:export`**：过滤参数补齐为与列表**同一组**：`actorId、onBehalfOfId、action、actionPrefix、sourceAddress、outcome、subjectKind、subjectId、from、to`（名称、类型、含义、描述文字一致）。**没有** `limit`、`cursor`（导出不分页）；传了按未知参数答 400。响应仍是 `text/csv` 附件，文件名与列不变。导出上限 = `forcitis.platform.audit.export.max-rows`，值 10,000（= `ListLimits.EXPORT_MAX`）。符合条件的条数大于上限时答 422 `PLATFORM_AUDIT_EXPORT_TOO_LARGE`，响应的 `detail` 为通用文案，不暴露条数（异常里的原文只进日志；总数需要 `count`，不再给出）。该错误码保留。
3. **`GET /own-login-records`**：响应由裸数组改为 `{items, nextCursor}`；参数 `limit`（默认 50，1..200，OpenAPI 已声明 `minimum/maximum/default`）加 `cursor`。`items` 元素 `occurredAt、action、outcome、sourceAddress、loginMethod` 不变，**仍不含**条目 id、`detail`、`actorId`、`subject*`。顺序：最新在前（`created_at desc, id desc`）。游标不透明、带版本、不签名（裁定要点第 1 条）；它只含排序键，数据范围（本人 + 四个登录类动作）仍在 SQL 里写死，伪造游标拿不到别人的行。不合格游标答 400 `PLATFORM_WEB_CURSOR_INVALID`；`userId` 等未登记参数答 400 `PLATFORM_WEB_REQUEST_INVALID`（既有）。
4. **错误码**：删除 `PLATFORM_AUDIT_QUERY_INVALID`；替代 = 复用 `PLATFORM_WEB_REQUEST_INVALID`（400）。不新增错误码，不新增 `PLATFORM_AUDIT_*`。`ErrorCode` 枚举随之少一项，前端生成物同步。
5. **列表与导出共用同一过滤参数对象**：应用层只有一个 `AuditSearch`（十个过滤字段，校验在构造器里）。Spring 的未知参数拦截器靠 `@RequestParam` 声明认参数名，因此两个控制器各自声明同样的十个 `@RequestParam`，再调同一个静态工厂 `AuditSearch.of(...)`（或同一个 web 层辅助方法）构造；**以验收测试守住两处声明一致**（K3B4-05），不靠人眼。
6. **导出 `limit maxRows+1` 语义**（TB-04）：`ExportAuditEntries.execute` 调 `entries.findLatest(filters, maxRows + 1)`；返回行数 `> maxRows` 即抛 `PLATFORM_AUDIT_EXPORT_TOO_LARGE`（事务回滚，不写 `audit-entry.exported` 条目，与现状一致）；否则按原样写导出审计条目（`rows=<实际行数> filter=…`）并出 CSV。恰为 `maxRows` 行成功，`maxRows+1` 行失败。全程**没有** `count` 语句。`AuditEntryQueries.count` 与 `JdbcAuditEntryQueries.count` 删除。
7. **删 `AuditQuery.MAX_LIMIT`**：`limit` 上限只来自 `ListLimits.MAX_LIMIT`，由 `PageRequest` 的构造器校验；`ListOwnLoginRecords` 不再自己校验。
