# 生产环境与专用演练环境：需求与成本评估（one-ops，2026-10-21，待用户定）

依据：ADR-0054 决定 4（投产准入 G-1：窗口 ≤48 小时、末次演练实测 ≤窗口 80%、至少两次含全部历史明细与真实敏感数据的全量模拟）、ADR-0055（自成体系，迁入为一次性受控通道）、INFRA_RUNBOOK D-1（生产「扩容现有实例共用」）、C-1、C-9。价格为 2026-10-21 阿里云询价接口（`DescribePrice`）的杭州公共价，**不含折扣与优惠、不含税**，仅供比较；购买一律待用户批准。

## 1. 现状（只读核实）

| 项 | 现状 |
|---|---|
| 应用服务器 | `ecs.g8i.xlarge`（4 核 16 GB，系统盘 100 GB、数据盘 200 GB，ESSD），包年包月，**2027-10-14 到期**；现在 dev 在这台机器上，没有生产应用 |
| 数据库 | RDS PostgreSQL 18 高可用 `pg.x4.large.2c`（4 核 16 GB，**存储只有 40 GB**，ESSD），包年包月，**2026-11-18 到期（距今约 4 周，须续费）**；与 IT 服务门户的库 `forcitis_one` 同实例，dev 库 `forcitis_one_dev` 也在上面；`max_connections` 1600 |
| C-1 扩容（8 核 32 GB、200 GB、自动扩容） | **未做**；生产库 `forcitis_one_prod` 与角色脚本（c9）已写好、未执行 |
| 演练环境 | 不存在 |

## 2. 生产环境需求

1. **应用服务器**：生产与 dev 不能共用一台机器（同一台上的 one.env、systemd 单元、发布拉取定时器、`/data/forcitis-one` 都是单实例设计，见 RELEASE.md）。需要独立的生产应用服务器，规格建议与现机相同（4 核 16 GB）起步。
2. **数据库**：按 D-1 扩容现有实例并另建 `forcitis_one_prod`（C-1 + C-9），或另买一台独立实例（见下方方案 P2）。生产数据库承载全历史迁入，存储 200 GB 是假设值，**需要迁入的数据量估算才能定**（现在没有该数据；NAS 合同不在库内）。
3. **配套**：SLS（已建，生产加独立 logstore 与告警）、OSS 归档桶 WORM 锁定（B-13，待做，7 年保留、**锁定不可逆**）、KMS（C-8）、证书与域名、公网带宽、备份保留（C-2 演练）、发布通道（OIDC 与部署角色按 prod 环境另建，R-4）。
4. **访问与隔离**：生产库角色与 dev 分离（c9 已按此生成）；生产的连接预算要重算（C-3/C-9 现为 46 + 46 + 门户）。

## 3. 专用演练环境需求（ADR-0054 G-1）

- 必须与生产**同规格**，否则「实测耗时 ≤ 窗口 80%」不成立；含全部历史明细与真实敏感数据，所以要与 dev 隔离：独立交换机或独立安全组、只放行运维与审计人员、不接企业微信与 U8C 的生产回调、用后清库或销毁。
- 数据来源是 ADR-0055 的一次性迁入通道（读 A8 与老系统库、归档文件）：演练环境的内网地址要加入那两个库的白名单，用完撤回；这是新增的外部访问面，须先批。
- 至少两次全量模拟，最后两次连续无返工；加上准备与彩排，按「每次 48 小时窗口 + 前后各约 2 天准备与核对」估计。

## 4. 方案与成本（月、人民币，包年包月公共价；按量为小时价）

| 项 | 规格 | 价格 |
|---|---|---|
| ECS 一台 | 4 核 16 GB + 系统盘 100 GB + 数据盘 200 GB（`ecs.g8i.xlarge`） | 约 802 /月；按量约 1.68 /小时 |
| ECS 一台（大一档备选） | 8 核 32 GB（`ecs.g8i.2xlarge`，同盘） | 约 1305 /月 |
| RDS PG 高可用，现状 | 4 核 16 GB、40 GB | 1456 /月 |
| RDS PG 高可用，C-1 目标 | 8 核 32 GB、200 GB | 3084 /月；按量约 6.44 /小时 |
| RDS PG 高可用 | 8 核 32 GB、500 GB | 3564 /月 |
| RDS PG 高可用 | 4 核 16 GB、200 GB | 1712 /月 |

**生产方案**
- **P1（D-1 原决定）**：扩容现有实例到 8 核 32 GB、200 GB，加一台生产 ECS。月增 ≈ （3084 − 1456）+ 802 ≈ **2430**。dev、门户、生产继续同实例，靠连接上限与超时隔离（ADR-0025 第 2 条）；风险：dev 批量测试与门户相互影响，规格变更有一次约 30 秒主备切换，门户短暂断连。
- **P2（独立实例）**：保留现实例给门户与 dev（不扩容，1456），另买生产 RDS 8 核 32 GB、200 GB（3084）和生产 ECS（802）。月增 ≈ **3886**。生产与门户、dev 完全隔离，门户不受规格变更影响；这与 D-1 已定「扩容共用」不同，须用户重新决定。

**演练方案**（均不含 SLS、带宽与备份的零头）
- **R1 按量演练（推荐）**：每次演练起一台 8 核 32 GB RDS（6.44/小时）加一台 ECS（1.68/小时）≈ 8.1 /小时；一次含准备共约 7 天（168 小时）≈ **1370**，两次全量加一次彩排约 **4100**，不演练的月份不花钱。用后释放，数据即销毁。
- **R2 常驻演练环境**：RDS 8 核 32 GB、200 GB（3084）加 ECS（802）≈ **3886 /月**，直到投产；准备期长（> 1 个月）时才划算；常驻意味着真实敏感数据长期留在一个环境里，安全评审要求更高。
- **R3 复用 P1 的扩容实例另建库当演练库**：成本最低，但真实敏感数据与生产同实例，演练的压力会影响门户，不满足「与生产同规格独立演练」的 G-1 意图，不推荐。

## 5. 要用户定的事（进收件箱）

1. 生产选 P1（维持 D-1）还是 P2（独立实例），以及何时执行 C-1（有一次主备切换，要与门户负责人约窗口）。
2. 演练选 R1 还是 R2；是否同意把演练环境的内网地址加入 A8 与老系统库白名单（一次性、用完撤回）。
3. **RDS 2026-11-18 到期，续费**：规格沿用 1456 /月还是在续费时一并升配（升配与 C-1 合并成一次变更更省事）。
4. 存储与规格依据：全历史迁入的数据量估算（谁出、何时出）。

## 6. 未核实与限制

- 价格为公共价，实际含合同折扣与优惠券的价格以控制台订单为准；按量价格以下单时为准。
- 迁入数据量、窗口耗时、并发都没有实测，规格是按「与生产同规格」假设；末次演练实测后可能要上调。
- 本评估没有创建或购买任何资源。
