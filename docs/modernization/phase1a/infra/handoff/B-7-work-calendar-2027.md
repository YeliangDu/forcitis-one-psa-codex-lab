# B-7 交接包：录入 2027 年工作日历（给组织数据管理员）

收件人：组织数据管理员（A-4）。时点：1a 上线前（D-1a-114）；以后每年 12 月 1 日前录入下一年（D-1a-115，11 月系统会提醒）。

## 为什么要做

审批时限按工作日计算（D-1a-110..113：T+1 工作日 23:59 截止、次一工作日 09:00 提醒、再次一工作日升级）。某一年的日历没有录入，依赖它的计算会失败并告警（`forcitis.organization.attendance.calendar.unmaintained`），不会按自然日糊过去。2016–2026 年由 C-6 从老系统迁入；2027 年老系统没有，须人工录入。

## 录入什么

FORCITIS one 默认周一至周五上班、周六周日休息，只录「例外日」：

| 类型 | 含义 | 规则 |
|---|---|---|
| `HOLIDAY` 节假日 | 周一至周五中放假的日子 | 按国务院办公厅发布的 2027 年部分节假日安排 |
| `MAKE_UP_WORKDAY` 调休上班日 | 周六、周日中要上班的日子 | 必须是周六或周日，否则系统拒绝 |

公司若有额外的放假或调休（例如年会日），一并按上表录入，并在备注中说明依据。

## 步骤

1. 等国务院办公厅发布 2027 年节假日安排（往年一般在 11 月前后），按其逐日列出例外日。
2. 由第二人（业务管理员）对照官方通知复核清单。
3. 录入：
   - 若 PC 管理端已有「工作日历」页面，在页面中按年录入并保存。
   - 页面上线前，由运维代为调用接口（使用组织数据管理员的会话，操作记入其名下审计）：
     `PUT /api/v1/organization/work-calendars/2027`，权限 `organization.attendance:work-calendar:update`，请求体：
     ```json
     { "days": [
         { "calendarDate": "2027-MM-DD", "dayKind": "HOLIDAY" },
         { "calendarDate": "2027-MM-DD", "dayKind": "MAKE_UP_WORKDAY" }
     ] }
     ```
     日期按官方通知填写；同一年整份替换，重复提交以最后一次为准。
4. 校验：`GET /api/v1/organization/work-calendars/2027` 返回的例外日与复核清单逐条一致。

## 验收标准

- 2027 年已维护（GET 返回 200，例外日条数与清单一致），审计中有录入人与时间。
- dev 上用一条跨春节的审批任务验证截止时刻顺延到节后第一个工作日。

## 回滚

录错时重新 PUT 整年正确清单即可（每次保存都有审计）。
