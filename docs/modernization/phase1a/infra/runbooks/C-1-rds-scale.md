# C-1 剧本：RDS 扩容到 8 核 32 GB、ESSD 200 GB，开启存储自动扩容

依据：ADR-0025 第 2 条（扩容规格建议）、用户「扩容现有实例共用」。时点：dev 前。性质：**购买操作**，执行前须用户在会话中明确确认规格与费用（费用以控制台为准，本文不写金额）。

## 执行前确认点

1. 用户已确认：目标规格（8 核 32 GB 通用型或独享型，以控制台可选规格为准）、ESSD 等级（PL1 建议）、存储 200 GB、自动扩容上限。
2. 与 IT 服务门户负责人约好变更窗口：规格变更可能有一次 30 秒级的主备切换，门户（`forcitis_one` 库）会短暂断连。
3. 确认实例当前状态「运行中」，近 24 小时无进行中的备份或变更任务。
4. 记录变更前基线（截图或导出）：规格、存储、`max_connections`、CPU / IOPS / 连接数近 7 天曲线。

## 步骤（RDS 控制台，实例 pgm-bp13vak0sew3m003）

1. 「基本信息」→「变更配置」：选目标规格与存储 200 GB；生效时间选「可维护时间内」（或用户指定的窗口）。提交订单。
2. 「存储空间」→「自动扩容」：开启；触发阈值 可用空间 < 20 %；上限 500 GB（建议，由用户确认）。
3. 「参数设置」：变更后核对 `max_connections` 新值，写入 C-3 连接预算（`c3_dev_db_verify.sql` V7）。

## 校验

- 控制台规格、存储与订单一致；自动扩容开关为开。
- 门户在窗口后可用（请门户负责人确认）。
- `SHOW max_connections;` 返回值已记录；`SELECT version();` 仍为 PG 18。

## 回滚

规格变更可再次「变更配置」降回原规格（存储空间只能扩不能缩）。若切换后门户异常，先在控制台看「主备切换日志」，再联系阿里云工单。
