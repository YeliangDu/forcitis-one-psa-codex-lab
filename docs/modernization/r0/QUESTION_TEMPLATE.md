# 经营问题清单模板（Q12 / B4）

- 用户决定（BI_SCOPE §6.1 Q12）：「需要，R0 列清单 (Recommended)」——按管理层级起草问题模板，由业务 Admin 补充删改，作为 R0 的输入、R6 的验收清单。
- 填写位置：仓库外 `~/.modernize/psa/bi-inputs/questions/questions.md`（已放好同结构的待填文件）。问题里可能有客户、项目名称，所以不进仓库。会话只把归类后的结构（问题类型、所需指标、所需事实）整理进仓库。
- 预填内容：下面每个层级预填了若干问题。来源是六份在用报表正在回答的问题（`REPORT_INVENTORY.md`）和它们答不好的地方（K1–K20、E15–E22）。请删掉不需要的、改写不准确的、补上没想到的。

## 怎么填

每行一个问题。能写的列尽量写，写不了的留空：

| 列 | 写什么 |
|---|---|
| 问题 | 用经营会上的原话写，例如「华东今年哪些项目亏钱，亏在哪」 |
| 谁问 | 层级或岗位 |
| 多久问一次 | 周 / 月 / 季 / 年 / 临时 |
| 看完做什么决定 | 例如调人、催款、调整目标、发激励 |
| 现在怎么答 | 哪张报表、哪个人手工算，或者答不了 |
| 为什么答不了 | 没数 / 数对不上 / 太慢 / 口径说不清 / 其他 |
| 重要程度 | 高 / 中 / 低 |

会话据此为每个问题标注：所需指标（`METRIC_BASELINE_DRAFT.md` 的 M 编号，没有的新增）、所需事实与 BC、报表包（P1–P8）、在哪个阶段能答（R1–R6）。
