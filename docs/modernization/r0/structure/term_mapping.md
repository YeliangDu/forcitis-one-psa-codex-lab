# 四份在用报表：指标名与维度名 对照正式用语 / OAT（term_mapping）

范围：经营分析 PPTX（含文件 A「月度经营分析」与文件 B「交付中心季度汇报」）、损益表汇报表、现金流量表与应收账款分析底表、运营看板。依据：terms_compact.tsv（348 条）、oat_compact.tsv（245 条）、已定用户决定。所有输入已脱敏，本文不含金额、数值、人名、客户名、项目名。

## 0. 使用说明

- 位置简称：A=PPTX 文件 A（页码 p）；B=PPTX 文件 B（页码 p）；PL=损益表汇报表（表名）；CF=现金流量表；AR=应收账款分析底表；OPS=运营看板（表名）。
- 判定：A=已是正式用语；B=方言，词表已登记为 dialect 别名，映射到正式用语；C=叫法或公司叫法，可能对应已有词条，需确认；D=新概念，词表无对应。
- 严格执行判定规则：只有与词表正式用语或已登记 dialect 别名字面完全一致才判 A/B。凡字面一致但指标义与词条实体义不同（例如「合同」作金额指标），判 C 并在备注说明。
- 「毛利」「毛利率」用户已裁定为方言并统一映射 CM/CMR，但词表尚未登记该 dialect 别名，故本文判 C，并在待确认清单中建议登记。
- 一行是一个概念簇，同簇多种叫法用「/」并列；统计按「条目（行）」计，见第 4 节。
- 含税性：报表中凡未标注含税与否的收入类金额，在备注写「未标注」。收入类一律不含税；含税另列且名称带「含税」。
- 两个账簿：收付账簿（法定）与权责账簿。备注中「权责」「收付」指该指标天然所属账簿。

## 3. 同名不同义 / 同义不同名 线索

编号 S-xx。

- S-01 毛利：同叫「毛利」，公式至少六种。交付毛利=产值−交付成本；区域总毛利（含支持）=交付毛利−客户到合同相关费用；产值毛利=产值不含税−区域成本；回款毛利=回款−成本（收付口径）；BU毛利、项目毛利润、战区毛利润按核算层级逐级；FST 月度表「毛利」行各月公式不一致（有的取人工费用差，有的取收入−成本）。A p29 的「利润率」推断=毛利/产值，与税前利润率不同。统一映射 CM/CMR 时必须带层级和账簿（权责 vs 收付）。
- S-02 主营业务收入：FST 月度表取序时账贷方（法定，收付侧），汇总版取产值不含税（经营口径），同名不同账簿。
- S-03 税前利润：A p11、PL 财务状况=交付毛利−客户到合同费用−研发−总部；PL 公司层级=BU 毛利−业务组−方案中心−结构造价−总部平台；FST=主营业务收入−成本费用合计；汇报-分摊为「税前净利润」；A p48 的「税前净利润」与 p11 可能不一致。
- S-04 产工比：分子有产值、开票、回款三种（同名「产工比」多指回款产工比）；分母有薪酬费用累计使用（A p20）、人工费用（PL）、人力成本费用（OPS 手工）；PL 汇总版人工费=人工费用−奖金；OPS 回款产工比用回款÷人力成本，且回款的范围含预收、工抵标志的回款单。「目标产工比」「应释放薪酬」随之变。
- S-05 人均 / 流入流出：人均除数有平均人数（月数再除）、当前在职、预算人数、交付端平均人数四种；A p36 注明纯区域不含总部与技术人员；OPS 年化公式写死「8 个月推 12 个月」与月份参数不一致。现金流入流出的「流入/流出」：CF 控股汇总不含筹资，月报部门列含筹资而合计列不含，A p12 合计口径为 BU+销售、支持、总部。
- S-06 完成率：预算完成率（实际/预算）、承诺完成率、挑战完成率、理论完成率（时间进度）、清单完成率、预测完成率、达标率分母各异；OPS 列标题常只写「完成率」；A 色标阈值（预算完成率<80% 红等）与 B 色标阈值（相对时间进度 75%/65%）不同；「预实比」=(实际−预算)/预算，与完成率差 1。
- S-07 回款 / 收款 / 现金流入混用：PL「回款收入」（手工台账，含现金/保理/商票/工抵）；CF「销售商品、提供劳务收到的现金」（收付账簿，含个独账户流水）；OPS「回款」（回款单金额，含预收/工抵标志）；A p12「流入」（经营+投资）。工抵、保理发票核销不是现金流入，应属于权责侧抵销，需与收付账簿拆开。
- S-08 内审完成率：A p44=内审项目数/交付项目数；B p28=已审核/已交付并另有「存量风险（往期待审核未发流程）」；内审覆盖率（A p51）与完成率是否同义待定。
- S-09 逾期 / 超期 / 账龄：A、AR 的「超期应收」=账龄>90 天（按开票日起算）；AR 表头写「超期+坏账准备」但公式未加坏账准备；PL Sheet1 的超期总计不含 45–90 天档；商票「已逾期」按票据到期日；B「已超期/承诺超期」指承诺开票日已过。按用户决定，前两者应改称「账龄超 N 天」，只有到期日口径才叫「逾期」。账龄分段六段与九段并存。
- S-10 未开票：B 的「本年度未开票」（按产值日期的年内产值）与「全量已确认未开票」（合同资产，多年累积）口径不同、不可相加；A 无此指标；词表中 unbilled_wip 与 contract_asset 是否同义，OAT WIP 合并为「UnbilledWipOrContractAsset」。
- S-11 新签：合同表按赢单日期年度，产值表按合同日期年度；「新签合同开票」公式实为全年开票，「新签合同回款」恒为 0；「合同转化率」分母是立项而非商机，名实不符。
- S-12 立项 vs 合同：「立项」金额（项目金额）与「合同」金额（合同日期）不同日期口径；立项早于合同时合同表项目编号为空。
- S-13 承诺五义：月度承诺目标；承诺开票池；商机预测类型「承诺」；开票表预计回款状态「首次承诺/滚动承诺」；库存商机等级「承诺」。与词表「承诺差异」（合同承诺比对）无关。
- S-14 库存 / 存量 / backlog：库存商机（未关闭商机）、存量资产（合同资产）、待签合约存量、年初/年底 backlog（剩余履约义务）。
- S-15 成本 / 费用 / 费用支付：PL「成本」实为各类权责费用合计（含人工）；CF 同名科目（办公费、差旅费、委外费、项目佣金等）是支付发生额；居间费 PL 按比例预提，CF 为实付。按用户决定分「费用（权责，按发生期间）」与「费用支付（按支付日）」两个指标。
- S-16 DSO：365 / 360 / 90 天与实际天数混用；2026 当年 DSO 基准日写 2025-01-01；客户 DSO 为近 12 个月滚动；销售额取开票而非收入；A p40 将 DSO 作为客户分类依据，需绑定同一算法。
- S-17 区域 / BU / 事业部：同一单元多叫法（海外客户部/海外事业部；03/04 技术研发中心；H1-/H2- 前缀）；AR 侧（客户服务中心）与 FR 侧（项目交付中心）同属一个区域；PL 雷蒙沃等法人下的 BU 与区域并列。
- S-18 客户键：AR「客户名称」「客户DSO 客户名称」实为客户集团；台账「客户大类」同为客户集团；A「客户分类」是 A/B/C 等级，B「客户分类」同；A「客户类型」是行业类别。
- S-19 含税：PL 明确含税/不含税（1.06 硬编码互转）；A 仅 p11 标不含税；B、OPS、CF、AR 均未标注；AR 发票金额默认含税；CF 支出为价税合计实付，税额拆为进项税额行。
- S-20 计提 vs 减值计划：B p23 自述两套口径未统一；A「坏账准备」又是第三个名字。
- S-21 EB 比分母：订单（销售合同，A p11、PL）与合同（A p41）。
- S-22 DPE/ODC/OH（预算成本分类）与词表 direct_labor/direct_expense/indirect_cost_pool 是否一一对应待确认。
- S-23 产值 vs OAT OUTPUT：词表把「产值」定为收入确认的方言，OAT 的 OUTPUT「产出价值」是另一概念（词表 forbidden 中含 OutputValue），不要映射错。
- S-24 工时分类：收费/非收费/商机工时 与 词表的 可计费/有效/无效/返工 工时 不是同一划分；工时有效率 OPS 公式含商机工时，与 OAT HVR 可能不同。
- S-25 现金转化：词表 cash_conversion 与 OAT CCR（现金转化率）在四份报表中均未出现，勿将「回款/开票」直接定名为现金转化。
