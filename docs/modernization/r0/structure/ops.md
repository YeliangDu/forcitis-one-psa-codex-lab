## 2. 看板表逐表说明

### 2.1 交付-完成趋势
- 用途：「2026 年度」全年指标看板。五项指标（立项 / 合同 / 产值 / 开票 / 回款）按交付区域给出「年度预算目标 / 累计结果 / 预算完成率」，叠加 Q4 季度冲刺预测、全年预测与偏差，再展开到各区域月度完成趋势与季度汇总。
- 期间粒度：年累计；月度（1 至 12 月）；季度（Q1 至 Q4）。当前月份由 P2 参数提供（右邻 Q2 标注「月」）。
- 维度：执行部门（弗思特运营中心合计 + 8 个区域 / 中心 + 技术研发中心）；月份；季度；业务（立项 / 合同 / 产值 / 开票 / 回款）。
- 列标题 / 行项目（原文）：
  - 顶部（行 3 至 4）：执行部门 / 立项 / 合同 / 产值 / 开票 / 回款 / Q4季度冲刺预测 / 全年预测 / 预测偏差 / 产值架构 / 合计；子列：年度预算目标 / 累计结果 / 预算完成率；指标 / 立项 / 合同 / 产值 / 开票 / 回款；新签合同 / 合同转化率 / 新签合同产值 / 新签合同开票 / 新签合同回款；剩余合同额产值 / 本年度新签合同产值（按月对）。
  - 第二块（行 16 至 17）：理论完成率 / 黄色（区间，已脱敏）/ 红色（低于阈值，已脱敏）/ 偏差。
  - Q4 冲刺目标块（行 17 至 27，列 R 至 X）：Q4目标 / 立项 / 合同 / 产值 / 开票 / 回款 及各区域行（表头外部分为手输常量）。
  - 五个月度明细块（立项、合同、产值、开票、回款各一块，每块每区域四行）：行标题 执行部门 / 类型 / 累计值 / 1 至 12（月）/ 趋势 / Q1 至 Q4；类型行：年度预算（a） / 理论目标（o） / 实际结果（b） / 完成率 （b/a）。
- 口径说明文字（原文）：「黄色（区间）」「红色（低于阈值）」两段为条件格式图例（具体百分比已脱敏）；「理论完成率」= 按月线性分摊；无其他说明段落。
- 公式逻辑：
  - 年度预算目标 = SUMIFS(年度预算-2026年!金额列，指标类型列 = 对应「立项金额 / 合同金额 / 客户产值 / 开票金额 / 回款金额」，区域列 = 本行区域) ÷万；月度块额外加月份列条件。键：区域 + 指标类型 +（月份）。
  - 累计结果：
    - 立项 = SUMIFS(立项!项目金额，立项!区域，区域) ÷万。
    - 合同 = SUMIFS(合同!合同金额，合同!区域，区域) ÷万。
    - 产值 = SUMIFS(产值!产值金额，产值!区域，区域) ÷万。
    - 开票 = SUMIFS(开票!本次开票金额，开票!区域，区域) ÷万。
    - 回款 = SUMIFS(回款!回款金额，回款!区域，区域) ÷万。
  - 预算完成率 = 累计结果 ÷ 年度预算目标（IFERROR，错误显示「na」）。
  - 理论完成率 = 全年按月线性：当前月份 ÷ 全年月数（12），写在 F16；黄线、红线按「理论完成率 × 阈值系数」得到（硬编码系数）。

### 2.4 激励报销
- 用途：激励台账：按执行区域汇总各季度「客户端」（销售侧）与「交付端」激励的应发总额、已支付、余额。

  - Q2 交付端「支付情况」含一个手工补充常量（相加项之一）。
