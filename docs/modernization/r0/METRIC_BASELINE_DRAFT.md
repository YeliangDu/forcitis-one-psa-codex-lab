## 1. 重新梳理的原则

1. **一个指标只有一个定义**：定义放在 `operations.policy` 的口径版本中，报表、导出、AI 都只经语义层取数，报表不自带算法。这是 E1–E4、K1–K12 的根本原因。
2. **按事实归位**：每个指标写明来自哪个 BC 的事实。目标、预算、承诺、预测都是 `operations.planning` / `operations.budgeting` 的版本化事实，不再是手工表格。
3. **账簿与口径显式**：
   - 收入类指标以不含税为准，含税另列且名称带「含税」（Q6-1）。
   - 利润类声明账簿（权责 / 收付）与层级（Q6-2、ADR-0022）。
   - 法定报表数由 `accounting.reporting` 提供，语义层只引用，不重算（BI_SCOPE §3.4）。
4. **比率写明分母**：凡「完成率」「占比」「产工比」「人均」，名称或定义中都写出分母，例如「目标达成率（承诺）」「人工成本产出倍数（回款）」。
5. **参数不写死**：税率、日标准工时、账龄分段、分摊费率、激励门槛、色标阈值都是配置类参数，按 版本化，不追溯。
