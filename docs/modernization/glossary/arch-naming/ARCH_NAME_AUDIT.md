## 方言或同名异义（需用户答复）

1. **考勤**：词表「考勤与休假」把「考勤」列为方言（organization.attendance）；架构名「考勤记录」「月度考勤确认」「导入考勤记录并补卡」「生成、确认并锁定月度考勤」「阶段 考勤确认」同 bc 内在用，须定改名或词表放宽。
2. **红冲 / 冲销**：词表「冲销」别名红冲（operations.facts）；架构名「红冲销项发票」「发票红冲后冲减应收」在用。发票侧红冲（receivables）是税务用语，建议按 bc 分立，待定。
3. **销售合同**：词表「合同」把销售合同列为方言；「销售合同归档」。
4. **签证**：词表「现场签证」；「提出并生效协议变更或签证」。
5. **产值**：词表归「收入确认」；「填报经营产值」已有用语问题（与 progress_assessment 冲突）。
6. **调休 / 补休**：词表「调休」现指调休上班日（organization.attendance），请假 B-27 的「加班后安排休息」用「补休」（劳动法第 44 条）；补休已提议，同名异义已登记。
7. **结算 / 收尾**：词表「收尾」以「结算」为别名（项目阶段 7），而「供方结算」「协议结算」「月度薪酬结算」是另一义；「结算」一词跨 bc 多义，建议只在 bc 内用，阶段 7 统一「收尾」。待定。

以下是子串命中但属不同 bc 的同形词，不判方言，仅提示：授权（风险交付授权、控制科目授权表版本，对「授予权限」platform.identity）、规则版本（薪酬规则版本、假期规则版本、分摊规则版本，对「编号规则版本」）、停用、决定、行（报表行定义、分摊运行）、已完成。

## 阶段与价值流名的词表缺口
