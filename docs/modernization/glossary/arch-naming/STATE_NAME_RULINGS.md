# 状态名定名（one-glossary，2026-10-21，NAM-1021-GLO-14）

状态名用「已××」写法（流程方法稿 §11），状态名属各自对象，跨对象同名不冲突；以下是几个业务组写法不一的状态，按词表规则直接定。

| 状态 | 定名 | 旧写法 | 依据 |
|---|---|---|---|
| 新版本取代后旧版本的状态 | 已被取代 | 已停用（被新版本取代）、已取代 | 词表已有被取代的用法（合同基线版本「转被取代态」）；同一件事一个名；「已停用」在词表里指停用，不是被取代 |
| 协议、报价、交付计划版本的草稿状态 | 草拟 | 草案 | 报价、交付计划版本已在用「草拟」；「合同草案」是文件名，与状态名分开 |
| 法定申报状态链 | 待申报 → 已申报 → 已缴款，另有更正申报 | 已生成、已提交 | 企业信息图 OBJ-92；已登记 statutory_filing 系列（proposed） |
| 协议签署后 | 已签署、已生效是否分开 | 已签署生效 / 已生效 | 交用户定（GL5-01），民法典第五百零二条 |
