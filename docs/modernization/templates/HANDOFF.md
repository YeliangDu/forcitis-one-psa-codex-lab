# 交接模板

用途：会话在批次边界交接时，写给接手会话的报告。放在 `docs/modernization/handoffs/HANDOFF_<原会话>_<日期>.md`（旧位置的交接文件不迁移，也不再新增）。头部四行由 `build_sessions.py` 检查；不写上下文百分比，只写触发原因（读到旧数字的人无法判断它还对不对）。接手会话开场第一步：用 gh / git 核对“在途”，再把状态改为“已接手”。

## 模板

头部四行的值：写于 = 本机本地时间；状态 = 有效 或 已接手（二选一，写别的或加注释都会被检查拒绝）；基线提交 = 7–40 位十六进制；触发原因 = 一句话。

```markdown
# 交接报告：<原会话> → <接手会话>

- 写于：YYYY-MM-DD HH:MM
- 基线提交：<git 提交号，7–40 位>
- 状态：有效
- 触发原因：<批次边界 / 压缩两次 / 超过约 8 小时 / 用户指示>

## 1. 先读
## 2. 在途（PR、分支、worktree、后台任务；接手方以 gh / git 为准核对）
## 3. 已定与待定（用户已决定的事、待用户的事）
## 4. 下一步命令
## 5. 不要做的事
```
