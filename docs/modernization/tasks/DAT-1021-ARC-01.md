依据：ADR-0073 第 3 条第 4 款（#508 @768c9573）；用户 PR #508 评论 6317197354 第 2 项（intent `2026-10-21-155934`）。

要判别：老系统 24 个月跨法人调动为 0 的成因是 (a) 业务上从不跨法人调动、(b) 老系统流程不支持、还是 (c) 跨法人以「离职＋入职」处理。

取证：
1. 同一人（按身份证件号或工号对照）是否先后出现在两家公司代码下：员工主档与公司代码历史、A8 人员变动记录（ODS_MEMBER_CHANGE）；
2. 若有，按月给出条数，以及离职与入职的间隔天数分布（0 天、1–7 天、更长）；
3. 只出计数与分布，不出明细与个人信息；按 ADR-0037 登记取证一行。

交付：结论（a / b / c）与依据一段，回 one-architecture，抄 one-coordinator。判为 (c) 时 one-architecture 另立 ADR-0073 补篇。
