# GOV-1023-MRG-12 统一切分支与清理

开工条件：GOV-1023-COO-01 清单中所有在开整改 PR 合入（含 QUA-06 #659）。完成后才做最终验收。

## 目标

各工作区落后 main 34～553 个提交，`.claude/settings.json` 每工作区一份，旧分支残留已删画像与旧规则，是冲突与钩子不一致的来源。
做法：①one-merge 出逐会话清单：分支、落后数、`origin/main..分支` 未合入提交（区分已被合集收走的 docs 提交）；②各会话写交接、确认无未合入改动后，在自己工作区 `git switch -c claude/<会话名>-<主题> origin/main` 并重启会话，回报新分支与 HEAD；③旧分支：已合入的删除远端分支，未合入但须保留的改名 `archive/<原名>`，逐条记清单；④无主工作区（如 advrev-copy、nx5-kerr2、xin-589、codex-qua*、qua01-merge 等）列清单，经用户确认后清理。

## 完成标准

逐会话新分支 HEAD 均为同一 main 提交或其后代、钩子与 settings.json 与 main 一致；旧分支处置清单（删除/归档）完整；无主工作区清理有用户确认记录。核验见总验收清单 ~/.modernize/psa/coordinator/team-audit/acceptance-1023.md 新增项。
