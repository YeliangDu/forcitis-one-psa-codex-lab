# GOV-1023-MRG-07 批准评论自动入队

加急，开工条件：#635 合入 main；与 GOV-1022-MRG-01 同一 PR 交付。

## 目标

**10-23 改题（intent 115815）**：自动入队永久关闭——撤掉「评论自动入队」与「发帖门合入后开开关」；保留评论留痕、head 核对、人工入队、执行会话登记与批次审计。


根因（10-20～10-23 统计）：已合 code PR 开 PR→入队中位 1.0h、尾部 9–11h；在开 PR 最长 20h。每次批准走「调度消息→one-merge→enqueue」两跳，任一方忙或消息丢失即停。
做法：`mq.py` 运行器每轮扫在开 PR 评论，见调度账号发的「调度批准入队 head <sha>」且 sha 等于当前 head、PR 未在队列，即自动 enqueue 并记 `ENQUEUE-BY-COMMENT`；sha 不符记 `APPROVAL-STALE` 并进 GAPS。依赖写法「调度批准入队 head <sha> after #<m>」等同 `--after`。

## 完成标准

自测覆盖：合格评论入队、sha 不符不入、非调度账号不入、重复评论不重复入、after 依赖、PR 已关闭不入；破坏验证去掉账号判定与 sha 比对各自变红；one-merge 画像写明消息批准仍可用但以评论为准。

## 依据

用户 2026-10-23「现在代码合入太慢了，彻查根因，优化解决」（intent 当日 one-coordinator）。

## 不得做

不改仓库设置与分支保护；不用 --no-verify；产出 opus 首轮。
