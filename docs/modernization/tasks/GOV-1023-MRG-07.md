## 目标

根因（10-20～10-23 统计）：已合 code PR 开 PR→入队中位 1.0h、尾部 9–11h；在开 PR 最长 20h。每次批准走「调度消息→one-merge→enqueue」两跳，任一方忙或消息丢失即停。
