## 状态与最后更新（用户 2026-10-21，intent 2026-10-21-213907）

状态现行取值：已派、进行中、阻塞、完成、作废；表中其余写法（待派、复审中、返工中、待验收、已完成、已提交、已合并、已取消）是存量，检查器合成一条提示，对应关系是 待派→已派、复审中/返工中/待验收→进行中、已完成/已提交/已合并→完成、已取消→作废。可选字段「最后更新」写 ISO 日期或时刻（如 `2026-10-21T21:30:00+02:00`），开工、阻塞、完成时与「状态」一起更新。

`check_tasks.py` 在标准错误输出陈旧报告（先报告档，不失败，不进总表）：状态为进行中或阻塞、最后更新早于 12 小时或没填；片段的「分支」已合入 origin/main 而状态不是完成或作废。`--now <ISO 时刻>` 指定当前时刻供自测。

`task_backfill.py` 按任务号在已合入 origin/main 的提交与合并说明、其他分支的提交、远端分支名、PR 标题（`--prs-json` 或 `--gh`）里的引用推断状态：已合入→完成，有痕迹未合入→进行中，无痕迹→已派；阻塞与作废不覆盖。只输出按会话分组的建议清单（标「待确认」），不改片段，由 one-coordinator 分发给各负责会话确认。
