# GOV-1023-MRG-09 运行器存活

## 目标

现象：merge.log 10-23 01:10→06:19 无事件 309 分钟，期间 #637 似在队列（00:4x 台账记为已批在队）；launchd `com.forcitis.mq` 上次退出码 -15。
做法：①先查因（Mac 睡眠、app 重启连带、launchd 未 KeepAlive、锁未释放），结论报调度；②运行器每 5 分钟写心跳，队列非空且心跳超 15 分钟，或 START 后 90 分钟无 DEQUEUE，写 `STALL` 行进 GAPS（经 GOV-1023-QUA-01 信箱到调度）；③如需防睡眠（caffeinate/pmset），属改系统设置，写收件箱问用户，不自改。

## 完成标准

查因结论附证据；心跳与 STALL 自测、破坏验证；launchd 模板改动随附重装步骤。

## 依据

同 GOV-1023-MRG-07。

## 不得做

不改系统与安全设置；不用 --no-verify。
