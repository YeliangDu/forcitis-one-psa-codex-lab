## 3. 规格
1. `objects.yaml`：从 `docs/modernization/architecture/proposals/ENTERPRISE_INFO_MAP_DRAFT.md` §1 总表（126 行，含分组标题行，分组行不算对象）逐行转换。每条：`id`（OBJ-nnn 原样）、`name`、`definition`、`level`（「一级 / 次级」列原文）、`type`、`key_states`（「关键状态」列原文，不拆）、`relations`、`rules`、`facts`、`source`、`term`（「词表」列）、`scope`、`parent`（「父对象」列中的 OBJ 编号列表，原文另存 `parent_text`）、`group`（所在分组标题）、`source_line`。文字不改、不合并、不新增；加粗等 markdown 标记去掉并在自测覆盖。冻结结论：按 `panorama/FREEZE_FINAL.yaml` 给对应 OBJ 加 `freeze` 字段（原样拷贝该 OBJ 的结论键值），无结论的不加。
2. `state-machines.raw.yaml`：两套原样并列，不合并、不判定：
   - `by_object`：`objects.yaml` 中 `key_states` 非空的对象，`{object, key_states_text, source}`；
   - `by_aggregate`：`proposals/closeout/{finance,people,revenue}/state-machines.yaml` 的 `machines` 全部条目（预期 44＋34＋52＝130），每条保留原结构，加 `group`（finance/people/revenue）与 `source`（文件与序号）；同一 `aggregate` 出现多台时全部保留。
   - meta 写两套条数。
3. 生成文件首行「由 convert_objects.py 生成，勿手改」；`--check` 只比对、不一致非零退出；输入缺失、表头列数不符、OBJ 编号重复时报错退出，不静默跳过。
