# IMP-1022-COO-03 自定义函数固定 search_path

设计：`data/FUNCTION_SEARCH_PATH_PINNING.md`（R-SP-1 至 R-SP-4）。基线开放期直接改基线：八个 schema 共 34 个函数（含 `organization_administration` 的 7 个）在 `CREATE FUNCTION` 上加 `SET search_path = pg_catalog, pg_temp`，不另做追加迁移；函数体只引用目录表与变量，行为不变。

守护：`DataArchitectureTest` 查迁移后数据库的 `pg_proc`（除系统 schema 与扩展成员外全部 schema），每个函数须固定为 `pg_catalog, [本 schema,] pg_temp`，`SECURITY DEFINER` 函数 PUBLIC 无 EXECUTE；注入用例含建在 `public` 的未固定函数；dev、prod 校验脚本加 V11，由同一测试执行脚本文本。

不在本卡：静态扫描项 M7（基线只减不增，主守护已覆盖）、R-SP-5（库与角色层，one-ops）。
