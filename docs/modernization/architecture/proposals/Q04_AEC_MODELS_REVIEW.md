**结论：改后再出。** 研究面广、来源标注诚实，计价模式与履约义务分开、开票计划与收入计划分开两点可直接采用。但关键结论链有两环是推断却写成近似结论（高-1、高-2），推荐方案与自己的会计分析互相矛盾（高-4），对 Q-04 与 ADR 的影响写得比实际轻（高-5、高-6）。不改就合成确认页，会把未核实的推断当作用户决策的前提。

## 二、问题

### 高

1. **把「原样采用 14.1.1」写成主线**（:17、:130、:172）。改法：:17 第二句改为「若某类合同原样采用……第（三）项可能成立」，删去「对我们有利」的定性；:130 改为「可能不符合准则，须审计师判断」；:172「正是本稿推荐的」改为「与选项 X 一致」。另补两点：0210（外立面、照明）与分包格式合同不在 0209 范围；14.1 条位于违约责任下，其性质交律师。
2. **「财报按开票确认」的依据**（:19）。改法：写明证据只有一句答复，并列出替代解释：收付实现制账、增值税纳税义务时点、法定报表。依据 ADR-0016 决定 6（两套 U8C 账）与 D17-8（合同资产减值只记权责账），用户所说的「合同资产」大概率在权责账；F-3 改为分三问：对外报表取哪套账、按什么时点确认收入、税会是否一致。删去「两者都不是……」一句。
3. **准则前提没有前置**（:19、:440）。F-4 若答「小企业准则」：跨年劳务按完工进度确认；据评审方记忆，坏账可能按实际发生转销、不计提准备，「合同资产」「预期信用损失」也可能不适用（请核对原文）。这样第 2、4.3 节与用户「合同资产减值」的说法都要重写。改法：第 0 节第 1 条之前加「前提：F-4」，第 2 节标题注明「若适用 CAS 14」。
4. **推荐方案与本稿自己的会计分析矛盾**（:21、:286、:322 对 :221）。:221 正确指出：客户从未认可的部分，本质是收入确认过早或可变对价问题，不是信用损失。但 :21 推荐「里程碑之间的估计单列仅内部估计，进入减值分层」，等于先按内部估计确认收入，再靠减值兜底。按准则思路，证据薄弱应在**确认端**处理：进度不能合理确定、可变对价限制（第十二条、第十六条，请核对），不应放到减值端。改法：把推荐写成两条并列的待财务选择项：(a) 里程碑之间不确认，或按已发生成本确认（第十二条末句）；(b) 按估计确认，同时输出「证据完整度」供财务参考。「进入减值分层」一律改为「供财务参考」（见中-1）。
5. **C 加 R-b 的 ADR 冲击被写轻**（:394、:381、:419）。主研究判 C 为细化，依据是「规则无状态、收入只凭客户认可证据触发」（主研究 :23）。R-b 让时段履约义务的收入由估计触发、不需要客户证据，直接违反 INV-23 与 ADR-0047 第 1、2 条字面，C 加 R-b 不再能算细化。:394 只写「形态一致」，对 B1、B2 却写了冲击，比较不对等。改法：5.3 表加「ADR 冲击」一列，C 加 R-b 写「修订（待 one-architecture 判）」；同时写明 ADR-0047 第 1 条重申了「不提供投入法」，任何修订都要同时改 ADR-0016 决定 4 和 ADR-0047（后者 2026-10-16 刚采纳）。
6. **新记录的形态、所属 BC 与聚合没写清，而且自相矛盾**。(a) 结论说「两类记录」（:23、:330），但 5.2 表实际新增 R-b、R-c、R-d 三类（:372-374）。(b) R-b 写「只追加」（:372），:402 却说估计有「草稿、审批中」，这与 `Q04_REVIEW.md` J1 指出的问题同类，须说明草稿放在哪里（审批载荷，还是占用行）、「当前有效估计」怎样推导（进度研究乙-2 的代价）。(c) 词表 `progress_assessment` 已由用户 2026-10-15 批准为 `receivables.wip` 的**聚合**，定义是「项目×合同×期间的认定单（证据必备、封期锁定）」。:423 只说「粒度应改」，没有指出它已与 ADR-0016「无状态」及本稿的「只追加、不单独成聚合」（:402）冲突。(d) R-c 没写所属 BC：未定价变更与索赔属 `contract.agreement`（协议与变更索赔，AGG-13「应用变更」「最终价款」），交易价格又决定 AGG-44 的 INV-22 额度。须写清 R-c 与 AGG-13 基线版本的分工，以及与 INV-22 的关系。(e) 全稿没有提 AGG-77：按估计确认的过账要带估计 ID 和修订序号（进度研究 4.2），并沿用 `Q04_REVIEW.md` 第 8 条（确认与过账不同事务、outbox 加对账）；时段法下合同履约成本不挂账，影响 AGG-43 与 INV-88，也没写。改法：5.2 表加「所属 BC / 聚合候选 / 与 AGG-44、AGG-13、AGG-77 的关系」三列，标「交 one-architecture」。

### 中

1. **「减值分层」越界**（:21、:289、:322）。`contract_asset_risk_tier` 的定义是「管理分层……不是减值计量」，证据研究第 5 节也写明「会计口径交财务，只输出证据完整度供参考」。:289「证据强弱进入减值估计是准则内的事」属会计判断。改法：统一写成「系统输出已有客户确认 / 仅内部估计的金额，是否以及怎样用于减值，由财务与审计师定」。
2. **漏了情形甲**（:23、:331「不论选哪个都要加」）。进度研究的结论是：每期估进度若只是管理产值（情形甲），否决条件 1 不触发，估计属项目管理侧，不进 AGG-44。财务原话「产值收入—权责下」本身就可能落在情形甲。改法：:23、:331 加条件「若估计进入法定收入（情形乙）」；R-c 是否必需，也应以 M7、索赔的实际存在为条件（F-9、F-10）。
3. **「先建结构、按配置启用」**（:27、:401）与 CS-1.8「只实现当前阶段」冲突，也等于替正交那一题预选了答案；「都不返工」是过度承诺。改法：写成选项并标出 CS-1.8 冲突，由用户决定。
4. **分类不互斥**（:33-56）。本稿自己说计价方式与付款节点分开（:39），但 M1、M2 只在付款触发上不同；M4「监理式按月平均支付」实为固定总价分期；M7 多半在签约时折算成固定总价后按 M1 执行；M9 不是计价模式。改法：拆成两个维度，价款确定方式（固定、单价×量、工时、成本加酬金、按基数比例、期间服务费）× 付款触发，九种作为常见组合列出。可能还有遗漏：按节约额分成或成功酬金（设计优化、咨询常见，可变对价最重），限额设计奖罚。
5. **与词表的对应没有逐一列出**（:342、:421）。`fixed_price` 的定义是「按里程碑/节点开票计划计价」，把计价和付款混在一起，M2 套不进去；`time_and_materials` 定义里没有封顶。改法：加 M1-M9 到 `pricing_model` 现值及提议值的映射表；定义问题用 `new_term_issue.py` 交 one-glossary。
6. **对照表细节**（:182-190）。M3、M8 系列服务下数量可变，按次确认成立靠「可变对价分摊到可明确区分期间」的例外（IFRS 15.84-85，请核对），未提；M5 写「封顶本身使对价可变」不准，可变的是工时数，封顶只是限额；M6 把代理人净额与 FQ-04 管理口径「净收入 = 总收入 − 委外费用」挂在一起，会误导：我方是主要责任人时，委外成本仍按总额列示，两者不同，应删去这个关联。
7. **内部不一致**：:96 说「Deltek、Unanet 固定价默认是完成百分比」，:261 表写 Deltek 默认「B 累计开票」；「国际同行普遍按时段确认」（:96）是推断，应标出。
8. **证据研究的一处细节没吸收**（:307）。若 14.1.1 真的适用，同一条款也给了解约时按「已完成实际工作量、半阶段保底」主张的合同依据。里程碑之间的过程稿、提交轮次因此是可主张的证据，不只是「仅内部估计」。改法：4.2 第一行补上这一点，交律师。

## 三、事实题 F-1 至 F-11

- 基本都是用户或财务能回答的事实；F-11 是审计师的政策选择，不是事实，应单独标出。F-1 要求用户按金额给占比，负担重，建议以 C1、C2 取证为主，用户只确认口径。
- 诱导：F-3 引用财务原话后问「是否指……按开票确认」，属预设答案，应改为中性的三问（见高-2）。
- **缺少的关键事实**：
  - (a) 是否有法定年审、审计师是谁、对收入口径（A1、时段）有无已出的意见或管理建议书。A1 与 ADR-0047 的生效前提都是「审计师书面认可」，若没有法定审计，这两个前提都要重写；
  - (b) 外立面、照明、深化设计用哪种范本或格式合同，我方是直接对发包人还是分包（关系到 0210 与客户格式合同）；
  - (c) 现在账上合同资产与减值准备的大致规模，跨年未完工合同的规模（决定改口径是否重大）；
  - (d) 诉讼受阻的个案原因分类：缺签收、缺变更确认、视为同意不被采信、计费基数争议。F-6 问的是账面原因，没问诉讼原因；
  - (e) 现在「每期估进度」的结果是否进 U8C 权责账（区分情形甲、乙，F-5 只问用途）；
  - (f) 税务：增值税纳税义务按开票还是按收款，与收入时点是否一致。

## 五、合成确认页时必须让用户知情的事项

1. 「设计合同可能须按时段确认」只基于国家示范文本的通用条款。公司实际合同（专用条款、0210、客户格式合同、分包合同）一份都还没看，结论可能反转。
2. 「现在财报按开票确认收入」只有财务的一句话，可能指收付实现制账或税务口径，未核实。
3. 适用《企业会计准则》还是《小企业会计准则》是全部分析的前提。若是后者，合同资产、减值、第十一条的讨论都要重写。
4. A1、ADR-0047 的生效都要「审计师书面认可」，至今未取得，也不知道有没有法定年审。
5. 若部分履约义务按时段确认，无论 Q-04 选 C 还是 B，都要修订 ADR-0016 决定 4 和 2026-10-16 刚采纳的 ADR-0047（不只是细化）；INV-23 字面也要改。
6. 新增记录是三类（进度估计、交易价格与可变对价估计、履行方式判定），不是两类。它们的所属 BC 与聚合未定；词表 `progress_assessment` 已被批准为聚合，与「无状态」存在冲突。
7. 「里程碑之间的估计先确认收入、再靠减值兜底」与「证据薄弱应在确认端处理」是两种不同的会计做法，由财务与审计师选，系统只提供数据，不替他们分层。
8. 「每期估进度」若只用于管理产值，Q-04 的否决条件 1 不触发，这一题可能整体不需要。
9. 「先建结构、按配置启用」与 CS-1.8 冲突，是给用户的一个选项，不是默认做法。
10. 「约 98% 固定总价阶段款」是 2026-07-07 的口述，没有取证。
