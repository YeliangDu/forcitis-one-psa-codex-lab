## 4. 审批接入契约

1. 业务模块不碰流程引擎，只依赖审批 api 与 `ApprovalCompleted`（ADR-0007）。
2. 审批类型：用印审批、信息技术服务审批；借阅审批为第三个（Q9、Q10），归属待裁。登记路径为编号模块单据类型登记表与流程标识，**不再是枚举 `DocumentType`**（附录 APR-01）；平台枚举新增走 ADR-0067 冻结通道（APR-02）。
3. 回调须同时匹配单据引用、流程类型、实例 ID、轮次与当前状态；重复事件幂等；旧轮事件不改新轮；未知对应或不支持结果拒绝并告警。
4. `ApprovalCompleted` 结果映射：

| 审批结果 | 用印 | IT 工单 | 状态 |
|---|---|---|---|
| APPROVED | 已批准 | 已提交 | 冻结 |
| REJECTED | 已驳回 | 已退回 | 中文名与审批词条「已退回」相反，待 one-glossary（M11、APR-03） |
| RETURNED＋发起人 | 已撤回 | 已撤回 | 冻结 |
| RETURNED＋审批人、系统；CANCELLED | 未定 | 未定 | 待 one-architecture（APR-03） |

5. 审批人解析在本模块完成，以 `FormFieldUsers` 传入；取不到人的处理待审批模块 owner 与 one-security（APR-05）。
