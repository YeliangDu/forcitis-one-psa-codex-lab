# 财务组阶段对齐（流程目录补阶段与跳段说明）

依据：用户「阶段 → 能力 → 信息 → 干系人」逐层对齐（one-architecture 转，2026-10-16）。阶段定义取自 `value-streams.v2.yaml`（governance 分支）。本表供 one-architecture 改 `process-catalog.yaml`；本组骨架 `processes.finance.yaml` 已同步（理由写在 `stages_note`，与目录一致；support 的写 `stages: []` 加 `support: 理由`）。

| 流程 | 阶段 | 理由 |
|---|---|---|
| PRC-163 | VS-12.2 | 利润分配支付是「利润分配」阶段出口（应付股利结清）的一部分 |
| PRC-164 | VS-04.2 | 收入确认冲销后冲回已配对的成本结转，随收入确认所在阶段（VS-04.2，revenue 价值流） |
| PRC-165 | support | 成本核算参数是配置版本，供 VS-10.1 的成本分配与分摊使用，本身不推进任何阶段的对象状态 |
| PRC-166 | support | 资产类别与折旧政策是配置版本，供 PRC-99 计提折旧使用，不推进阶段 |
| PRC-167 | support | 期初余额只在投产时编制一次（ADR-0022 决定 11），是上线初始化，不是周期性价值流阶段 |
| PRC-168 | support | 口径版本是勾稽侧配置（ADR-0023 决定 2），不推进阶段 |
| PRC-169 | VS-10.1 | 勾稽差异案须在关账前处置（月结前置检查），属「期间关账」 |
| PRC-170 | VS-08.2 | 暂挂「报销核定」：事前额度是报销核定的前置依据；VS-08 没有「事前申请」阶段，见待定 ST-1 |
| PRC-171 | VS-05.4 | 公司直付分贝通订单：核对月账单后确认供方应付，属「应付确认」；之后付款进 VS-05.5（PRC-75） |
| PRC-172 | VS-08.2 | 暂挂「报销核定」：出差申请是差旅报销与补贴的前置依据；见待定 ST-1 |
| PRC-173 | VS-05.2 | 超标订单审批发生在向差旅服务商下单时，是对外部资源的采购决定，挂「供方签约」；见待定 ST-1 |
| PRC-174 | support | 出差补贴标准是配置版本，供 PRC-87 生成补贴行使用，不推进阶段 |
| PRC-175 | VS-05.5 | 直接付款申请（豁免清单内）以付款结束，属「付款」 |
| PRC-176 | VS-05.4 | 预付款在取得发票、确认应付时核销，属「应付确认」（阶段描述「确认应付」）；原挂 VS-05.5 改 |
| PRC-75 | 不改（VS-05.5、VS-08.1、VS-08.3、VS-12.2、VS-12.3、VS-13.5） | 写理由：VS-08 只承担 .1 借支、.3 报销付款中的付款时刻；.2 报销核定由 PRC-87 承担，不是跳段 |
| PRC-131 | 不改（VS-05.5、VS-08.1、VS-08.3、VS-12.2、VS-12.3、VS-13.5） | 写理由：VS-08 只承担 .1 借支、.3 报销付款中的付款时刻；.2 报销核定由 PRC-87 承担，不是跳段 |
| PRC-132 | 不改（VS-05.5、VS-08.1、VS-08.3、VS-12.2、VS-12.3、VS-13.5） | 写理由：VS-08 只承担 .1 借支、.3 报销付款中的付款时刻；.2 报销核定由 PRC-87 承担，不是跳段 |
