日期：2026-10-16。评审对象：`processes.finance.yaml`、`NOTES.processes.md`、`data-model.finance.yaml`、`NOTES.data-model.md`（本目录）。依据：`CONVENTIONS.md`（origin/claude/one-architecture-closeout-plan）、`finance_v1.yaml`、聚合稿 §1.2、§2.2、§3.2、§4.1、ADR-0016、0022、0033、0036、0043、0045、0046，SESSION_PLAYBOOK §14.1、§14.2，`glossary/terms.yaml`。只评审，不改被评文件。

机械核对结果：v1 字段除新增 `pending` 外未删改；24 个流程的 `goto`、`on_reject` 都在步骤范围内，判断点最后一条都是 `otherwise`；人工编排流程都有审批节点；所有 `cross_bc` 与 §4.1 依赖边方向一致，唯一不在 §4.1 的 B-12 → B-09（PRC-87 步 6）已登记为接缝问题；文件里没有老系统表名、状态值或编码。
