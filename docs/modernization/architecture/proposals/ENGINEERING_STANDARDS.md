## 未引用的候选（勾选页内容）

| 候选 | 现行版本（一手来源） | 用途 |
|---|---|---|
| OWASP ASVS | 5.0.0（2025-05） | 安全需求与验收逐条核对（比 Top 10 细） |
| OWASP Top 10 | 2025 版（新增软件供应链失败、异常处理不当） | 安全复审清单 |
| ISO/IEC 25010 | 2023（第 2 版，9 个质量特性）；国标 GB/T 25000.10 只有 2016 版 | 非功能需求与质量属性的统一口径 |
| GB/T 22239-2019 等保 2.0 | 现行 | 部署与安全控制的合规基线 |
| 个人信息保护法（2021）+ GB/T 35273-2020 | 现行 | 员工等个人信息的处理、敏感信息、最小化（§14.1 D13） |
| SLSA | v1.2（Build Track + Source Track） | 构建与发布链路的可信度（补 SUPPLY_CHAIN） |
| DORA 指标 | 现为 5 项（含部署返工率） | 交付效能度量 |
| Twelve-Factor | 12factor.net 仍是 2017 原文，修订版未发布 | 部署与配置原则（多已被现有规则覆盖） |
| SemVer、Conventional Commits | — | 版本号与提交信息规范（可选） |

未核实项：ASVS 级别与条目数、Top 10:2025 发布日、25010 九个特性名称、个人信息保护法条款细节、SLSA Build 各级定义。
