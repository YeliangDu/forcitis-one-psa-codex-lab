# 干系人（价值流利益相关者）

来源：用户本地 `forcitis-architecture/3-landscape/strategic/cycle-01/B-business/S01-B-WRK-vs-stakeholder-candidates.md`（v0.10，2026-10-08；多处标「所有者 2026-10-08 定」）。用户 2026-10-15 指定只采用其中的干系人部分（intent `2026-10-15-213742`）；该仓库其余内容仍不是信源（intent `2026-10-15-163920`）。结构依据 BIZBOK v11 §2.8（类型 → 类别 → 具体干系人）；关系：触发 / 参与阶段 / 接受价值（G178 §2.1、§2.2）。

用途：干系人决定有哪些价值流；逐个干系人核对其价值流涉及的业务对象，防止只从客户一个维度识别对象。业务对象不按干系人划分，跨价值流共用（同一「协议」对象以类型区分项目合同、分包合同、劳动合同）。

## 内部

| 类别 | 具体干系人 | 关系 |
|---|---|---|
| 管理层 | 执委会；职能高管；区域和事业部负责人 | 触、参 |
| 员工 | 用人经理；项目经理；设计师和顾问（含驻场）；技术专家；市场和客户经理；职能人员；注册执业人员 | 触 / 参 / 受 |
| 股东和合伙人（类型「两者」） | 股东和合伙人 | 触、受 |

## 只在价值阶段记作参与者（不立类别）

主体建筑设计院（不作发包方时）、施工总包和专业分包、监理、造价咨询和招标代理、保险技术检查机构（TIS）、持证检测机构、资金监管主办银行、物业服务企业（代业主委托时归既有建筑业主）。

## 不列

竞争对手（对我方结果无切身利益，作为商机丢单信息的属性记录）；院校、行业协会、集团内各法人（暂不考虑）。

## 对业务对象梳理的提示（待核对）

- 资本方与既有建筑业主意味着服务不止设计咨询：技术尽调、风险评估、IDI 技术检查、周期检查——可能带来检查任务、缺陷、证据档案等对象（与「品控证据线」相关）。
- 监管机构触发的法定价值流：纳税申报、资质年检与动态核查、社保与统计申报、施工图审查配合。
- 员工：入职到离职、获得报酬；候选人：应聘。
- 合作伙伴：外协分包、联合体、海外持牌伙伴（分工与分成）。
