# 建设工程质量保险与质量保障体系资料合读要点笔记

本笔记保存与 FORCITIS one 相关的阅读要点，不构成架构决定。正文自行概括，短引 0 处。资料均为公开资料（不进仓库），仅核对本地所给版本，未联网核验现行效力或产品现状。

## 核心思想

- **论断：建设工程质量保险包括建筑安装一切险、质量保证保险和相关职业责任保险，上海细则另要求保险公司签订风险管理合同。** 依据：QINS#保险产品集合、QINS#风险管理委托。含义：OBJ-05 协议分别记录职业责任保险、客户工程保险及风控服务的责任主体、标的和期间，不将保额当作我方服务合同金额。

- **论断：上海细则规定严重风险未整改不得提供竣工最终风险评估报告，监理对不合格整改结果须拦住验收。** 依据：QINS#最终风险报告、QINS#整改验收。含义：适用项目的 OBJ-35 交付物、OBJ-37 内部评审与 PRC-28 核对报告签章及前置未闭合项，不以附件上传成功证明闭环。

- **论断：上海细则要求设计整改回复保留前后图纸、计算书、变更及影像，施工整改还须经风控销项和监理验收。** 依据：QINS#设计整改证据、QINS#整改验收。含义：OBJ-48 检查计划、OBJ-49 检查、OBJ-38 不符合项和 OBJ-53 证据对应 PRC-41、PRC-43、PRC-45，保存发现、责任方、回复、复查和关闭证据。

- **论断：上海细则对检测结果规定不同通知时限，合格结果为24小时、不合格结果为12小时。** 依据：QINS#检测通知。含义：OBJ-52 外部检测与 PRC-46 核查资质、计划、结果和通知时间，该地方时限不设为全国统一默认。

- **论断：质量指导意见将全过程质量、合理工期造价及验收信息公开列为建设单位责任，职业人员质量责任亦须落实。** 依据：QINS#质量建设责任、QINS#质量组织模式。含义：沿用保险与风控服务分别保存责任主体的建议，不将保险委托、技术检查、最终报告和赔付混为一项完成记录。

## 对本系统的启示

- 协议 OBJ-05 中职业责任保险单与客户工程保险应记录被保险主体、标的、责任期间及相对方；建设工程 OBJ-46、项目 OBJ-29 关联风控服务协议，不能把保险公司保额当我方服务合同金额。对应 PRC-47、VS-05.2、VS-04.1。（QINS#保险产品集合、QINS#风险管理委托）
- 检查计划 OBJ-48、检查 OBJ-49、不符合项 OBJ-38、证据 OBJ-53 对应 PRC-41、PRC-43、PRC-45：每个问题保存发现、责任方、回复、复查及关闭证据。VS-03.4 的闭环不能由上传成功自动完成。（QINS#设计风险管控、QINS#整改验收）
- 外部检测 OBJ-52 与 PRC-46 采信报告应核查资质、计划、结果和通知时间；不合格快速通知是该细则的地方场景，不全局套用。（QINS#检测通知）
- 交付物 OBJ-35、内部评审 OBJ-37 与 PRC-28、VS-03.5 可记录最终风险评估报告签章及前置未闭合项。保险赔付、保单理赔管理本系统暂无对应完整流程，不自行新增编号或将工程索赔 OBJ-10 等同保险理赔。（QINS#最终风险报告、QINS#保险档案信息）

## 我们的取舍

- **建议采纳：** 保存保险及风控服务的不同责任主体和证据闭环。理由：委托、技术检查、最终报告和赔付是不同环节。（QINS#风险管理委托、QINS#最终风险报告）

- **建议采纳：** 在适用的上海项目中核对整改前后证据、报告责任与验收前置。理由：仅有附件或发现记录不能证明问题关闭。（QINS#设计整改证据、QINS#整改验收）

- **建议不采纳：** 把本系统扩为承保理赔平台，或把地方监管时限当全国统一默认。理由：本卡只证明资料中的具体要求，未证明业务范围与现行适用性。（QINS#保险档案信息、QINS#检测通知）
