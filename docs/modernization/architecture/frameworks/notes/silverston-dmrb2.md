# Silverston《The Data Model Resource Book》第 2 卷要点笔记

本文自行概括专业服务局部内容；不重建全书行业模型。短引：0 处。页码已抽查。

## 核心思想

- 专业服务可承诺特定人员、标准服务、交付物或定制工作，承诺与实际执行各有责任。（SIL2#服务内容与裁剪、SIL2#委托事项、SIL2#协议与服务履行）
- 服务记录保留工时、费用、材料及成果移交与承诺和工作投入的联系。（SIL2#协议与服务履行、SIL2#服务记录计费）
- 通用模式须按服务业裁剪，协议条件可以统辖多次委托，服务组合不等于物料结构。（SIL2#服务内容与裁剪、SIL2#委托事项、SIL2#协议与服务履行）
- 工时分析须按人员、客户、项目、日期、费率及委托事项类型解释；书中 p349 的 gross margin 局部原文口径是成本除以账单金额，不认作本系统的毛利率定义。（SIL2#工时分析）
- 服务目录与一次实际委托分别理解，从交易角色提取分析维度不改变主数据写入权。（SIL2#服务内容与裁剪、SIL2#工时分析）

## 对本系统的启示

- **业务对象（对照：OBJ-05、29、35、66、88（按原笔记待核））：** 专业服务承诺的内容可能是指定专业人员、标准服务、交付物或定制工作。一次委托事项与其条目、执行工作、实际服务记录各自承担不同责任；客户购买一名特定人员的时间，与购买由企业负责的成果也有差别。（SIL2#服务内容与裁剪、SIL2#委托事项、SIL2#协议与服务履行）

- **价值流（对照：原笔记未列本系统价值流编号）：** 本书不涉及 BIZBOK 价值流方法。请求、报价、委托、执行和计费之间的数据追溯可帮助检验价值交付证据，不宜据此直接命名阶段。（SIL2#专业服务请求、SIL2#委托事项、SIL2#服务记录计费）

- **能力（对照：OBJ-44）：** 本书不涉及企业业务能力图。所需技能与实际人员安排是资源匹配问题，不能等同于企业能力分解。（SIL2#专业服务请求、SIL2#协议与服务履行）

- **流程（对照：OBJ-66、82、83（原笔记未列流程编号））：** 实际发生的工时、费用、材料使用和成果移交应能关联承诺及工作投入；记录投入与记录交付并不相同。计费还可以按服务记录或工作投入分别追溯，不能只靠项目总额判断服务已履行。（SIL2#协议与服务履行、SIL2#服务记录计费）

- **数据建模（对照：OBJ-24、OBJ-06/08/30）：** 通用模式在服务业需要裁剪：服务组合不等于实物零件结构，库存也未必是核心；协议的条件可统辖多次委托事项。通用概念复用应保留业务差异，而不是保留所有制造业字段。（SIL2#服务内容与裁剪、SIL2#委托事项、SIL2#协议与服务履行）

- **度量与 BI（对照：原笔记未列本系统度量编号）：** 工时分析要能按人员、客户、项目、日期、费率类型及委托事项类型解释。**p349 对名为 gross margin 的量写成成本除以账单金额**；本文只记录这一局部原文口径，不将它认作本项目的毛利率定义。计费金额也不能自动等于收入确认金额。（SIL2#工时分析；收入边界为项目应用）

- **主数据（对照：OBJ-24）：** 人员、客户和服务目录可供交易与分析共同解释，但目录中的服务与一次实际委托不能混同；从交易角色提取分析维度也不改变主数据写入权。（SIL2#服务内容与裁剪、SIL2#工时分析；写入权为项目应用）

## 我们的取舍

**已审定（one-architecture 2026-10-18，页码已抽查）。**

- **采纳：承诺内容、资源安排、实际投入与成果移交分别追溯。** 理由：适合 AEC 项目制专业服务，但与现有协议、WBS、履约义务及交付物的映射仍须核验。
- **采纳：通用模式按服务业务裁剪。** 理由：书中专业服务章本身就有删除库存结构、调整产品组合等处理。
- **不采纳：将 Engagement 直接等同于项目、协议或履约义务。** 理由：书中将它置于订单承诺层，本项目已有各自语义，必须逐项映射。
- **不采纳：p349 的 gross margin 公式或按工时计费推导收入。** 理由：名称与口径须服从本项目指标定义、合同和会计规则；本卡不改这些规则。
