# 个人信息保护法与个人信息安全规范要点笔记

本笔记为本地资料阅读草稿，保存与 FORCITIS one 的对照，不构成架构决定。正文自行概括，短引0处；编号对应表示目录中有语义落点，不表示已实现或验收。

法律正文载2021年8月20日通过，末条载2021年11月1日起施行。国标封面载2020年3月6日发布、10月1日实施，版本与发布机构由封面图像核对。国标中文文本层乱码，以下条目直接阅读物理页8、11至14的图像；其印刷页为3、6至9，不能用乱码作为内容证据。ADR-0041已决定个人信息保护法与该国标同等采纳，本笔记仅补阅读定位。

## 核心思想

- 个人信息以可识别自然人为范围，去标识化仍保留恢复关联的可能，不能直接按匿名信息对外提供。（PIPL#个人信息范围、PIPL#去标识化隔离）

- 先确认处理依据和必要范围，再确定告知、同意及特殊处理要求；依法进行人力资源管理与任意扩张用途是不同情形。（PIPL#处理合法性基础、PIPL#最小必要目的、PIPL#敏感个人信息）

- 委托、对外提供、跨境及自动化决策有各自条件；接口可调用不代表已经完成这些条件的审查。（PIPL#委托处理边界、PIPL#对外提供、PIPL#跨境提供条件、PIPL#保护影响评估）

- 个人权利、保存期限、受限留存与安全事件响应贯穿生命周期；只追加审计不等于无限保存个人明细。（PIPL#保存期限、PIPL#个人信息删除、PIPL#安全事件处置）

## 对本系统的启示

- 对照 OBJ-56 人员、OBJ-123 人员薪酬档案、OBJ-62 社保与公积金参保及 PRC-123、PRC-125：建议逐项明确算薪、法定申报的处理依据与所需字段，家庭、医疗、金融账户按风险分别控制，不能以一般入职同意包揽全部用途。（PIPL#处理合法性基础、PIPL#敏感个人信息）

- 对照 OBJ-03 联系人、OBJ-120 差旅订单及 PRC-177、PRC-197：向服务商同步前核对其究竟是受托处理还是独立处理者，记录目的范围、约定、接收方与终止处理，不因已有同步功能而假定合法性条件已满足。（PIPL#委托处理边界、PIPL#对外提供、PIPL#保护影响评估）

- 对照 OBJ-109 绩效评估、PRC-120 及 VS-06：若以后引入自动评分或影响薪酬的自动决定，建议预留解释、异议及人工复核；当前材料只给合规条件，不证明系统已使用自动化决策。（PIPL#自动化决策、PIPL#标准自动决策复核）

- 对照 OBJ-53 证据及 PRC-191：保存期、归档和访问停止须逐类确定；依法尚需保留的资料限制非必要处理。删除请求及评估记录暂无独立业务对象对应，本系统暂无对应，不自拟编号。（PIPL#保存期限、PIPL#个人信息删除、PIPL#标准最短存储）

- 对照 OBJ-73 月度薪酬结算和 PRC-90：汇总分析只获取目的所需数据，去标识化映射另存，展示及导出逐项授权；不能因隐藏姓名就认定匿名化。（PIPL#去标识化隔离、PIPL#标准最小访问、PIPL#标准展示与用途）

## 我们的取舍

- 建议采纳：沿用 ADR-0041 已定的法律和国标范围，补齐处理依据、目的、保存期、权限和评估证据。理由：现有采纳决定需要具体处理场景对照，本笔记不重作决定。（PIPL#处理安全措施、PIPL#保护影响评估）

- 建议不采纳：把单独同意按钮作为全部人事处理的唯一合法性依据，或认为去标识化即可永久保留和跨境提供。理由：第13条处理基础、多重跨境条件与保存限制均需分别判断。（PIPL#处理合法性基础、PIPL#跨境提供条件、PIPL#标准最短存储）
