# 全过程工程咨询政策与服务指南合读要点笔记

本笔记保存与 FORCITIS one 相关的阅读要点，不构成架构决定。正文自行概括，短引 0 处。资料均为公开资料（不进仓库），仅核对本地所给版本，未联网核验现行效力或产品现状。

简称：政策为发改投资规〔2019〕515号；协会指南封面确认为武汉建设工程造价管理协会 T/WHECA 002—2025（2025-01-01 发布、01-15 实施），不能泛称全国统一指南；民航指南封面为机场司 IB-CA-2022-01、2022-08-24；监理协会稿封面及前言未载正式发布编号、日期，按派工标注征求意见资料，不能视作已发布规范。协会指南正文印刷页 = PDF 页减 9；民航指南正文减 5。HTML、DOCX 均用条款定位、页码 —。

## 核心思想

- **论断：全过程咨询允许跨阶段或同阶段组合服务，民航指南采用项目建设管理加一项或多项单项咨询的模式。** 依据：QCG#政策服务组合、QCG#民航组合模式。含义：OBJ-24 服务产品、OBJ-06 合同范围条目和 OBJ-25 阶段类型按委托选择组合，在 PRC-12、PRC-47 核对包内外工作，不默认纳入全部专业。

- **论断：联合实施须明确牵头方及各方权利义务责任，总负责人、专业负责人和团队须匹配相应资格与能力。** 依据：QCG#政策联合实施、QCG#政策人员条件、QCG#民航组织接口。含义：PRC-17、PRC-18 保留团队和接口分工，协议记录牵头与联合关系，OBJ-65 企业资质及 OBJ-64 人员证书承接资格核对。

- **论断：咨询酬金可采用专项费用叠加统筹费或人工成本加酬金，计入项目投资后不得重复列支相应专项费用。** 依据：QCG#政策酬金、QCG#民航费用列支。含义：全过程咨询服务范围核对中分列统筹费与专项费用，并检查同一服务是否重复列支。

- **论断：民航指南要求合同明确成果范围并经专业审核、总负责人审定签章，监理协会稿要求策划调整重新审核。** 依据：QCG#民航成果审定、QCG#监理策划审批。含义：OBJ-37 内部评审与 PRC-28 保留专项审核和对外报送证据，工作范围及策划调整保留版本并重新审核，不以此代替合同变更程序。

- **论断：协会指南聚焦政府投资房建市政项目的投资管控，民航指南仅供特定直属单位项目参考且不含运输机场专业工程。** 依据：QCG#协会适用边界、QCG#民航适用范围。含义：不将局部指南提升为全公司强制政策，也不把客户工程投资控制目标并入 OBJ-32 我方项目预算；PRC-19、PRC-30 标明度量主体。

## 对本系统的启示

- 服务产品 OBJ-24、合同范围条目 OBJ-06、阶段类型 OBJ-25 应支持按委托选择组合，在 PRC-12、PRC-47 与 VS-01.2、VS-04.1 核对适用范围、包内外工作和统筹责任，避免把某份指南的阶段枚举直接设成全公司字典。（QCG#政策服务组合、QCG#协会阶段划分）
- 项目 OBJ-29 是我方服务交付单元，建设工程 OBJ-46 是客户工程外部引用；客户投资管控目标与我方项目预算 OBJ-32 不同。PRC-19、PRC-30 核对我方预算及完工估算时，应标明度量主体，不能把客户投资节省直接算我方利润。（QCG#协会阶段目标、QCG#协会设计限额）
- PRC-17、PRC-18、PRC-28 中的团队、交付计划与内部评审 OBJ-37 应保留总负责、专项审核、对外报送及接口分工，服务于 VS-02.0、VS-02。（QCG#民航组织接口、QCG#民航成果审定、QCG#监理策划审批）
- PRC-06 的独立性检查 OBJ-23、企业资质 OBJ-65、人员证书 OBJ-64 可以承接利益关系与资格核对；适用政策版本仍需专业确认。PRC-38 的项目复盘 OBJ-107 可吸收评价方法，但建设项目投产后评价与我方服务复盘不能视为同一事项。（QCG#政策服务组合、QCG#政策人员条件、QCG#协会后评价）

### 供成熟产品关卡

- 协议：记录牵头、联合与委托关系、机构资格及成果责任；不能只留一个客户和一个项目经理。（QCG#政策责任模式、QCG#政策委托资质）
- 履约义务：各项服务和统筹活动提供承诺识别输入；本组指南未给会计上可明确区分的判定，关卡应要求另行核对。（QCG#民航成果清单、QCG#政策合同体系）
- 变更：工作范围和策划调整需保留版本与重新审核，继而对照合同的价款工期变更；本组不提供可直接代替合同变更程序的统一条款。（QCG#监理策划审批、QCG#监理设计界面）
- 全过程咨询服务范围：支持项目管理加单项或专项的可选组合，统筹费与专项费用分列、避免重复列支。（QCG#民航组合模式、QCG#政策酬金）

## 我们的取舍

- **建议采纳：** 以合同服务清单驱动团队、交付及接口核对。理由：组合式咨询要求责任可追溯，不能由产品模块名替代范围。（QCG#民航成果审定、QCG#民航组织接口）

- **建议采纳：** 将投资管控与我方服务经营分别标明主体、范围和成果。理由：协会指南主要管客户工程投资。（QCG#协会适用边界）

- **建议不采纳：** 把地方协会标准、特定单位指南或征求意见稿提升为全公司强制政策。理由：范围和发布状态有明确边界；拟改变已采纳 ADR 的工作仍须待提议。（QCG#民航适用范围、QCG#监理扩展边界）
