# 工程勘察设计收费管理规定及收费标准要点笔记

本笔记保存与 FORCITIS one 相关的阅读要点，不构成架构决定。正文自行概括，短引 0 处。资料均为公开资料（不进仓库），仅核对本地所给版本，未联网核验现行效力或产品现状。

通知及管理规定称为规定，PDF 内的《工程设计收费标准》称为设计标准。年份与发布机构取通知落款及 PDF 封面。PDF 正文印刷页与物理页有偏移：勘察总则印刷 2 对应 PDF 7，设计总则印刷 50–52 对应 PDF 55–57。以下保存的是 2002 年文本内容，未确认其中价格管理制度和参数在当前的效力。

## 核心思想

- **论断：2002 年规定要求在合同中约定收费金额和支付方式，收费公式结果并不自动成为合同金额。** 依据：FEE#收费披露、FEE#金额支付约定、FEE#历史浮动范围。含义：建议 OBJ-21、OBJ-22 及 PRC-07 保存报价依据，OBJ-05 另留谈定金额和偏离原因，不将标准报价直接当成签约或收入事实。
- **论断：设计收费以基本费用和其他费用组成，计费额决定基价，调整系数再参与计算。** 依据：FEE#设计计价公式、FEE#设计计费额、FEE#设计调整系数。含义：建议 OBJ-21、OBJ-22 在 VS-01.2 保存标准版本、计费额来源、档位与系数，历史系数不直接作为现行强制参数。
- **论断：基本设计服务包括后期配合，其他设计服务及部分阶段委托另有范围和计费规定。** 依据：FEE#设计基本服务、FEE#设计其他服务、FEE#部分阶段委托。含义：建议 OBJ-06、OBJ-35 在 PRC-47、PRC-28 明确已含后期配合与额外服务，由费用估算和合同范围共同支持 VS-02 的核对。
- **论断：发包人原因增加的工作量与设计人质量不合格导致的返工，费用责任不同。** 依据：FEE#工作量增费、FEE#质量返工。含义：建议 OBJ-38、OBJ-39 与 OBJ-09 分流，PRC-34 处置质量返工，PRC-48 处理客户范围变化，不把所有返工工时变成客户应付。

## 对本系统的启示

- 报价 OBJ-21 与报价估算分解 OBJ-22 在 PRC-07、VS-01.2 可保存引用标准版本、计费额来源、档位及系数，最终谈定合同 OBJ-05 另留金额与偏离原因，不把标准报价直接作为签约或收入事实。（FEE#设计计价公式、FEE#设计基价插值）
- 合同范围条目 OBJ-06、交付物 OBJ-35 对应 PRC-47、PRC-28 时，应明确基本费用包括的后期配合及额外服务；费用估算和合同范围共同支撑 VS-02 的成本与交付核对。（FEE#设计基本服务、FEE#设计其他服务）
- 不符合项 OBJ-38、返工认定 OBJ-39 与协议变更 OBJ-09 分流：PRC-34 处置质量返工，PRC-48 处理客户范围变化，不能将所有返工工时变成客户应付。（FEE#工作量增费、FEE#质量返工）

## 我们的取舍

- **建议采纳：** 将收费标准作为可追溯报价依据，保存版本、输入及人工商定结果。理由：公式价格与合同金额不同。（FEE#金额支付约定）

- **建议不采纳：** 把 2002 年投资门槛、浮动幅度、系数与服务比例当作现行强制价格政策。理由：本卡离线未核后续政策及合同适用性；需要引用时交负责会话核验。（FEE#历史价格分界、FEE#历史浮动范围）
