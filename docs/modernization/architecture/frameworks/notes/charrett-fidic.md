# Charrett 主编《The International Application of FIDIC Contracts》要点笔记

按资料清单 FID 读取原文，自行概括，短引 0 处。本书主要分析施工合同；第 1–4 章由 Charrett 撰写，国别差异分别归于各章作者。下文把这些解释与白皮书第五版的具体款对照，**对照是本笔记的比较，不表示本书逐款解释了白皮书**。所述国别法律与案例均是书中 2020 年出版时的材料，未作现行有效性核验；不据此制定当前法律规则。

## 核心思想

- **论断：书中巴西案例允许在没有客户书面变更指令时，凭客户持续到场、明知项目改动且未反对的事实主张变更价款；只查签字指令会漏掉可能成立的请求。** 依据：FID#变更默示认可（§5.8.1，印刷 86 / PDF 171）。含义：OBJ-09、PRC-48 保存指令及估价之外，还须容纳 OBJ-53 的知情和异议证据交 PRC-49 审查；这不是直接把未批准变更设为生效，对应比较白皮书 5.1.1–5.1.3、5.2.1–5.2.4。
- **论断：终止未完成合同不必然只结已做工作；书中瑞士任意终止机制补偿剩余合同损失包括利润，1999 红皮书对此未明示补偿会留下解释争议。** 依据：FID#终止补偿（§20.4.6，印刷 376–377 / PDF 461–462）。含义：OBJ-05 的 PRC-68 终止须把理由及范本版次交给 PRC-66 分项清算，不能将 OBJ-08 未履行承诺直接计成已履行；对应白皮书 6.5.1–6.5.4，而其利润补偿有更具体的事由范围。
- **论断：期中证书可以独立形成付款请求，而付款争议还可能另受法定短时限约束；它们都不能由最终竣工日或一张税票代替。** 依据：FID#期中证书与到期、FID#付款法定救济（§18.8.9、§14.4.2）。含义：OBJ-07、OBJ-53 分别保存核证、到期和争议程序起点；PRC-57 开税票不覆盖全部证据，对应白皮书 7.2.1、7.5.1 及另行委托施工管理的 3.9.1–3.9.3。
- **论断：合同赔偿上限和职业责任保险不能消除书中法国强制的工程责任；与客户直接签约的设计等角色可能仍负十年责任并须投保。** 依据：FID#责任上限差异、FID#强制责任与保险（§20.4.5、§9.5.2.1–§9.5.2.2）。含义：OBJ-05 应分别关联约定上限、角色、法定责任审查及保单，不能用保额反推赔偿责任或 OBJ-07 正常应收额；对应白皮书 8.1.3、8.2.1、8.3.1–8.4.1、9.1.1–9.1.4。
- **论断：客户付费委托作品不总以咨询方保留版权为默认；书中马来西亚章指出其法定归属与红、黄皮书由制作方保留权属的文字冲突。** 依据：FID#委托作品权属（§14.3.1.1，印刷 261–262 / PDF 346–347）。含义：OBJ-05、OBJ-35 要分别核对权属、项目用途许可和适用法，不能从 OBJ-07 已付款推导全部权利已转移；对应白皮书 1.7.1–1.7.5。

### ① 变更：书面程序之外还要识别知情行为与指令权边界

**Charrett 编著的解释与差异。** 巴西章 §5.8.1 指出，客户反复到场或参与管理，不可能不知项目已变却从未反对时，承包商即使没有书面批准也可能取得变更请求权；书中依据诚信与避免不当得利解释为何合同批准程序可能被突破，认定仍取决于客户专业能力、项目及改动复杂度。不是一切沉默都视为同意。德国章 §10.3.1.12 则从指令权入手：FIDIC 施工合同由 Engineer 或客户发起，BGB §650b 的法定结构要求先尝试协商，30 天未果才可指令；作者提出标准条款审查问题，又认为鉴于旧有实践，即时指令未必无效，书中没有作出一律等待 30 天的结论。（FID#变更默示认可、FID#变更协商期）

**对应白皮书。** 5.1.1、5.1.2(f) 区分客户通知与咨询方提案经书面接受；5.1.3 是咨询方尽快识别并估计费用、进度、客户收后 14 天回应，以及咨询方收否定通知后 7 天提争议。估价和定价按 5.2.1–5.2.3：附件 3 费率优先，不适用则议新费率；5.2.4 是收变更通知后 14 天未谈拢或开工前不能确定全部影响时，可再指令先做并按耗时、附件或合理费率补偿。这些白皮书数值来自 FIDW 原文，不能归给巴西或德国章，更不能把德国 30 天换进白皮书。（FIDW#变更、FIDW#变更价款与先行指令）

- **协议：** OBJ-05、OBJ-06 经 PRC-47 核对范本版次、指令权限、通知方式及适用法修改；不能让工程师职称自动获得商业改价权。（FID#专用条款与适用法、FID#角色语义）
- **变更：** OBJ-09、PRC-48 与 OBJ-53 保存书面指令、客户知情行为、异议、估价及日期；未获双方批准的请求仍可交 PRC-49 认定，但不能跳过信息图既有生效门槛。
- **履约义务：** 把受影响 OBJ-06、OBJ-35 关联 OBJ-08 重新判断承诺和交易价格；变更请求成立、执行工作和客户认可分别留证。
- **付款条件：** OBJ-07 分开已定价、按耗时暂计、争议待认定部分；本书未给白皮书咨询费估价的独立固定期限，不能杜撰「逾期估价即放弃价款」。

### ② 暂停与终止：法定权利、合同事由和剩余利润不能共用一个开关

**Charrett 编著的解释与差异。** 阿联酋章 §21.8.4 说明，Engineer 合同指令暂停之外，对方未履行对应义务时，民法典第 247 条还可能授予当事人暂停权，但错误行使会产生不利后果。巴西章 §5.8.2 所引判例认为，对企业持续经营必需的合同，仅凭司法重整便终止可能妨碍重整目的，条款可被排除。瑞士章 §20.4.6 区分有因终止与任意终止：不具备有因条件的终止可能被认作任意终止，按第 377 条补偿剩余合同损失含利润；这属于可由合同替代的规则。1999 红皮书 15.5 未明示剩余利润，作者要求澄清；2017 红皮书 15.5、15.6 已有不同表述，不能只记「FIDIC 终止」。（FID#暂停法定权利、FID#重整终止限制、FID#终止补偿）

**对应白皮书。** 6.1.1 的客户暂停需 28 天通知，6.1.2(a) 的无有效争议欠款暂停由咨询方提前 7 天通知；6.2.1–6.3.4 再处理复工、已做服务费、保全、减损、费用和延期。6.4.1(a) 是 28 天内未着手补救后再给 14 天终止通知，6.4.1(d) 任意终止为 56 天且不得借此转交他人或自做；6.4.2(b) 欠款或资金安排暂停超 42 天、6.4.2(a)/(e) 相应暂停超 168 天，另须 14 天终止通知。破产终止在 6.4.1(b)、6.4.2(c) 已明写受适用法律允许范围约束。6.5.1–6.5.3 区分已做服务、客户新增完成成本及咨询方额外费用；6.5.4 只对客户任意终止或咨询方 6.4.2(a)–(d) 的终止另补未做服务利润，不包括特殊事件的两条终止分支。（FIDW#暂停与恢复、FIDW#终止事由、FIDW#终止结算）

- **协议：** OBJ-05 保存暂停范围、事由及所据合同或法律审查证据；PRC-68 终止前核对适用版本和有效通知，而不是观察到破产标签便自动终止。
- **变更：** OBJ-09、PRC-48 处理暂停引起的范围、费用、工期调整，争议经 PRC-49 留证；合同权利与内部批准不能互相替代。
- **履约义务：** OBJ-08 标明已做、未做及取消的承诺，OBJ-35 固定终止时成果；剩余利润赔偿不能充作未完成成果的客户认可证据。
- **付款条件：** OBJ-07、PRC-66 把已做服务费、撤场及其他合理费用、剩余利润、客户反索赔及已付款逐项清算，另核暂扣权；终止状态不会消灭未清款项。

### ③ 付款与期中证书：核证、合同到期及法定争议程序各自起算

**Charrett 的解释。** 第 2 章 GP4 说明，缩短履责或提出请求的时间可能使权利丧失，延长发证时间则直接影响承包商现金流；GP5 把日常核证与独立争议裁决分开，避免让受雇于客户的 Engineer 同时成为最终争议裁断者。中国章 §6.8.1 再区分授权 Engineer 审核付款、发指令、作中立决定与当地监理法定职责。（FID#风险配置、FID#角色语义）

**国际差异。** 南非章 §18.8.9 将获客户授权者发出的期中证书视为独立付款请求基础；相关三年期间待证书签发且金额到期才起算，最终合同价的期间又可能取决于全部完工及最终证书到期。马来西亚章 §14.4.2 则先要求走合同付款机制，未付方随后可发法定请款；对方有 10 天承认或争议，未回应视为争议全部金额，绝非自动批准；裁决须在裁决答辩送达后 45 天内作出。该章明确范围可含咨询协议，裁决在被撤销、书面和解或终局裁判前有约束力，认定款不付还可引出暂停等救济。章中同时指出背靠背付款禁令的判例适用范围和该法时间效力仍有争论，不能抹去这些限定。（FID#期中证书与到期、FID#付款法定救济）

**对应白皮书。** 自身咨询费按附件 3 填付款节点、账单提交程序及方式；7.2.1 缺省开单后 28 天付款，7.2.2 逾期按约定利率从到期日至实收日按月复利；7.5.1 部分拒付须开单后 7 天内说明，余款照付，争议款最终认定应付仍计融资费。受托为施工承包商核证则属 3.9.1–3.9.3 的另行委托和施工合同权限，并不把自己的咨询费统一转为证书请款；上述南非、马来西亚规则也不替换白皮书时限。（FIDW#报酬与付款条件、FIDW#争议账单、FIDW#施工合同管理与证书）

- **协议：** OBJ-05、PRC-47 标明收费协议、被管理施工合同及客户授权，防止将两种合同的付款人、收款人或核证角色混用。
- **变更：** OBJ-09、PRC-48 调整节点或账期时保留前后条件、核证权限及生效日，不能追溯覆盖已开证书。
- **履约义务：** OBJ-08、PRC-53 仍须独立核对收入依据；PRC-28 的交付物认可、施工期中核证与自身账单不是同一事实。
- **付款条件：** OBJ-07、OBJ-53 分开登记请款、核证、到期、争议及实收；PRC-56 处理可结算，PRC-57 处理税票。法定请款和裁决证据的具体承载须另作规格，不虚构现有流程能自动执法。

### ④ 责任上限与保险：合同除外条款还须经角色和强制责任检验

**Charrett 编著的解释与差异。** 瑞士章 §20.4.5 说明，2017 施工范本责任上限及间接损失排除不保护故意或重大过失，较 1999 版的重大过失缺口已调整，且该词须按瑞士强制法解释。法国章 §9.5.2.1 区分验收后一年完善、两年设备正常运转和十年重大缺陷责任，排除或限制相应强制责任的条款无效；十年责任可及直接与业主签约的工程师、建筑师等，不能把所有分包人和纯顾问一律算进来。§9.5.2.2 的保险机制又按角色区分：业主工程损害保险先融资修复，再追索责任方的十年责任保险；直接签约设计者等须投保，书中明确列举了例外及工程类型限制。责任存在、法定投保义务及某份保单实际能赔，是三个判断。（FID#责任上限差异、FID#强制责任与保险）

**对应白皮书。** 8.1.3 限可预见直接损失及可归责比例，8.2.1 由专用条件定责任期；8.3.1–8.3.2 定累计赔偿上限并保留融资费，8.3.3 的利润等排除保留 6.5.4。8.4.1 列举故意、明显且鲁莽的违约、欺诈、欺诈性失实陈述及鲁莽不当行为，没有照搬瑞士章所讨论施工范本的重大过失措辞。9.1.1–9.1.4 要求职业责任、公众责任和法定险，在商业上合理可得的前提下维持，保额不得低于专用条件、职业责任险维持至责任期末，并提供证明和取消通知。国别法的修订是否适用于某份咨询协议，仍须核实际角色与法律。（FIDW#责任范围与期限、FIDW#责任上限与例外、FIDW#保险）

- **协议：** OBJ-05、PRC-47 分别核责任上限、适用期间、法定责任审查及保险单 OBJ-53；职业责任保险单在信息图属于协议类型，不另造已经实现的保险对象。
- **变更：** OBJ-09、PRC-48 扩服务、延工期或调责时核保单范围、期限、除外责任是否要变，不能仅随合同额自动放大保额。
- **履约义务：** OBJ-08 的服务承诺与赔偿、持续投保义务分别追溯；OBJ-35 已交付不能证明后续责任终止，PRC-49 保留损失和归责证据。
- **付款条件：** OBJ-07 的正常服务费不以赔偿上限或可赔保额截断；反索赔抵扣另核白皮书 7.2.3 的同意、裁决或仲裁依据，不能直接净掉未认定索赔。

### ⑤ 知识产权与成果归属：法定初始归属和项目许可须分别取证

**Charrett 编著的解释与差异。** 马来西亚章 §14.3.1.1 先说明版权起初归作者，再说明委托或雇佣作品被视为转给委托人或雇主，指出与红、黄皮书 1.10 由承包商保留设计文件版权的文字冲突，建议合同调整以与法律一致。瑞士章 §20.6.1.5 则说明，满足独创性条件的建筑及图纸均可获保护；建筑建成后所有人可以改造，但损害建筑师人格权时仍可能被其反对。文件交付、付费、实物所有权、知识产权及可否修改不能互相替代。（FID#委托作品权属、FID#建筑作品修改）

**对应白皮书。** 1.7.1 新创知识产权归咨询方，客户取得全球、免许可费、与项目有关的使用复制许可；1.7.2 双方原有权属不变并相互授必要许可；1.7.3 咨询方保证纳入服务的本方材料不侵害第三方权利，1.7.4 限定偏离原用途使用的责任，1.7.5 对欠付到期款允许提前 7 天通知撤许可。6.5.2(a) 特定终止时交付可编辑成果另有依据。这是与国别默认规则比较的款号，并不表示马来西亚或瑞士章验证了该白皮书许可撤回条款的效力。（FIDW#成果使用许可、FIDW#终止结算）

- **协议：** OBJ-05、OBJ-06 经 PRC-47 核知识产权初始归属、许可用途、可修改范围及专用条件变动，OBJ-53 保存第三方许可和审查证据。
- **变更：** OBJ-09、PRC-48 对跨项目复用、扩大用途、另交源文件重新核权利及定价；设计内容修改再关联 OBJ-40、PRC-31，不能只看修订版号便推定获得权利。
- **履约义务：** OBJ-35、PRC-28 保存成果与来源；是否包含可明确区分的许可承诺交 OBJ-08 判断，不能把每次复制等同新履约义务。
- **付款条件：** OBJ-07 欠款只能触发撤许可权利审查与有效通知核对，不能自动删除客户文件；已付款也不能直接证明全部权属转移或作者人格权消失。

### 供成熟产品关卡

- **变更：** 同一案例分别放入「有书面指令」和「客户明知且未反对」两组证据，检查产品能否保存请求与争议而不伪造批准；再核德国 30 天协商讨论和白皮书 14/7 天机制不会被混成同一个时限。（FID#变更默示认可、FID#变更协商期；FIDW#变更）
- **暂停与终止：** 用重整、欠款暂停、任意终止三例核通知、法律审查、截至终止日服务费及剩余利润的适用依据，检查终止后清算和索赔仍可追溯。（FID#暂停法定权利、FID#重整终止限制、FID#终止补偿；FIDW#终止结算）
- **付款与期中证书：** 用一张施工期中证书和一张咨询费账单核付款人、授权者、到期起点及争议程序；法定请款超时未回应不得自动标作认可，且不能以税票替代所有证据。（FID#期中证书与到期、FID#付款法定救济；FIDW#施工合同管理与证书）
- **责任上限与保险：** 用项目扩范围后保单未续保、约定上限与强制责任冲突两例，检查能否分别表达角色、责任期、保额和法定责任审查，不能仅给「已投保」勾选框。（FID#责任上限差异、FID#强制责任与保险；FIDW#保险）
- **知识产权与成果归属：** 用委托作品法定归属、跨项目复用、建成后修改三例，检查能否分别追溯权属、用途许可和作者权利；付款及文件下载均不单独证明获全部权利。（FID#委托作品权属、FID#建筑作品修改；FIDW#成果使用许可）

## 我们的取舍

- **建议采纳：每项变更、暂停、终止和付款请求都保留所据款、触发事实、通知及救济期限。** 理由：书中具体案例表明，签字、知情、核证、到期或司法重整会产生不同后果，单一审批状态不能承载这些条件。（FID#变更默示认可、FID#重整终止限制、FID#期中证书与到期）
- **建议采纳：清算、责任、保险和许可按项目协议及适用版本逐项审查。** 理由：剩余利润补偿、强制工程责任及委托作品权属均有具体差异，可作为 OBJ-05、OBJ-07 后续规格与产品核验问题。（FID#终止补偿、FID#强制责任与保险、FID#委托作品权属）
- **建议不采纳：把本书施工合同机制或国别案例直接变成白皮书及全企业通用规则。** 理由：GP 表述明确限施工合同，国别章也有适用角色、程序和历史时点限制；每个白皮书款号的对应是比较，不是同一规则。（FID#风险配置、FID#适用法律、FID#付款法定救济）
- **建议不采纳：以证书、终止利润、保险赔款或知识产权许可直接代替履约义务及收入证据判断。** 理由：合同请求权、损失救济与 OBJ-08、PRC-53 的会计处理不同，笔记不能改变现行决定。（FID#期中证书与到期、FID#终止补偿、FID#强制责任与保险）
