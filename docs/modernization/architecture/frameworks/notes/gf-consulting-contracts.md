## 核心思想

- **论断：全过程咨询服务清单须逐项列明工作、成果、标准、管理配合及限制，并可约定接口责任。** 依据：GFQ#全咨服务清单。含义：OBJ-05、OBJ-06 在 PRC-47、VS-04.1 中据此核对承诺，OBJ-07 的付款条件与 OBJ-08 的会计义务分别识别，不能按清单勾选自动一项一义务。
- **论断：全咨费用可采用专项费用加统筹费、人工成本加酬金等组合，开支和奖励另列，按时间及实际开支计费须保留完整记录。** 依据：GFQ#全咨计价组合、GFQ#全咨时间记录。含义：产品关卡核对单项费用、统筹费、包内开支与另行补偿，并保留 OBJ-66、OBJ-53 作为时间及费用计费依据。
- **论断：服务变更须识别、通知并评价价格与其他服务的影响，价格未商定时仍可能获执行指令并按时间补偿。** 依据：GFQ#全咨变更程序、GFQ#全咨变更影响。含义：PRC-48、PRC-49 的 OBJ-09、OBJ-10 与 PRC-31 的 OBJ-40 分开追溯，区分已识别、获指令和费用已商定，未定价工作仍留 OBJ-66、OBJ-53，支撑 VS-02。
- **论断：工程咨询交付验收须约定形式、数量、时间、方法及标准，合格后出具书面成果完成证明。** 依据：GFQ#咨询交付验收、GFQ#造价成果清单。含义：PRC-28 保留交付认可证据，与 PRC-53 收入确认、PRC-56 付款条件达成分别核对；产品支持成果清单、付款节点和会计义务的关联，不自动视为一一对应。
- **论断：监理合同终止要求工作完成且酬金全部结清，造价合同还分别核对已完成服务结算与资料交还。** 依据：GFQ#监理终止条件、GFQ#造价终止结清。含义：PRC-66、PRC-68 及 VS-02、VS-04.5 分别核对工作、款项和资料，不能合成一个完成勾选。

## 对本系统的启示

- 协议 OBJ-05、合同范围条目 OBJ-06、付款条件项 OBJ-07 和履约义务 OBJ-08 应分别承接范围、计价、到期与会计承诺；服务清单字段可帮助 PRC-47 和 VS-04.1 检查完整性，不能据勾选项自动一项一义务。（GFQ#全咨服务清单、GFQ#造价服务计价清单）
- 项目团队成员 OBJ-34、人员 OBJ-56、注册执业证书 OBJ-64 与 PRC-17 应可回查对外授权、投标承诺及替换批准，而非只看内部资源排期。（GFQ#监理团队、GFQ#造价团队授权）
- PRC-48、PRC-49 对应协议变更 OBJ-09、索赔 OBJ-10；PRC-31 对应设计变更 OBJ-40。需区分变更已识别、获执行指令和费用已商定，未定价工作仍留工时单 OBJ-66、证据 OBJ-53，服务于 VS-02。（GFQ#全咨变更程序、GFQ#全咨变更影响、GFQ#全咨时间记录）
- PRC-28、PRC-53、PRC-56 分别对应交付认可、收入确认和付款条件达成；PRC-66、PRC-68 对应最终结算及终止。工作完成、金额结清、资料移交不能合成一个完成勾选。对应 VS-02、VS-04.5。（GFQ#咨询交付验收、GFQ#造价终止结清、GFQ#监理终止条件）

### 供成熟产品关卡

- 协议：能否承载多服务清单、排除项、接口责任、联合体和受托责任，保留不同合同范本的约定。（GFQ#全咨服务清单、GFQ#全咨转委托）
- 履约义务：产品是否支持范围单元、成果清单、付款节点和会计义务多对多核对；文中没有规定它们自动一一相等。（GFQ#造价成果清单、GFQ#咨询付款安排）
- 变更：验证先发执行指令、后定最终费用，以及附加时间补偿时，能否保留通知、指令、实际工时和价款修订链。（GFQ#全咨变更影响、GFQ#监理附加工作）
- 全过程咨询服务范围：能否并列单项费用和统筹费，明确包内开支与另行补偿；不将全过程咨询缩为监理或仅设计。（GFQ#全咨计价组合、GFQ#监理服务边界）

## 我们的取舍

- **建议采纳：** 用服务、成果、费用、时间和责任清单核对协议完备度。理由：四类范本各有可核对的清单及程序。（GFQ#全咨服务清单、GFQ#造价成果清单）

- **建议采纳：** 保留时间及费用计费证据，并分开技术变更、合同变更及会计处理。理由：费用暂未一致也可能先执行工作，不能丢失权利基础。（GFQ#全咨变更影响、GFQ#全咨时间记录）

- **建议不采纳：** 将任何默认期限、赔偿公式或逾期同意条款设成全局政策。理由：受专用条款及合同适用条件约束；若拟以逾期同意自动确认收入，须待提议，并按 ADR-0047 的开放条件核对。（GFQ#全咨成果审查）
