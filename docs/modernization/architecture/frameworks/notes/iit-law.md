# 个人所得税法、实施条例与专项附加扣除暂行办法要点笔记

本笔记为本地资料阅读草稿，保存与 FORCITIS one 的对照，不构成架构决定。正文自行概括，短引0处；编号对应表示目录中有语义落点，不表示已实现或验收。

## 核心思想

- **论断：居民工资、劳务报酬、稿酬和特许权使用费按年度合并计税，股息红利等另按其所得类别计税。** 依据：IIT#个税居民身份、IIT#综合所得范围、IIT#工资与劳务报酬、IIT#个税税率结构。含义：OBJ-56、OBJ-123 及 PRC-123、PRC-124 分别保存居民身份与所得类别的生效期间；OBJ-112、PRC-112、PRC-113 的利润分配不得并入工资税率表输入。
- **论断：支付所得的单位或个人承担扣缴义务，居民综合所得的预扣与年度汇算是不同环节。** 依据：IIT#扣缴义务人、IIT#个税计税基础、IIT#预扣与年度汇算。含义：OBJ-73、OBJ-92 及 PRC-125 沿 VS-13 分开记录算薪、预扣申报、缴税与汇算协作，调岗或部门变化不能自动改变扣缴法人。
- **论断：扣除信息由个人提交并负责真实性，扣缴方发现不符时不得擅自改写个人申报。** 依据：IIT#扣除信息报送、IIT#扣缴信息更正。含义：OBJ-53、OBJ-123 和 PRC-123 保留个人提交版本与更正来源，按用途限制家庭、医疗信息访问，不向项目经营分析直接输出这些明细。
- **论断：所供2018年办法对教育、租金及赡养老人扣除分别规定期间、分摊或互斥条件，不能用一个固定月额概括。** 依据：IIT#继续教育条件、IIT#住房租金条件、IIT#赡养老人分摊、IIT#旧版附加扣除类别、IIT#子女教育条件。含义：OBJ-123 的扣除信息须随个人申报版本和所得年度追溯，不默认替个人选择夫妻分摊，也不以2018年六类与旧金额直接实施现行扣缴。

## 对本系统的启示

- 对照 OBJ-56 人员、OBJ-123 人员薪酬档案及 PRC-123、PRC-124：建议为税收居民身份、所得类别、扣缴法人和扣除信息分别保存生效期间；调岗或部门变化不能自动改扣缴主体。（IIT#个税居民身份、IIT#扣缴义务人）

- 对照 OBJ-73 月度薪酬结算、OBJ-92 法定申报和 PRC-125：沿 VS-13 分开算薪、预扣申报、税款缴纳及年度汇算协作，记录应扣、已扣、已报与缴库回执的差异。（IIT#预扣与年度汇算、IIT#扣缴缴库期限、IIT#全员全额报送内容）

- 对照 OBJ-112 利润分配和 PRC-112、PRC-113：股息红利与工资综合所得须按其真实所得性质分别核对，不能把利润分配金额并作工资税率表输入。（IIT#综合所得范围、IIT#个税税率结构）

- 对照 OBJ-53 证据、OBJ-123 人员薪酬档案和 PRC-123：扣除信息更正须保留个人提交版本与更正来源，按用途限制访问家庭、医疗信息；不给项目经营分析直接输出这些明细。（IIT#扣缴信息更正、IIT#扣除信息报送）

### 供 one-rules 核对

- IIT#扣缴义务人：支付所得法人必须与任职、承担成本、参保口径分别核对。
- IIT#预扣与年度汇算：年度税额与月度预扣不应混为同一计算结果。
- IIT#住房租金条件：同年度房贷利息与租金互斥及夫妻分摊需查声明。
- IIT#扣缴信息更正：个人申报不能由算薪人员无依据覆盖。

## 我们的取舍

- 建议采纳：用个人申报版本、所得年度和支付主体形成扣缴计算依据。理由：法律分别规定年度计税、支付扣缴和信息更正责任。（IIT#扣缴义务人、IIT#扣缴信息更正）

- 建议不采纳：用2018年六类及旧金额直接实施现行扣缴，或由系统默认替个人选择夫妻分摊方式。理由：所供文件未覆盖全部后续政策，分摊属于个人声明且有年度限制。（IIT#旧版附加扣除类别、IIT#子女教育条件）
