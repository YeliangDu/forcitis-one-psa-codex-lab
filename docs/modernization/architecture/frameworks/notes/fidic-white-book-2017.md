# FIDIC 白皮书第五版要点笔记

资料出处：公开资料（不进仓库）《Client/Consultant Model Services Agreement》。题名、机构、版次与年份据封面及扉页（PDF 1、3）；按派工分类为书籍，内容实际是咨询服务协议范本。以下为自行概括，正文短引 0 处，不构成架构决定或具体协议的法律意见。未入词表的概念标题仅作资料索引，待用语核对，不是新增正式术语。

## 核心思想

- **协议由有优先顺序的文件共同构成。** 协议书、专用条件、通用条件、附件及被纳入的要约和接受文件共同界定承诺，不能只保存一份金额摘要。（FIDW#协议文件组成）
- **范围同时界定做什么、排除什么、依赖谁。** 附件分别说明服务、客户提供条件、报酬与付款、进度；服务目的与专业注意义务相互约束。（FIDW#合同范围、FIDW#客户提供条件、FIDW#专业注意义务）
- **变更既有指令链，也有计价和时间影响链。** 客户通知、顾问提案、影响评估、书面约定和开工指令须能相互追溯；未定价先行有专门处理条款。（FIDW#变更、FIDW#变更价款与先行指令）
- **履行服务、出具账单和收款各有证据。** 按时计费还要求保存可核查的时间与费用；争议部分与无争议部分分别处理。（FIDW#报酬与付款条件、FIDW#争议账单、FIDW#时间与费用记录）
- **暂停有保全与费用后果。** 暂停不抹去已经履行的服务，也不等于终止；其对费用、期限及恢复的影响需要独立记录。（FIDW#暂停与恢复）

## 对本系统的启示

- **把协议承诺还原到来源文件与授权。** OBJ-05 协议、OBJ-06 合同范围条目和 OBJ-53 证据可支撑 PRC-47 起草并回签协议；建议核对文件清单、版本、优先级、授权代表及通知方式的承载位置。VS-01.5 合同签订可据此检查签署资料是否足以说明承诺，不能只看协议已上传。（FIDW#协议文件组成、FIDW#通知与送达、FIDW#授权代表）
- **客户输入与交付责任应连到计划。** OBJ-42 发包人提供资料与 OBJ-31 交付计划可对应输入责任、到位日期和延误通知；OBJ-35 交付物保存本方产出。该对照支持 VS-02 的交付链；范本本身不证明本系统已有全部字段。（FIDW#客户提供条件、FIDW#交付计划、FIDW#延期申请）
- **变更与设计变更分别核对。** OBJ-09 协议变更、PRC-48 提出并生效协议变更或签证承载商业承诺修改；OBJ-40 设计变更与 PRC-31 承载成果内容修改。二者可以关联，但不能自动等同。未定价先行涉及 OBJ-12 风险交付授权，其具体准入与计价规则仍待提议，不从范本直接获得授权。（FIDW#变更、FIDW#变更价款与先行指令）
- **分包并不自动转走对客责任。** OBJ-05 的供方协议及 PRC-70、PRC-72 可与对客范围相连，记录客户同意与本方责任；按总额或净额确认收入还须另做收入准则判断。（FIDW#转委托责任）
- **账单依据与收入依据分别留痕。** OBJ-07 付款条件项、OBJ-66 工时单与 OBJ-53 证据可支撑计价核验，PRC-57 的增值税发票不能直接等同范本的商业账单；VS-03.1 收入确认仍按本系统已采纳的会计决定及确认配置执行。（FIDW#报酬与付款条件、FIDW#时间与费用记录、FIDW#争议账单）

### 供成熟产品关卡

- **协议：** 检查能否同时保存协议书、条件、五类附件、被纳入的要约文件及优先顺序，并追溯变更后的适用版本。（FIDW#协议文件组成）
- **履约义务：** 范本按服务范围与专业注意义务规定承诺；产品应能把范围、排除项、客户条件与成果关联，再由财务判断 OBJ-08 履约义务，不能把一个附件或付款节点直接视为一项履约义务。（FIDW#合同范围、FIDW#专业注意义务）
- **变更：** 检查通知、提案、费用与进度影响、批准及先行指令是否各有证据；未定价先行不得被界面自动处理为无偿工作。（FIDW#变更、FIDW#变更价款与先行指令）
- **全过程咨询服务范围：** 检查客户及第三方投入、接口责任、顺序、资料与决定日期、施工合同管理范围能否按具体委托填写；白皮书不提供一套适用于全部项目的必选服务清单。（FIDW#合同范围、FIDW#客户提供条件、FIDW#交付计划）

## 我们的取舍

- **建议采纳：按范围、客户提供条件、计价付款及进度四个方面核对协议完备度。** 理由：能把交付与收费追溯到具体约定，不预设新增对象或表。（FIDW#合同范围、FIDW#客户提供条件、FIDW#报酬与付款条件、FIDW#交付计划）
- **建议采纳：变更保留原因、通知、影响及批准链。** 理由：可区分业务识别、合同修改与实际执行；未定价先行如何适用本系统须另行待提议。（FIDW#变更、FIDW#变更价款与先行指令）
- **建议不采纳：把范本默认天数、许可撤回或责任分配写成本系统通用强制规则。** 理由：须结合实际协议及适用法律核实，范本不是本企业政策。（FIDW#通知与送达、FIDW#成果使用许可、FIDW#报酬与付款条件）
- **建议不采纳：把服务进度或账单发出直接当成收入确认。** 理由：范本规定合同权利义务，不替代本系统 ADR-0016、ADR-0047 及 ADR-0056 的会计与证据边界；改变既有口径属待提议。（FIDW#交付计划、FIDW#报酬与付款条件）
