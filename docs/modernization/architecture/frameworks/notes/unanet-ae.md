# Unanet AE 产品资料要点与本系统对照

本笔记保存本地培训资料可直接支持的产品语义，不构成采购、架构或业务口径决定。以下均为自行概括，短引：0 处。英文名称是来源称谓，不是 FORCITIS one 的新增正式术语。

## 核心思想

- **论断：Bill Terms 节点可位于项目顶层或汇总节点之下，人工记录落在叶节点，其他费用可另设归集层级。** 依据：UAE#项目计费节点、UAE#工作分解节点、UAE#工作分解记账粒度、UAE#计费金额与上限。含义：OBJ-29、OBJ-30 显式区分交付结构与计价用途，人工叶节点和费用粒度分别规定；项目节点不替代 OBJ-05 协议，Path 不作自有主键。
- **论断：岗位或费用需求可先于具名资源排期，预算可由需求和排期汇总，也可自上而下编制。** 依据：UAE#岗位及费用需求、UAE#具名资源安排、UAE#预算与基线变动、UAE#ETC及完成进度历史、UAE#基准费率与实际展示。含义：OBJ-32、OBJ-33、OBJ-44、OBJ-45 分别保留预算基线、剩余估算、未具名需求和具名安排；计划视图中的未提交或未批准工时另审展示口径，不混入已过账成本。
- **论断：商业账单先经 PM 与 PA 复核交接，再生成和过账，计费交易可追溯到销售分录。** 依据：UAE#商业账单复核、UAE#商业账单及销售分录、UAE#收款与核销分配。含义：PRC-57、PRC-59 核对复核后增量、明细防重及账单关联，并串联 OBJ-82、OBJ-85、OBJ-86 的请款和核销；商业账单与 OBJ-83 增值税发票分别处理。
- **论断：费率有有效期和父子覆盖，Net Days 参与到期日计算，税费还可按项目、人工和费用设置排除范围。** 依据：UAE#费率版本及覆盖、UAE#付款条件与送达地址、UAE#税费率及排除范围。含义：OBJ-26、OBJ-27、OBJ-123 留存版本、优先级及选用日期，OBJ-07 区分说明字段和到期日算法，OBJ-83、OBJ-124 的税务规则按本系统政策确认。
- **论断：分析模型可供多个看板共用，而看板内的局部查询和公式不自动成为共用定义。** 依据：UAE#数据来源与分析模型、UAE#看板与局部公式、UAE#看板分发与权限组。含义：模型、局部查询、局部公式、看板及分发权分别登记，正式财务指标沿统一口径和 reporting 契约，不把指标藏在局部表达式中，也不因产品支持 SQL 而允许分析直读业务表。

## 我们的取舍

以下全部为**已审定（one-architecture 2026-10-18，页码已抽查）**；不变更现行 FRAMEWORKS、ADR、对象图、流程目录或术语。

- 建议借鉴项目、需求、具名安排、预算、ETC 与实际的独立语义，以及按日／周／月排期和保存基线的可追溯关系；以现有 OBJ-29–45 的定义为约束，不移植产品节点树和编码。
- 建议优先审定 UAE#计费资格及复核增量待核、UAE#催收送达轨迹待核、UAE#账龄日期与应付查询待核、UAE#计费及付款中断恢复待核：它们直接关系重复计费、复核有效性、应收应付解释和付款重复执行；先补规则与关系，再决定实体和表。
- 建议借鉴商业账单复核与收付核销链；先分清税票、商业账单、应收、收入确认，不将 Billing 的完成百分比公式用作收入确认依据。
- 不建议采纳会计映射失败时自动记入 Error G/L（AR p8；BI p25）、允许无审计修改供应商／发票号（AP p10）、批量转移可绕开合同层级并把工时移到非叶节点（AD p45；BI p37）。这些产品行为与本系统失败告警、审计、更正及叶节点规则冲突。
