# 《企业会计准则第14号——收入》应用指南（2018）要点笔记

资料出处：公开资料（不进仓库）《〈企业会计准则第14号——收入〉应用指南2018》。题名、编写机构、年份据封面，版次及印次据版权页（PDF 1、3），出版社为中国财政经济出版社。以下自行概括，正文短引 0 处。仅作本地指定版本的条款与案例索引，不裁定具体协议的会计处理，不把书中案例假设当作本企业事实。新增阅读索引不是新增正式术语。

## 核心思想

- **论断：合同获批或形式上已签署仍不足以单独满足收入准则的合同识别条件。** 依据：CASG#合同成立条件。含义：建议 PRC-47 为 OBJ-05 留存批准、权利、支付条款、商业实质及收款可能性依据，VS-04.2 的收入准入不只看回签状态。
- **论断：重大整合、定制或高度关联会使多项活动形成一项组合产出，阶段数量不能直接决定履约义务数量。** 依据：CASG#履约义务、CASG#可明确区分。含义：建议 OBJ-06、OBJ-07 与 OBJ-08 分别关联并保存可区分性判断，不默认一阶段或一付款节点对应一项义务。
- **论断：服务具有不可替代用途时，仍须具有覆盖已完成部分成本及合理利润的收款权，才能据此支持时段履约。** 依据：CASG#时段履约、CASG#咨询服务收款权。含义：建议 OBJ-08 留存合同条件及 OBJ-53 证据；与 ADR-0016、ADR-0047、ADR-0056 的既有确认边界不一致处仍待提议。
- **论断：产出法须反映已转移给客户的服务价值，投入法也不能把不反映履约进度的成本机械计入。** 依据：CASG#产出法、CASG#投入法、CASG#履约进度。含义：PRC-53 与 VS-04.2 继续使用已批准方法及有效证据，OBJ-33 和 OBJ-32 不自动驱动收入，也不据指南开放投入法选项。
- **论断：新增服务的可区分性、单独售价及剩余服务与已交付服务的关系，决定合同变更的三种会计处理。** 依据：CASG#变更作为单独合同、CASG#变更终止后续处理、CASG#变更累积调整。含义：建议 OBJ-09 经 PRC-48 生效后分别记录商业变更与会计分类；会计上的终止重立不等于调用 PRC-68 或删除原协议。
- **论断：履约成本资本化须增加未来履约资源且可收回，普通投标支出不因后来中标就成为合同取得成本资产。** 依据：CASG#合同履约成本、CASG#合同取得成本、CASG#合同成本摊销。含义：建议 PRC-55、VS-10.0 追查成本性质、所服务义务及摊销基础，OBJ-66、OBJ-87 仅有成本发生依据还不够。
- **论断：已履约的收款权仍附其他履约条件时列合同资产，无条件收款权单列应收，履约前对价则按规定列合同负债。** 依据：CASG#合同资产、CASG#合同负债。含义：建议 OBJ-85、OBJ-07 与 OBJ-53 记录收款权条件，OBJ-83 和 PRC-57 不代替控制权判断，列报也不以未开票金额相减直接得出。

## 对本系统的启示

- **范围、付款与会计承诺分别建关联。** OBJ-05 协议、OBJ-06 合同范围条目、OBJ-07 付款条件项与 OBJ-08 履约义务各有含义。PRC-47 的回签不能代替合同成立的全部会计条件，VS-04.2 确认收入应能回溯财务对承诺与可区分性的判断；服务阶段数量不是义务数量的充分证据。（CASG#合同成立条件、CASG#履约义务、CASG#可明确区分）
- **变更批准与会计处理分别留痕。** OBJ-09 协议变更经 PRC-48 生效后，财务仍须识别三种会计情形并说明对价及剩余服务处理。会计视同终止原合同并不等于调用 PRC-68 终止协议，更不等于删除原协议。（CASG#变更作为单独合同、CASG#变更终止后续处理、CASG#变更累积调整）
- **按时段履约与按时点履约不能只凭行业名称选择。** OBJ-08 应有判据、相应合同条件与证据 OBJ-53；咨询案例说明收款权具有决定作用。现有设计成果时点确认及证据开放边界按 ADR-0016、ADR-0047、ADR-0056 执行，书中时段或投入法案例不直接改动本系统决定；不一致处待提议。（CASG#时段履约、CASG#咨询服务收款权、CASG#投入法）
- **进度值、对价、估计与实际费用分别解释。** OBJ-33 完工估算、OBJ-32 项目预算不能自动驱动收入；PRC-53 确认收入与 VS-04.2 应使用已批准方法及有效证据。新增费用、亏损或索赔也不能直接视为新增可收对价，须留存可变对价判断与更新依据。（CASG#履约进度、CASG#产出法、CASG#投入法、CASG#可变对价）
- **合同成本按可资本化条件核对。** 工时单 OBJ-66、供方履约确认 OBJ-87 可提供成本发生依据，但不能证明未来履约资源条件；PRC-55 结转合同履约成本和 VS-10.0 执行记账结转需能追查成本性质及所服务的义务。投标成本不可仅凭后来中标而整体资本化。（CASG#合同履约成本、CASG#合同取得成本、CASG#合同成本摊销）
- **列报与商业款项状态分别核对。** OBJ-85 往来款项、OBJ-07 付款条件项及 OBJ-53 证据应说明收款是否仍附履约条件；OBJ-83 增值税发票与 PRC-57 不决定控制权转移。合同资产及合同负债的列报不是把未开票金额相减即可得到。（CASG#合同资产、CASG#合同负债、CASG#交易价格）
- **总额、净额判断落实到特定服务。** PRC-70 的分包协议和 PRC-72 的供方履约可提供供应关系证据，但在有分包时仍需识别本方是否在转让前控制服务；管理口径净服务收入与会计总额、净额列示不是同一判断。（CASG#主要责任人与代理人）

### 供成熟产品关卡

- **协议：** 检查会计合同识别是否保留批准、权利、付款、商业实质与收款可能性依据；纸面签署、开票许可及收入准入应分别检查。（CASG#合同成立条件）
- **履约义务：** 检查范围条目能否多对一或按实际承诺关联义务，记录整合、定制和关联的判断，而非默认一阶段或一付款节点一项义务。（CASG#履约义务、CASG#可明确区分）
- **变更：** 检查范围获批未定价时的估计、三种会计分类与变更当期调整如何解释；不以商业终止状态冒充会计后续处理。（CASG#变更审批与对价暂估、CASG#变更作为单独合同、CASG#变更终止后续处理、CASG#变更累积调整）
- **全过程咨询服务范围：** 检查设计、管理、现场与持续咨询的服务组合是否逐项评估可区分性、收款权与控制权；指南没有给出一套全过程咨询的统一义务清单。（CASG#可明确区分、CASG#咨询服务收款权、CASG#时段履约）

### 供 one-rules 核对

- CASG#合同成立条件：核对回签以外的会计识别条件及其判断证据，不把形式状态当成完整准入结论。
- CASG#履约义务、CASG#可明确区分：核对阶段、范围、付款节点与会计履约义务之间的映射及重大整合服务判断。
- CASG#时段履约、CASG#咨询服务收款权：核对持续咨询及终止补偿权能否支持时段判断，与现有设计成果时点口径不一致时待提议。
- CASG#履约进度、CASG#产出法、CASG#投入法：核对进度证据是否反映控制权转移，保持现有批准口径，不开放投入法选项。
- CASG#变更审批与对价暂估：核对范围批准但价格未定的变更是否进入适当的对价估计与转回限制评估。
- CASG#变更作为单独合同、CASG#变更终止后续处理、CASG#变更累积调整：核对三类变更的判断输入、处理期间及原已确认金额的可追溯关系。
- CASG#交易价格、CASG#可变对价、CASG#价格分摊：核对不含税对价、折让、索赔及单独售价分配，不直接按合同标价或付款比例分摊。
- CASG#合同履约成本、CASG#合同取得成本、CASG#合同成本摊销：核对资本化条件、费用化边界及与相关收入一致的摊销基础。
- CASG#主要责任人与代理人：核对分包服务转让前控制权的证据，勿按有无分包直接选总额或净额。
- CASG#合同资产、CASG#合同负债：核对附条件与无条件收款权、履约前收款及开票对列报的不同影响。

## 我们的取舍

- **建议采纳：将指南的判断条件与案例作为规则核对索引。** 理由：能追问履约义务、收款权、变更分类、成本性质及列报的证据，仍由财务对具体交易形成判断。（CASG#可明确区分、CASG#时段履约、CASG#合同履约成本、CASG#合同资产）
- **建议采纳：商业变更与会计处理分类分别记录并关联。** 理由：同一次变更可能有不同会计后果，不宜用同一商业状态代替会计结论；改变现有对象或规则前仍须正式提议。（CASG#变更终止后续处理、CASG#变更累积调整）
- **建议不采纳：将指南允许的时段履约或投入法直接开放为本系统设计收入算法。** 理由：ADR-0016 的既有产出法口径及 ADR-0047、ADR-0056 的确认机制已采纳；存在适用性问题须待提议，本文不改决定。（CASG#时段履约、CASG#投入法）
- **建议不采纳：把预收、开票、工时耗用、协议价款或项目预算直接作为收入确认的充分条件。** 理由：这些分别涉及现金、结算、投入和估计，不自动证明履约或取得对价的权利。（CASG#合同成立条件、CASG#产出法、CASG#交易价格、CASG#合同负债）
- **建议不采纳：把案例中的税率、概率、金额与成本比例设为通用参数，或用累积调整覆盖已过账事实。** 理由：案例为说明判断而设定，实际更正仍受 ADR-0016 的追加及冲销边界约束；会计差额如何落开放期间须按既有规则核对。（CASG#变更累积调整、CASG#可变对价）
