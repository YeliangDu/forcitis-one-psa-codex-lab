# 建设工程设计合同示范文本（房屋建筑工程、专业建设工程）要点笔记

本笔记保存与 FORCITIS one 相关的阅读要点，不构成架构决定。正文自行概括，短引 0 处。资料均为公开资料（不进仓库），仅核对本地所给版本，未联网核验现行效力或产品现状。

资料简称：房建本、专业本分别指两部封面所载范本；两本均 45 页，所引印刷页与 PDF 物理页一致。阅读说明、通用条款和范围、支付附件。房建本适用范围与专业本互补，不能混为同一份通用模板。

## 核心思想

- **论断：设计合同的协议书、专用条款、通用条款等组成文件有优先顺序，同类文件以最新签署为准。** 依据：GFD#合同文件顺序。含义：OBJ-05 在 PRC-47、VS-04.1 中保留组成文件、专用约定及签署版本，产品须能回查有效约定。
- **论断：设计基本服务包含相应现场配合，超出约定现场服务时限的工作另付费，专业本还涉及试车考核。** 依据：GFD#基本服务与其他服务、GFD#施工配合边界。含义：OBJ-06 核对基本或其他服务及排除项，不能把交图当全部服务完结；组合其他咨询服务时仍须明确边界。
- **论断：设计文件交付须登记签收，审查有异议重新报审时期限重新起算。** 依据：GFD#交付签收、GFD#成果审查。含义：OBJ-35、OBJ-53 在 PRC-28 分别保存送达、签收、意见和认可日期，新成果版本关联重起审查期，不覆盖首次送达。
- **论断：设计合同附件分别列示阶段服务费用和付款安排，二者并非同一种分配结构。** 依据：GFD#阶段费用与付款。含义：OBJ-07、OBJ-08 分别核对付款条件和履约义务，不凭附件比例确定收入；VS-04.2、PRC-53 仍遵守现行会计决定，示例比例不作为全公司硬编码规则。
- **论断：设计变更可增加或减少工作，须评价价款与工期影响，并分别记录通知、声明和答复期限。** 依据：GFD#设计变更及索赔。含义：OBJ-40、OBJ-09、OBJ-10 经 PRC-31、PRC-48、PRC-49 和 VS-02、VS-04.6 分别追溯技术指示、承诺调整及价款工期请求，保留原因、送达与计算证据。

## 对本系统的启示

- 协议 OBJ-05 应能回溯组成文件、专用约定和相对方；合同范围条目 OBJ-06 记录基本或其他服务及排除项，支撑 PRC-47 起草并回签协议、VS-04.1 签署合同。（GFD#合同文件顺序、GFD#基本服务与其他服务）
- 交付物 OBJ-35、证据 OBJ-53 在 PRC-28 中分别保存送达、签收、意见与认可日期；审查期重起须关联新的成果版本，不能覆盖首次送达。（GFD#交付签收、GFD#成果审查）
- 付款条件项 OBJ-07 与履约义务 OBJ-08 分开核对：合同阶段分费和付款安排只提供识别输入，不能单凭附件比例确定会计义务或收入。对应 VS-04.2、PRC-53 的现行口径仍由已采纳 ADR 约束。（GFD#阶段费用与付款）
- 设计变更 OBJ-40、协议变更 OBJ-09、索赔 OBJ-10 分别追溯技术指示、承诺调整、价款工期请求；衔接 PRC-31、PRC-48、PRC-49 和 VS-02、VS-04.6，保留责任原因及通知证据。（GFD#设计变更及索赔）

### 供成熟产品关卡

- 协议：多组成文件及优先顺序，专用条款可细化通用条款；产品须能回查有效约定。（GFD#合同文件顺序）
- 履约义务：基本服务包括现场配合；阶段服务费用和付款节点有不同结构，须验证产品能否保持它们与会计识别结果的关系。（GFD#基本服务与其他服务、GFD#阶段费用与付款）
- 变更：减少工作量也能调价；通知、声明、答复与费用工期计算不能只留一个新金额。（GFD#设计变更及索赔）
- 全过程咨询服务范围：两本规定的是工程设计服务及配合，未覆盖全过程工程咨询全部单项服务；应允许与其他服务组合并明确边界。（GFD#施工配合边界）

## 我们的取舍

- **建议采纳：** 保存服务范围、价格、付款、交付及审查的独立记录与来源关系。理由：同一阶段不代表同一种业务事实。（GFD#阶段费用与付款）

- **建议采纳：** 将变更理由、送达日期、计算依据与答复关联到协议变更和索赔。理由：权利主张有证据及期限要求。（GFD#设计变更及索赔）

- **建议不采纳：** 把附件示例比例、定金预付比例或逾期视为同意直接硬编码为全公司规则。理由：范本允许专用约定，实际合同与现行规则须复核；若因此改变收入触发条件，属待提议，交 one-architecture 对照 ADR-0016、ADR-0047。（GFD#成果审查、GFD#阶段费用与付款）
