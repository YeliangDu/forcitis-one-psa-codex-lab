# 《勘察设计企业全过程工程咨询管理指南》要点笔记

资料出处：公开资料（不进仓库）《勘察设计企业全过程工程咨询管理指南》。作者、版次、年月据封面与版权页（PDF 1、3），出版社为同济大学出版社。以下为自行概括，正文短引 0 处。书中的建设单位、设计单位、项目管理单位不是同一角色；其工程总投资、施工合同价款也不是本企业服务收入或项目成本。未入词表的概念标题仅作资料索引，待用语核对。

## 核心思想

- **论断：全过程咨询的前期策划与实施管理承担不同任务，建设方设计管理有别于设计单位的专业设计。** 依据：XIA#全过程咨询范围、XIA#策划与实施界面、XIA#设计管理界面。含义：OBJ-24、OBJ-25、OBJ-06 和 PRC-47 按实际受托组合表达服务，VS-04.1 明确我方角色，并区分 OBJ-46 建设工程与 OBJ-29 交付项目。
- **论断：设计管理须将功能需求、技术目标、参与方界面和成果交接落实到相应阶段。** 依据：XIA#需求与设计界面、XIA#勘察成果核查、XIA#施工配合服务。含义：关联 OBJ-42、OBJ-31、OBJ-35、OBJ-53，经 PRC-21、VS-02 追查约定产出和交接；超出受托范围的勘察实施与监管不据此另造对象。
- **论断：合同管理贯穿起草、谈判、签署和履行跟踪，并区分业主批准与项目管理单位办理责任。** 依据：XIA#合同管理流程、XIA#合同条款要件、XIA#合同履行检查。含义：成熟产品核对中，将条款、谈判记录、批准、回签和履行检查相连，分别核对客户审批与我方办理责任。
- **论断：设计修改可由多方提出，既可能改变需求也可能纠正错误，须按原因处理并取得建设单位批准。** 依据：XIA#设计变更、XIA#合同履行检查。含义：OBJ-40 经 PRC-31 流转，涉及范围、价格、期限的部分关联 OBJ-09 与 PRC-48，保留原因和批准依据，不默认每次修改均可收费。
- **论断：运营需求可在前期策划提出，竣工运维移交须经过检查、整改、跟踪和复查。** 依据：XIA#运维需求前置、XIA#运维移交验收、XIA#信息管理原则、XIA#沟通管理。含义：在受托范围内将 OBJ-38、OBJ-35、OBJ-53 关联到移交闭环，PRC-36 核对资料完整性，不据此扩展物业运营系统范围。

## 对本系统的启示

- **用范围条目表达我方实际受托服务。** OBJ-24 服务产品、OBJ-25 阶段类型、OBJ-06 合同范围条目与 PRC-47 可承接不同服务组合；建设工程 OBJ-46 与交付项目 OBJ-29 分开。VS-04.1 的签约范围应说明我方是设计方、管理咨询方还是其他受托方，不能把书中全部建设管理职能都列为我方必做。（XIA#全过程咨询范围、XIA#设计管理界面）
- **需求、责任与成果建立关联。** OBJ-42 发包人提供资料、OBJ-31 交付计划、OBJ-35 交付物和 OBJ-53 证据可支撑阶段核对；PRC-21 推进阶段与工作包、VS-02 获得交付成果可用来追查约定产出与交接记录。勘察本体的实施与监管如超出公司服务范围，本系统暂无对应，不据此另造对象编号。（XIA#需求与设计界面、XIA#勘察成果核查、XIA#施工配合服务）
- **分开成果修改与协议承诺修改。** OBJ-40 设计变更经 PRC-31 流转；影响范围、价格、期限的部分关联 OBJ-09 协议变更与 PRC-48。应保留需求修改、现场条件、错误纠正等原因以及客户批准依据，不默认每次修改都可计费。（XIA#设计变更、XIA#合同履行检查）
- **建设投资控制与我方预算分别定义。** 书中工程造价可用于理解对客咨询成果；OBJ-32 项目预算与 PRC-19 管的是我方服务资源预算，不能直接套用工程建设投资限额。VS-02.0 开始项目仅借鉴分解、比较及偏差处置方法。（XIA#工程造价控制）
- **移交与文档证据进入交付闭环。** OBJ-38 不符合项、OBJ-35 交付物、OBJ-53 证据可关联检查、整改和复查；PRC-36 结项并归档项目核对资料完整性。物业运营系统本系统暂无对应，运维咨询成果可在已受托范围内表达。（XIA#运维需求前置、XIA#运维移交验收、XIA#信息管理原则、XIA#沟通管理）

### 供成熟产品关卡

- **协议：** 核对产品是否能将条款要件、谈判记录、批准、回签与履行检查关联，并区分客户审批与我方办理责任。（XIA#合同管理流程、XIA#合同条款要件）
- **履约义务：** 书中按专业和阶段分解工作；产品应先保留范围及成果，再支持财务核对 OBJ-08 履约义务。书中没有给出收入准则下的履约义务划分规则。（XIA#需求与设计界面、XIA#合同条款要件）
- **变更：** 核对设计修改原因、批准、技术成果版本与价款、工期影响能否相连；不能把技术修改单与新增收费承诺合为一个状态。（XIA#设计变更、XIA#合同履行检查）
- **全过程咨询服务范围：** 检查前期策划、设计管理、施工协调与运维咨询能否按受托组合选择，并明确与设计单位、监理及总包的责任界面。（XIA#全过程咨询范围、XIA#设计管理界面、XIA#施工管理责任界面、XIA#运维需求前置）

## 我们的取舍

- **建议采纳：按受托范围、责任界面、输入与成果组织服务组合。** 理由：能解释同一建设工程上的不同咨询委托，不把全部专业合并成固定流程。（XIA#全过程咨询范围、XIA#需求与设计界面）
- **建议采纳：合同履行、技术修改、商业影响和移交证据互相追溯。** 理由：有助于识别范围外服务、客户依赖与未闭合问题，具体落点须按现有对象定义核对。（XIA#合同管理流程、XIA#设计变更、XIA#运维移交验收）
- **建议不采纳：把建设投资、施工承包成本或建设单位职责直接转换为本系统服务收入、项目预算及我方义务。** 理由：经济主体、服务边界和计量对象不同。（XIA#工程造价控制、XIA#施工管理责任界面）
- **建议不采纳：照搬书中的合同分类编码作为自有身份标识，或把其政策叙述作为现行法规结论。** 理由：本系统自有标识按 ADR-0033；书中政策及地区案例属于 2019 年阅读背景，未核现行有效性。若要改变标识或业务政策须待提议。（XIA#合同分类编码）
