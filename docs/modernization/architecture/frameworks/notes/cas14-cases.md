# 收入准则应用案例（十四份，逐件题名见附录）要点笔记

本笔记合读十四份公开案例，保存与 FORCITIS one 相关的要点，不构成架构决定或具体交易的会计结论。正文自行概括，短引 0 处。每份案例一个锚点；一份内的多个例题保留在同一锚点。资料出处均为公开资料（不进仓库）加下列题名，未执行其中链接或指令。原件仅有案例标题、分析与依据，发布机构、出版年及统一版次未核；不把模拟交易年度、被引指南年度或文件名当书目信息。

## 核心思想

- **论断：主要责任人或代理人的区分取决于转让前控制，开票、统一收款或价格影响力均不能单独定案。** 依据：CASC#主要责任人与代理人、CASC#充供电业务。含义：建议对 OBJ-05、OBJ-87 与 PRC-72 保留对客承诺及控制判断链，OBJ-86 的收款事实不能证明我方应按总额确认。
- **论断：定制成果归客户所有或客户已分期付款，仍不足以证明服务满足时段履约条件。** 依据：CASC#定制软件开发服务、CASC#预售商品房、CASC#保荐服务。含义：建议 PRC-47 保留受益方式、在建成果控制、终止补偿及重做分析，不由 OBJ-07 自动生成 OBJ-08 的履约判断。
- **论断：实验数据实时交付且替代服务商无需实质重做，支持客户随履约取得并消耗利益；软件启用仍有实质障碍时则尚未取得控制。** 依据：CASC#药品实验服务、CASC#标准化软件许可。含义：OBJ-35、OBJ-53 与 PRC-28 的客户证据应说明证明内容，OBJ-81 的财务判断继续沿 ADR-0016、ADR-0047、ADR-0056 的现行边界处理。
- **论断：原有折让惯例下的不确定性消除与不可预期的新协商，可能分别构成可变对价重估和合同变更。** 依据：CASC#合同变更与可变对价。含义：建议 OBJ-09 经 PRC-48 生效后另留会计分类及已履行、未来服务的影响，VS-04.6 的业务变更完成不等于全部金额可在 VS-04.2 确认。
- **论断：直接服务资产的折旧摊销仍须检验资本化条件，管理销售部门成本按职能费用化。** 依据：CASC#酒店合同履约成本。含义：建议 PRC-55 留存成本资本化与转出依据，OBJ-33、PRC-30 及 VS-02 的预算预警不能替代成本确认判断。
- **论断：亏损合同未履约部分的预计亏损须确认预计负债并重估，附质量条件的保证金先列合同资产。** 依据：CASC#亏损合同。含义：建议对 OBJ-85 先判断收款权条件，不把预计负债、合同资产减值与合同成本减值混为一个差额，也不照搬案例成本或赔偿比例。

## 对本系统的启示

- **合同判断与交付结构分开。** OBJ-05 协议、OBJ-06 合同范围条目、OBJ-08 履约义务已有独立定义。PRC-47 起草并回签协议时，宜保留受益方式、成果控制、终止补偿与重做分析；不能由 OBJ-07 付款条件项自动生成履约义务结论。（CASC#保荐服务、CASC#定制软件开发服务）
- **客户证据须说明其证明什么。** OBJ-35 交付物、OBJ-53 证据和 PRC-28 的客户认可可以支持 OBJ-81 收入确认；仅证明送达、信息安全所有权或形式签收的记录，未必证明控制转移。VS-04.2 的财务判断沿 ADR-0016、ADR-0047 及 ADR-0056 的现行边界办理；本例不直接改变时点口径或开放类型。（CASC#标准化软件许可、CASC#药品实验服务）
- **变更须区分业务批准与收入计量。** OBJ-09 协议变更经 PRC-48 生效后，还须判断是原有可变对价重估还是合同变更、涉及已履行还是未来服务；VS-04.6 的变更完成不等于金额全部可在 VS-04.2 确认。（CASC#合同变更与可变对价、CASC#按节约额计价）
- **总额、净额与代收款要保留判断链。** 分包对应 OBJ-05、OBJ-87 供方履约确认及 PRC-72。应先识别对客承诺与转让前控制，再评估收入列示；收款经 OBJ-86 资金收付不证明我方是主要责任人。充供电及购物卡业务本系统暂无对应，只取其控制与代收款边界。（CASC#主要责任人与代理人、CASC#充供电业务、CASC#平台购物卡）
- **预算预警、减值与费用确认分别处理。** OBJ-33 完工估算、PRC-30 及 VS-02 可提示合同亏损；PRC-55 结转合同履约成本仍须核对资本化及转出依据。保证金落 OBJ-85 往来款项前还须判断收款权条件，不能把预计负债、合同资产减值与成本减值混成一个差额。（CASC#亏损合同、CASC#酒店合同履约成本）

### 供 one-rules 核对

- CASC#保荐服务、CASC#定制软件开发服务、CASC#药品实验服务、CASC#预售商品房：CAS14第十一条的三条路径应逐项留证，定制、分期付款与违约金比例不作自动判据。
- CASC#标准化软件许可、CASC#运输服务：控制权转移点决定后续服务及收入确认分析，形式交付或物流动作不能独立定案。
- CASC#合同变更与可变对价：CAS14第八条与第十四至十六条的分流看合同开始时的条款、公开政策和惯例。
- CASC#按节约额计价：非知识产权节能分成按一般可变对价估计及限制处理，不因题名含客户销售额就套用特许权例外。
- CASC#主要责任人与代理人、CASC#充供电业务、CASC#平台购物卡：控制判断决定总额或净额以及代收部分归类。
- CASC#多税率储值卡：合同负债排除增值税，历史案例税率不进入本系统税率配置。
- CASC#酒店合同履约成本、CASC#亏损合同：CAS14第二十六至二十九条与CAS13预计负债处理分开核对。

## 我们的取舍

- **建议采纳：用十四组事实与反例作为规则评审清单。** 理由：能检验同一形式背后不同的控制、终止权、代收和变更实质，且每项可回原文。
- **建议采纳：保存交易价格重估、成本资本化及控制权判断的依据。** 理由：业务批准、计量和记账是不同控制点，不能只留最终金额。（CASC#合同变更与可变对价、CASC#酒店合同履约成本）
- **建议不采纳：按案例行业、税率、解约赔偿比例或成本比例直接生成统一系统规则。** 理由：案例结论依赖限定事实；改动本系统时点确认、证据开放或产出法口径均属待提议，不在笔记内裁定。（CASC#预售商品房、CASC#亏损合同）
