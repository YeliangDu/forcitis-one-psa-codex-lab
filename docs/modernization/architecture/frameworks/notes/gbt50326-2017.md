# 建设工程项目管理规范要点笔记

本笔记保存与 FORCITIS one 相关的阅读要点，不构成架构决定。正文自行概括，短引 0 处。资料均为公开资料（不进仓库），仅核对本地所给版本，未联网核验现行效力或产品现状。

## 核心思想

- **论断：WBS 终端工作单元须说明范围、质量、费用、时间、资源和职责，并管理工作界面。** 依据：PMGB#范围与工作单元。含义：OBJ-30、OBJ-31、OBJ-32 在 PRC-18、PRC-19、PRC-21 和 VS-02.0 中关联范围、接口、资源与质量要求，不能只存层级树。
- **论断：项目参与方的授权及职责应书面明确，进度计划须把合同、规划与资源约束转为控制性和作业性安排。** 依据：PMGB#项目授权责任、PMGB#进度计划依据。含义：核对项目资料中的授权、计划与目标是否衔接，不把施工单位项目经理的约束外推到所有专业服务人员。
- **论断：资源管理从需求、状态分析延续到供给、配置、使用控制和改进，需求与配置是不同环节。** 依据：PMGB#资源管理程序。含义：OBJ-44 与 OBJ-45 在 PRC-20、VS-02 中分别表达所需和安排，工程材料机具等内容不自动扩为本系统模块。
- **论断：风险管理包含识别、评估、应对和监控，风险计划调整须经授权批准，质量计划须与合同标准及资源过程协调。** 依据：PMGB#项目风险程序、PMGB#项目质量计划。含义：OBJ-108、OBJ-37、OBJ-38 在 PRC-27、PRC-28、PRC-34 中保留责任和证据，不能用看板颜色替代评估。
- **论断：项目收尾分别处理验收、结算、档案和责任期，管理绩效评价须结合过程与结果并对照目标。** 依据：PMGB#项目收尾、PMGB#管理绩效评价。含义：PRC-36、PRC-38、PRC-66 与 OBJ-107、OBJ-05 分别核对工程、合同及管理收尾，VS-02.7 不代表客户工程竣工结算全部完成。

## 对本系统的启示

- WBS 节点 OBJ-30、交付计划 OBJ-31、项目预算 OBJ-32 在 PRC-18、PRC-19、PRC-21 与 VS-02.0 中需关联范围、接口、资源和质量要求，不能只保存层级树。（PMGB#范围与工作单元、PMGB#进度计划依据）
- 资源需求 OBJ-44 与资源分配 OBJ-45 在 PRC-20、VS-02 中分别代表所需与安排；本标准列的工程材料机具等资源超出我方人员安排的常见场景，不能由此自动增加模块。（PMGB#资源管理程序）
- 项目风险与问题 OBJ-108、内部评审 OBJ-37、不符合项 OBJ-38 对应 PRC-27、PRC-28、PRC-34；风险计划与质量计划需要责任和证据，不能靠看板颜色代替评估。（PMGB#项目风险程序、PMGB#项目质量计划）
- PRC-36、PRC-38、PRC-66 与项目复盘 OBJ-107、协议 OBJ-05 对照工程、合同、管理不同收尾；VS-02.7 不等于客户建设工程竣工结算全部完成。（PMGB#项目收尾、PMGB#管理绩效评价）

## 我们的取舍

- **建议采纳：** 用工作单元、计划、授权及目标检查项目资料完整性。理由：它们连接承诺与实施，但无需每个章节新建独立对象。（PMGB#范围与工作单元、PMGB#策划成果层次）

- **建议不采纳：** 把施工单位项目管理约束和工程现场全资源管理原样设为所有专业服务项目规则。理由：参与方、授权和服务范围不同。（PMGB#项目授权责任、PMGB#资源管理程序）
