# 收入准则实施问答（五则）要点笔记

本笔记合读五份财政部会计司页面的问答正文，不构成架构决定。正文自行概括，短引0处。出处为公开资料（不进仓库）加附录题名；不跟随页面导航、附件或分享指令。页内固定导航日期不作发布日期，信息栏取正文下的发布日期。HTML没有页码，两页码列均为「—」。五问仅覆盖八个可分辨规则点，不为凑每页八条而扩写不存在的条款。

## 核心思想

- **论断：合同资产减值计入资产减值损失并形成减值准备，转回时作相反分录。** 依据：CASQ#合同资产减值计提、CASQ#合同资产减值转回。含义：建议 （提议补阶段：合同资产减值评估）、（提议补阶段：应收款项信用减值评估）区分合同资产与应收款项的准备、损益及转回记录，科目映射仍经 OBJ-95、PRC-93 处理，不在业务模块写死科目。
- **论断：给予客户的现金折扣按可变对价处理，不能一律把提前付款的差额列作财务费用。** 依据：CASQ#现金折扣。含义：建议 OBJ-05、OBJ-07 留存折扣条件，交 PRC-53、PRC-60 核对估计与实际差异，不让折扣只在到账差额中消失。
- **论断：不构成单项履约义务的运输，其已资本化成本按相关收入同一基础摊销，并在利润表营业成本列示。** 依据：CASQ#履约成本摊销基础、CASQ#履约成本列报。含义：建议 PRC-55 与 VS-10.2 分别验收成本转出及列报，追溯对应收入、成本类别和 OBJ-99 的报表行映射，不据此把全部项目支出资本化。
- **论断：尚待履约的已收或应收对价使用合同负债，其中增值税不满足合同负债定义。** 依据：CASQ#合同负债、CASQ#合同负债税额排除。含义：OBJ-86 与 OBJ-83 分别记录资金及税务事实，收入、合同负债和税额分开，VS-04.2 与 VS-04.4 不合并为同一触发点。
- **论断：首次执行收入准则新产生的预期信用损失调整期初留存收益，不追溯调整可比期间。** 依据：CASQ#首次执行信用损失。含义：PRC-167 可引用初始确认依据，但本系统启用是否属于企业首次执行须交财务核实，不能直接据此生成迁入指令。

## 对本系统的启示

- **分开减值对象与损益映射。** OBJ-81 收入确认及 OBJ-85 往来款项覆盖收入和无条件收款权；（VS-04.2；提议补阶段：合同资产减值评估）、VS-04.4 分别涉及收入更正减值和坏账。宜把合同资产与应收款项的准备、损益、转回记录区分；会计映射经 OBJ-95 会计科目、PRC-93 生成会计分录处理，不在业务模块写死科目。（CASQ#合同资产减值计提、CASQ#合同资产减值转回）
- **现金折扣须进入价格证据链。** OBJ-05 协议、OBJ-07 付款条件项应记录提前付款折扣条件，并交 PRC-53 确认收入和 PRC-60 收款核销核对估计与实际差异；折扣不能只在到账差额中消失。（CASQ#现金折扣）
- **成本转出与利润表映射各自验收。** PRC-55 结转合同履约成本和 VS-04.2 的结转结果应能追至对应收入及成本类别；OBJ-99 报表行定义把损益科目映到营业成本。问答不支持所有项目支出一概资本化，运输活动本系统暂无独立对应。（CASQ#履约成本摊销基础、CASQ#履约成本列报）
- **收款事实不直接生成收入。** OBJ-86 资金收付与 OBJ-83 增值税发票分别记录到账和税务事实；收入、合同负债与税额按实质分离，VS-04.2 与 VS-04.4 不合并为一个触发点。（CASQ#合同负债、CASQ#合同负债税额排除）
- **保留首次执行与软件启用的差别。** PRC-167 编制并签字确认期初余额可引用初始确认依据，但本问答不能证明 FORCITIS one 本次启用即企业首次执行新准则；是否适用交财务核实。（CASQ#首次执行信用损失）

### 供 one-rules 核对

- CASQ#合同资产减值计提、CASQ#合同资产减值转回：核对合同资产减值准备与资产减值损失的计提、转回映射。
- CASQ#现金折扣：把客户现金折扣放入可变对价评估与重估规则。
- CASQ#履约成本摊销基础、CASQ#履约成本列报：相关成本随对应收入摊销，利润表列营业成本。
- CASQ#合同负债、CASQ#合同负债税额排除：先收对价的待履约部分与增值税拆开。
- CASQ#首次执行信用损失：仅在企业首次执行该准则的条件成立时适用期初留存收益转换规则。

## 我们的取舍

- **建议采纳：将五问转成科目映射、含税拆分、价格重估与成本列报核对项。** 理由：问答给出窄而明确的口径，适合 one-rules 逐项对照，映射位置仍遵守 ADR-0016。
- **建议不采纳：以问答替代完整的合同成立、资本化或减值模型判断。** 理由：问答均有前提，未给出折扣估计方法的全部条件或信用损失参数。（CASQ#现金折扣、CASQ#合同资产减值计提）
- **建议不采纳：把首次执行调整直接用作本系统迁入指令。** 理由：企业是否首次执行未核，须先确认适用条件；若涉及已采纳切换或期间规则则为待提议。（CASQ#首次执行信用损失）
