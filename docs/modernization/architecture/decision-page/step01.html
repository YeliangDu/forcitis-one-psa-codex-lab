0 愿景：8 个目标、16 个 KPI

驱动力（为什么要做）
  • 技术栈全线过保与公网可利用的安全缺陷
  • 权责发生制业财一体是业务核心
  • 权责事实分散在老系统与 OA 两处
  • 财务总账与三大报表要由新系统直接产出
  • 现有经营分析不满足经营管理需要
  • 避免按旧系统架构直接现代化
01 权责业务事实只在新系统产生

合同、交付与收入确认、工时与成本、费用、开票与应收、回款、分包与应付、付款、薪酬等权责事实的记录系统一律是 FORCITIS one，A8 不再是这些事实的产生地或存放地，U8C 只接收新系统推送的结果；每类事实在会计期间边界一次切换，不设双源期。

KPI：

  • OA 迁入模板停用率
  • 切换后 A8 凭证插件新增凭证行数
  • 权责事实遗留类别数
02 业务事实一次过账、事实只追加、期间受控

触账的业务只提交类型化的过账候选，由单一过账管道校验（期间开放、借贷平衡、幂等、法人一致）并分配序号；更正只能冲销，关账后的更正落在开放期间；业务模块不认识会计科目。

KPI：

  • 经单一过账管道入账的权责事实占比
  • 月结对账等式差异数
03 新系统直接出权责口径三大报表

五家法人（1001、1002、1003、1006、1007）每月由新系统出权责口径的资产负债表、利润表、现金流量表；收付口径账簿（法定账）与 U8C 收付账套按 法人 × 科目 对账一致；条件成熟后年度切换法定账。

KPI：

  • 权责口径三大报表按月产出率 → M-35、M-36
  • 与 U8C 收付账套对账差异数
04 经营指标一个定义、一套口径

每个经营指标只有一个定义，定义放在口径版本中，报表、导出、AI 只经语义层取数；指标按 OAT 声明（原语、单位、期间类型、加总规则、含税、核算基础）。

KPI：

  • 指标目录 OAT 声明完整率 → M-01..M-48
  • 同一指标的并存算法数 → M-13、M-42、M-08
05 经营管理能回答「上月末是多少」，且经营结果与财务结果可勾稽

应收、在手合同（剩余履约义务）、合同资产等存量指标随关账生成期间快照；经营口径与法定口径的差异由口径差异清单逐期勾稽。

KPI：

  • 关账期间快照覆盖率 → M-06、M-13、M-17
  • 口径差异清单逐期勾稽完成率 → M-35
06 经营管理可见权责口径成本与毛利

项目、BU 层面可得权责口径的成本与贡献毛利（OAT 的 CM 及其变体），经营利润口径统一，取代老 BI 中「产值减当期全部费用」等混用算法。

KPI：

  • 项目贡献毛利可得覆盖率 → M-29、M-30、M-32
  • 贡献毛利率 → M-29、M-08
07 老系统在持续运行中按阶段切换并下线

迁移期间老系统持续运行，行为功能复刻但现代化；按 BC 绞杀式切换，老系统与 A8 之间的数据通道逐阶段下线；老 BI 在切换期不中断（过渡镜像）。

KPI：

  • 老系统与 A8 数据通道下线数
  • 过渡镜像对账通过率
08 新系统不带入老系统的安全缺陷

新系统的鉴权、会话、敏感信息处理按安全不变量建设，不信任老系统令牌，数据范围默认拒绝。

KPI：

  • 安全不变量满足数

获取并认识客户，把线索转化为经评估、已报价的商机。

  • 线索与商机跟进
  • 商机评估
  • 报价编制与承诺
合同管理 6

把客户承诺固化为可执行、可计量的合同基线，并管理其后续变化。

  • 合同基线管理
  • 框架协议与任务订单管理
  • 合同变更与签证索赔管理
  • 合同完备度检查
  • 无合同交付授权
  • 竣工结算
项目交付管理 6

把合同转化为可计划、可执行、可验收的项目交付。

  • 项目立项

  • 项目预算与完工估算
  • 交付成果验收

资源与工时管理 4

  • 利用率与产能监控

商机到签约 5

为客户（拟签约的项目业主）：线索已获取 → 合同已签署且合同基线已生效

  1. 线索与商机建立 → 商机已建立
  2. 商机评估 → 商机评估结论已作出
  3. 报价与承诺 → 报价已承诺给客户
  4. 签约前先行投入授权 → 风险交付已转正或已叫停
  5. 合同签订 → 合同已签署且基线版本已生效
签约到交付验收 8

为客户（项目业主）：合同基线已生效 → 客户已验收交付成果且项目已结项

  1. 项目立项 → 项目已立项
  2. 计划与预算编制 → 计划基线与项目预算已批准并锁定
  3. 交付执行与工时填报 → 工时已提交
  4. 工时审核与有效性认定 → 工时已审核通过且成本与计费金额已生成
  5. 范围变更处理 → 变更已批准且合同基线已修订
  6. 质量与返工处理 → 质量问题已关闭
  7. 成果验收 → 客户验收已登记
  8. 项目结项 → 项目已结项
验收到收入确认与开票 6

为客户（项目业主，收票方）：客户验收已登记 → 收入已确认且发票已开具

  1. 收入确认 → 收入已确认且合同资产已形成
  2. 计时账单编制 → 期间账单已生成
  3. 开票申请与准入 → 开票申请已准入
  4. 发票开具 → 发票已开具且应收已形成
  5. 收入更正与减值 → 更正已冲销入账
  6. 竣工结算 → 交易价格已最终确定
开票到回款 5

为公司（财务与经营管理层）：发票已开具 → 应收已结清或已核销

  1. 应收确立与账龄监控 → 应收已登记并纳入账龄监控
  2. 催收与回款计划 → 回款计划已确认
  3. 回款认领与核销 → 应收已核销
  4. 减值与坏账处理 → 减值已计提或坏账已核销
  5. 质量保证金返还 → 质量保证金已收回
支出到付款 8

为员工；供应商与分包商：费用已发生或采购需求已提出 → 款项已支付且费用或应付已入账

  1. 费用事前申请与备案 → 申请已备案
  2. 供应商准入 → 供应商档案已生效
  3. 采购与分包立项 → 采购合同或分包合同已签订
  4. 分包交付与应付确认 → 分包成本与应付已入账
  5. 费用报销 → 报销单已批准并入账
  6. 员工借还款 → 借款已发放或已还款核销
  7. 付款申请与批准 → 付款申请已批准
  8. 付款执行与银行核对 → 款项已支付并与银行流水匹配
员工入职到离职 6

为员工：用人申请已提交 → 员工已离职、交接已完成且账号已停用

  1. 用人申请与招聘 → 录用已批准
  2. 入职与账号开通 → 员工档案已建立且账号已开通
  3. 考勤与休假 → 月度考勤已确认
  4. 绩效评定 → 月度评估已完成
  5. 薪酬核算与发放 → 薪酬已发放且职工薪酬事实已入账
  6. 异动、离职与交接 → 异动或离职已生效、交接已完成且账号已停用
期末核算到经营报告 7

为经营管理层与财务：会计期间已结束 → 期间已关账，三大报表与经营月报已发布

  1. 成本归集与分摊 → 成本已归集并分摊
  2. 成本预提与结转 → 成本结转批次已过账
  3. 关账前置检查与勾稽 → 关账前置检查已通过且对账等式成立
  4. 凭证与期末结转 → 期末凭证已过账
  5. 期间关账 → 期间已关账且期间快照已冻结
  6. 财务报表编制 → 三大报表已出具
  7. 经营分析发布 → 经营月报已发布
经营计划到复盘 4

为经营管理层：经营计划周期已开始 → 偏差已解释且经营动作已确定

  1. 目标与计划编制 → 经营计划与计划基线已批准
  2. 承诺目标与预测 → 承诺目标已确认且滚动预测已提交
  3. 预算编制与额度管控 → 预算基线已生效
  4. 经营复盘与偏差解释 → 偏差已解释且经营动作已确定
