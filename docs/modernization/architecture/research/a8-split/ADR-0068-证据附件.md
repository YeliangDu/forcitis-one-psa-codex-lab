## 守护规则明细


1. **人事命令**：守护以下行为——
   - 重放幂等、未来生效作业的执行与告警；
   - 补登早于版本时拒绝；
   - 同一员工同一生效日只有一条待生效命令、离职之后不得再录更晚命令、按生效日顺序执行；
   - 只追加触发器。
2. **待放行离职**：守护以下行为——
   - 单条放行、不重跑；
   - 剩余超管数分别为 2、1、0 时的行为；
   - 运维命令缺见证人时拒绝；
   - 无 CASCADE、关闭只能一次；
   - C 的预检与 D2 的断言。
3. **F-1**：两套键各自去重；列与 `origin_kind` 的绑定 CHECK。
4. **封存**：封存后对 INSERT、UPDATE 的负向测试；封存表不可改；有 `PENDING` 对照时拒绝封存。
5. **登记与目录**：`DataArchitectureTest`、`DdlNamingTest`、事件目录、MUST_AUDIT、system-actors 随卡更新。删除 `EmergencyLoginIntegrationTest:209` 的断言（D1）须在 PR 中单列理由；其余断言不放宽。
