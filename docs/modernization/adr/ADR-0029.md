- **理由**：按岗位授权须以新的岗位体系为对象，老系统现有岗位不作对照。重启条件：岗位体系重梳完成（职位目录与按职位授权规则经用户确认）。

## 背景

要决定的是：非敏感权限能否按岗位成批授予，敏感权限仍逐人授予（ADR-0032）。初稿见 PR #96（未合入）。看到老系统岗位取证后，用户决定公司重新梳理岗位体系，本 ADR 不按老系统现有岗位建对照，以岗位体系重梳为前置。正文待重启后按新格式重写。
