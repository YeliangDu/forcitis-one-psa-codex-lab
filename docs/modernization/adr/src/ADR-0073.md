## 背景

用户在 ADR-0071 批准页上批准两张后续卡（intent 2026-10-21-131235）：ARC-1021-COO-07 组织单元调整属性命令，ARC-1021-COO-08 员工与组织单元的法人归属维护命令；并要求命令契约写清生效日、成本归集读当时值还是当前值、法人归属变更须财务会签。ADR-0068 第 1、4 条的命令种类清单未含这两类，本篇补上。

## 决定

### 1. 读取口径：一律读当时值

成本归集、交付单元判定、权限范围（法人 × 部门）与单据归属，按业务事实的业务日期读当日有效的版本（当时值），不读当前值。改属性或改法人归属只影响生效日及以后的事实，历史成本与已过账结果不重算。依据：SESSION_PLAYBOOK §14.1 D6（会被分析或授权按日期引用的维度有生效区间，变化只追加新版本）、D15「不追溯」、ADR-0016 已关账期间不改。读取方须在契约中声明按日期取版本，守护检查不得按「当前」读取这些维度。

### 2. 调整组织属性（COO07）

1. `org_structure_commands` 增种类调整属性 `SET_ATTRIBUTES`（暂名），只用于组织单元，改总部 / 区域 `region_kind` 与是否交付单元 `is_delivery_unit`，至少改一项，其余内容列为空；沿用新建命令已有的 `target_region_kind`、`target_is_delivery_unit` 两列，放宽「只随新建」的 CHECK 为「新建或调整属性」。
2. **生效日**：不早于登记日；未来生效的为待生效，到日不依赖作业（ADR-0068 A68：读生效日 ≤ 今天的版本）。改过去的属性不走本命令。
3. 登记即写 `org_unit_versions` 新版本（`change_org_structure_command_id` 指本命令），可撤回规则同其他组织命令。
4. 权限：组织数据管理员登记，权限码按 G43 定。

### 3. 法人归属（COO08）

1. **复用区间表**：员工法人归属写 `employee_legal_entities`，组织单元法人归属写 `org_unit_legal_entities`（W2 设计第 3.6 节），不另起模块或聚合。
2. **种类**：人事命令增变更法人归属 `CHANGE_LEGAL_ENTITY`（暂名，目标列 `target_legal_entity_id`）；组织结构命令增指定法人 `ASSIGN_LEGAL_ENTITY`（暂名，只用于组织单元，目标列 `target_legal_entity_id`）。目标法人须在 ADR-0022 的五家之内。
3. **财务会签**（用户要求）：这两种命令由人事或组织数据管理员起草后处于待会签 `AWAITING_COUNTERSIGN`（暂名），财务负责人会签后才登记生效并写归属版本；会签人不得为起草人（具名 CHECK）。会签列（会签人、会签时刻、会签审计记录 ID）只能由空变非空一次。会签权限码按 G43 定，授财务负责人。未会签的可由起草人撤回。
4. **生效日**：不早于会签日（不追溯）；同一主体同一生效日只有一条未生效的归属命令。
5. **更正**：归属录错的更正同样须财务会签；更正走 W2 统一的作废机制（RULE-416），不再新写覆盖表。
6. 法人归属变更后，按第 1 条只影响生效日及以后：权限范围、单据归属、成本归集按当时值读取。

### 4. 表结构

上述增列、增种类、增状态与会签列由 one-data 在 ADR-0068 附件 DDL 基础上签发（W2 第 3.6 节同步）；种类 CHECK 与目标列 CHECK 按 ADR-0068 附件同法写成「种类决定哪些目标列非空」。

## 影响面

- `organization.workforce`：两张命令表增种类、状态、会签；归属区间表接入命令；会签界面与权限。
- 读取方（成本归集、交付单元判定、数据范围、单据归属）：按业务日期读版本。
- 事件：新增属性已调整、法人归属已变更两类事件（名称交 one-glossary），F-1 是否订阅由其卡判定。
- one-data：DDL 签发；one-glossary：种类与状态用语。

## 迁移方案

1. W2 与 ADR-0068 的命令表同批实现；采纳时同一提交在 ADR-0068 头部「被部分取代」列本篇。
2. 迁入的归属区间仍为 `MIGRATION` 行，不经会签，按 ADR-0071 质量检查。

## 回滚方案

种类未上线前，两类变化只能由迁入数据表达，属性与归属在投产后不可改；不得以直接改库代替命令。

## 需同步修改的守护规则

1. 集成测试：调整属性只改两列；法人归属命令未会签不写版本、会签人等于起草人被拒、生效日早于会签日被拒、目标法人超出范围被拒。
2. 读取守护：成本归集与数据范围对组织属性、法人归属的读取都带业务日期参数。
3. 不放宽、不删除现有断言。

## 后果

- 组织属性与法人归属在投产后有维护入口，且历史成本不因改动而重算。
- 法人归属多一步财务会签，变更周期变长；换来财务口径不被单方改动。
