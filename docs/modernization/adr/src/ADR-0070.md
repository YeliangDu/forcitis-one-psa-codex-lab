# ADR-0070：恶意文件检测：自建 ClamAV 的检测流程与宏文档防护（ADR-0060 补篇）

- **状态**：提议
- **日期**：2026-10-21
- **档位**：正式
- **起草**：one-architecture
- **类别**：安全与权限
- **BC**：
  - 全局
- **阶段**：
  - W0
- **取代**：
  - ADR-0060 决定 5 第 1 条（部分：临时区先于检测）
  - ADR-0062 决定 1 第 1 条（部分：含宏文件不预览）

## 背景

ADR-0060 定了「每个文件检测、未通过隔离、检测不可用即不放行」，选型留待用户同意（ADR-0060:114、129）。用户在 PR #494 评论 6311040189 选定自建 ClamAV（clamd），W0 内建成，不询价、不建账号、不调用云服务，并给出 8 条建成判据与两条提醒（intent `2026-10-21-100709`）。其中第 7 条要求把已知取舍写进 ADR-0060 补篇；运维侧实施卡为 OPS-1021-OPS-02（分支 claude/one-ops-r56 `phase1a/cards/OPS-1021-OPS-02-clamav.md`）。

与 ADR-0060 的结构冲突：ADR-0060 决定 5 第 1 条的流程是「写入临时区（对象存储前缀）→ 检测」，临时区在对象存储里；而用户判据 1 要求 `SCAN` 扫本地路径、不用 `INSTREAM`，提醒 1 要求「临时区不能有任何预签名 URL 或外部可读路径」。对象存储里的未检文件同时违背两条，所以本篇把检测前移到本地检测暂存，部分取代该条。

## 决定

### 1. 选型

1. 检测引擎为自建 ClamAV（clamd），检测适配器在 `platform.integration`，以本系统用语的端口供文件服务调用（ADR-0060 决定 2 第 3 条不变）。
2. 不选：云安全中心 SDK（文件原文出境到第三方）；对象存储内置检测作拦截闸（事后扫描，违 ADR-0060「通过前不可关联」）。
3. **升级路径**：商业引擎现在不选型、不询价。触发条件为安全评审要求更高检出率，或出现首例漏检或绕过事件；负责人 one-ops，带询价报用户（许可方式、离线或内网更新、socket 或 HTTP 接口、单节点吞吐与并发）。

### 2. 检测流程（部分取代 ADR-0060 决定 5 第 1 条）

1. **写入内容**：后端把上传流写到**本地检测暂存目录**，边写边算 SHA-256，大小超业务上限即中止并拒绝。
2. **检测**：适配器经 clamd `SCAN` 扫该路径，不用 `INSTREAM`。clamd 与后端同机优先；同机放不下时，用同 VPC 小机加内网共享暂存目录，仍用 `SCAN`，不退回 `INSTREAM`。
3. **三态判定**，每次写审计（文件 ID、SHA-256、引擎与病毒库版本、结论）：
   - **通过**：写入对象存储临时区（ADR-0060 第 5 条第 2 项的时效不变），状态「可用」，之后关联、复制到正式键照 ADR-0060。
   - **未通过**：写入对象存储隔离前缀 `<环境前缀>/quarantine/<文件 ID>`，状态「已隔离」，不可关联、不可下载，留 SHA-256，记 `ALERT` 并通知上传主体（ADR-0060 第 5 条第 4 项）；隔离保留期为配置项（缺失启动失败），到期由生命周期规则过期。
   - **不可用**（clamd 不可达、超时、超限、病毒库过期）：拒绝本次写入并告警，**失败即拒**，不重试到超时后放行，不跳过任何文件。
4. 本地检测暂存的文件在判定后立即删除（无论结论）；目录权限只给后端运行用户，不在任何静态资源、预签名或下载路径下。进程重启时清空残留。
5. **临时区不可外部读**：对象存储临时区与隔离前缀都不签发预签名 URL，应用下载角色对两者无读权限（RAM 显式 Deny）；只有正式键可签下载链接（ADR-0060 下载链接条款）。
6. 迁入（ADR-0060 迁移方案第 3、4 条）走同一流程。

### 3. 引擎参数与健康

1. **参数**：`MaxFileSize`、`MaxScanSize` 不小于业务单文件上限；`MaxRecursion`、`MaxFiles`、`MaxScanTime` 防压缩炸弹；`AlertExceedsMax yes`，超限按「不可用」处理。具体数值在运维测得业务单文件 P99 大小与单次扫描 P95 耗时之后再定（判据 8），未定前不开放上传。
2. **病毒库过期算故障**：库龄进健康检查，超过阈值（暂定 48 小时，经验值，配置可调，缺失启动失败）即判检测不可用，按第 2 条第 3 项拒绝并告警；`freshclam` 更新失败即告警，早于阈值触发。
3. **出向**：只为 `freshclam` 放行固定更新域名或内网镜像，写入安全组变更单，其余保持拒绝。

### 4. 宏文档的另外三条防护（判据 7）

ClamAV 对文档宏与新型样本的检出弱于商业引擎，这是已知取舍，不指望引擎兜住宏文档。

1. **识别**：写入时由文件服务判定「含宏」并记为文件属性（暂名 `contains_macros`）：启用宏的 Office 格式（docm、xlsm、pptm 及其模板）一律为含宏；doc、xls、ppt 与 docx、xlsx、pptx 按内容判定（OOXML 含 `vbaProject.bin`，OLE2 含 VBA 存储）。判定失败按「含宏」处理。
2. **不自动执行**：本系统任何环节不打开、不转换、不执行文件内容；下载一律 `Content-Disposition: attachment`（ADR-0060 已定）。
3. **不内联预览**（部分取代 ADR-0062 决定 1 第 1 条）：含宏文件不进在线预览，即使格式在预览范围内；界面提示「含宏文件不提供预览，请下载后在受控环境打开」。
4. **下载时提示来源**：下载含宏文件前，界面显示上传主体（本人、同事、外部链接持有人）与上传时间，并提示「含宏，打开前确认来源」；外部链接回传的含宏文件额外标「外部来源」。

### 5. 行为守护（判据 5）

未扫、未通过或判定不可用的文件，不能出现在「关联」「下载」「预览」三条路径上；含宏文件不能出现在预览路径上。

## 影响面

- `platform.file`：写入内容用例、检测状态、隔离前缀、`contains_macros` 属性与预览前置校验。
- `platform.integration`：ClamAV 适配器（`SCAN`、超时、三态映射）。
- 前端：含宏文件的下载提示与预览降级文案。
- one-ops：clamd 部署、`freshclam` 出向、健康检查与告警、临时区与隔离前缀的权限和生命周期（OPS-1021-OPS-02）。

## 迁移方案

1. 本篇与 ADR-0060 实施卡同批落地，W0 内、通用审批先行上线前建成；8 条判据逐条验收，缺一条不算建成。
2. 未建成前不开放上传、不开始迁入（ADR-0060:129 不变）。

## 回滚方案

检测引擎更换只换适配器，端口与三态不变（ADR-0060 回滚第 3 条）；切换期新上传不放行并告警。宏文档三条防护不随引擎更换取消。

## 需同步修改的守护规则

1. `ExternalConnectionIsolationTest`：clamd 客户端只在 `platform.integration`。
2. 行为测试：EICAR 样本走「写入→未通过→隔离」；停 clamd、超时、超限、病毒库过期各走「不可用→拒绝＋告警」；未扫与未通过文件在关联、下载、预览三条路径被拒；含宏文件预览被拒、下载带提示；本地暂存判定后为空。
3. 启动校验：隔离保留期、库龄阈值、超时与大小上限缺失即失败。
4. 不放宽、不删除现有断言。

## 后果

- 文件不出本系统，检测离线可控；代价是检出率弱于商业引擎，由宏文档三条防护与升级路径补。
- 病毒库更新失败会在阈值后阻断上传，靠告警及时处理。
- **待登记用语**（交 one-glossary）：本地检测暂存、隔离前缀、含宏（`contains_macros`）。

## 证据

- 用户：PR #494 评论 6311040189（8 条判据与两条提醒），intent `2026-10-21-100709`。
- ADR-0060 决定 2 第 3 条、第 5 条、下载链接、迁移方案第 3、4 条（ADR-0060:44、53、58、88–94、128–129）；ADR-0062 决定 1（ADR-0062:32、38）。
- 运维实施卡 OPS-1021-OPS-02（@5643fbc5）：判据 6 阈值暂定 48 小时。

## 备选方案（未采用）

- **临时区仍在对象存储、检测从对象存储读回扫描**：未检文件已在对象存储，违用户提醒 1；还要为扫描另开读权限。
- **`INSTREAM` 远程流式扫描**：有流长度上限，大文件需调参，且易被配置成「超限跳过」即静默放行（用户判据 1）。
- **含宏文件一律拒收**：客户资料与内部表格可能含宏（尚未取证），一律拒收会把人推到系统外传文件；以识别加三条防护替代。
