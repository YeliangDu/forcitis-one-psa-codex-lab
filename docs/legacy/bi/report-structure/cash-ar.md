## 1.6 核对表格-NN（01 … 12，同结构一组）与 表格累计余额核验

**核对表格-NN**：
- 透视表（行：现金流量表大类；列：来源法人；值：「求和项:金额」；总计列「总计」）+ 其下手工整理块。
- 行项目：「流入」「流出」「净额」「核对」；列：必捷、弗思特、个独综合、杭州分公司、雷蒙沃、山西隆达通、工抵卡、(空白)。
- 公式：「流入」= 销售商品 + 收到其他经营 + 处置固定资产 + 收到税费返还类行之和；「流出」= 购买商品 + 支付各项税费 + 支付其他经营 + 支付给职工 + 购建固定资产 + 支付其他投资 之和；
- 「净额」行**全部是手工公式常量**（形如「本月银行收入合计 − 本月银行支出合计 ± 个别调整」，数字硬编码在单元格里）；「核对」= 流入 − 流出 − 净额。意在验证：底稿汇总的流入流出差 = 银行日记账净发生额。
- 月报表中「核验-流入 / 流出」引用本表总计。

**表格累计余额核验**（可见）：
- 列标题：「日期」「银行」「2025/12/31期末余额」，之后每月两列「发生额」「余额」，月份 01月份–12月份。
- 行项目（账户 / 法人）：若干个人账户（3 行，名称为人名，已脱敏）、「个独综合」（上述个人账户合计）、「必捷」「雷蒙沃」「弗思特库存现金」「弗思特」「保函保证金」「弗思特杭州分公司」「山西展恒」「山西展恒南京分公司」「山西隆达通南京分」「山西隆达通」「工抵卡」；尾部「核验」「合计：」「每日余额表可用资金合计」及差异行。
- 口径：期末余额 = 上月余额 + 当月发生额；发生额为手写算式（如收入合计 − 支出合计 ± 项）。「每日余额表可用资金合计」为手工从资金日报抄入的值；差异行 = 合计 − 每日余额表合计（用来对账）。

  - 下方块：「BU」「开票」「回款」「同比」「应收」「DSO」，用手工日期（常量日期区间）计算同期开票、回款同比；应收列「24-9」「25-9」「26-9」是**粘贴值**，DSO 列「25-4」「26-4」为期次比较。
- 手工注释列：备注文本说明个别项目的剔除 / 转入（含客户项目名，已不转述）。

## 2.6 2026当年DSO

- 列标题：「BU」「2026开票」「2026年开票回款」「当年开回率」「2026年形成的应收」「当年DSO」「换天数」「剔除退22年以前发票收入部分」，B1 / H1 为手工日期（期初 / 截止）。
- 公式：
  - 2026年开票回款 = SUMPRODUCT(开票日期 ∈ [B1, H1] ∧ 新BU = 本行, 回款金额)/10000（**按开票日期过滤的回款**，即「当年开票当年回款」）。
  - 2026年形成的应收 = SUMPRODUCT(YEAR(26.09 开票日期) = 2026 ∧ 交付部门 = 本行, 应收账款金额)/10000。
  - 2026开票 = 当年回款 + 当年形成应收（推算，不是直接取开票金额）。
  - 当年开回率 = 当年回款 / 2026开票。
  - 当年DSO = 当年形成应收 / 当年开票 × (截止日 − 2025 年 1 月 1 日 的天数)（**基准日是 2025-01-01，与年份 2026 不一致，疑为未更新**）。
  - H 列「换天数」类比率含手工常数调整（如加若干万元的手工补项）。
- 右侧 I–M：旧 BU 名 + 手工填的「换天数 / 剔除退22年以前发票收入部分」硬编码值，与新 BU 无自动映射。
- 下方块：2024 年的历史粘贴值（开票 / 回款 / 开回率 / 形成应收 / DSO，按旧 BU 与「战区」弗思特 / 必捷 / 雷蒙沃）；2026 年块：「当年开票」「当年开票当年回款」「当年开回率」，BU 行为粘贴值，只有「当年开回率」和「合计」是公式。

## 2.7 客户DSO

- 列标题：「序号」「客户名称」（实为客户集团）「开票」「回款」「应收账款」「滚动DSO」（M1 另注：「DSO = 365 天 / (销售额 / 平均应收账款)」），之后「逾期商票」「商票总计」，以及各年份（2026 … 2020）的**平均开票回款时间差**列。
