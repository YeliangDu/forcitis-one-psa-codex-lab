# 《企业会计准则第 14 号——收入》（2017 年修订）要点笔记

本笔记保存与 FORCITIS one 相关的阅读要点，不构成架构决定，也不替代财务对具体交易的会计判断。正文为自行概括，短引 0 处，不写本机路径。原文为财政部公开发布的准则文本，共 22 页，页脚页码与 PDF 页一致，故两列同值。阅读聚焦于合同、履约义务、履约进度、交易价格、合同变更、合同成本和列报，未展开金融工具、租赁、售后回购等与本系统业务无关的条款。

## 核心思想

- **论断：收入在客户取得控制权时确认，单项履约义务以可明确区分的商品或服务为识别依据。** 依据：CAS14#控制权转移、CAS14#单项履约义务。含义：合同条款兼作履约义务与付款节点的关系继续交 one-rules 和财务核对 G-21，不以开票、收款或付款节点直接确定收入时点。
- **论断：满足时段履约的三个条件之一才按时段确认，否则按时点确认。** 依据：CAS14#时段履约条件。含义：时段或时点判定作为合同级可追溯记录保留结论、依据条款和判定人，不把设计咨询行业名称写成默认判据。
- **论断：时段履约采用反映商品性质的进度方法，同类义务方法一致，进度不能合理确定时仅按预计可补偿的已发生成本确认。** 依据：CAS14#履约进度。含义：在对象定稿和流程目录中保留方法选定与变更、进度认定的落点；本笔记不裁定具体合同类型的处理。
- **论断：交易价格排除代收及预计退还款，可变对价的计入金额受重大转回限制。** 依据：CAS14#交易价格、CAS14#可变对价。含义：合同变更进入核算时应留下对交易价格及履约进度的影响，不用开票或收款金额替代收入确认判断。
- **论断：合同变更因新增服务及价格条件不同，分别按单独合同、终止重立或原合同组成部分处理。** 依据：CAS14#合同变更。含义：销售合同变更进入核算时记录其会计处理类型，作为合同级可追溯记录进入对象定稿与业务对象界定的双向核对。
- **论断：只有为取得合同发生且预计可收回的增量成本才可资本化，无论是否中标都会发生的投标成本不满足增量条件。** 依据：CAS14#合同取得成本。含义：投标人员工时等商务费用不能因项目中标就直接转资产，具体处理继续由 one-rules 与财务确认。
- **论断：只有收款权仅取决于时间流逝时才列应收款项，仍附履约条件的权利列合同资产。** 依据：CAS14#合同资产与合同负债。含义：度量登记须说明管理口径 WIP 与准则口径合同资产的差异项，不能以累计履约收入减累计开票直接替代合同资产列报。

## 对本系统的启示

- **合同与履约义务是收入链的骨架。** 本系统合同条款兼作收入、成本、开票挂接锚点，terms.yaml 已记其语义接近履约义务且兼作付款节点，待财务确认（G-21）；本准则要求履约义务按「可明确区分」判定，付款节点不能自动等同履约义务。对象定稿时须分开这两种角色。（CAS14#单项履约义务）
- **时段履约判定应是合同级、可追溯的记录。** 设计咨询合同多数按时段履约，但判据依赖合同条款中的终止补偿权；判定结论、依据条款和判定人应留存，供审计回查，不宜写死为行业默认值。（CAS14#时段履约条件）
- **履约进度是一个独立的度量与认定过程。** 本系统已有「履约进度」「履约进度认定」两个术语；准则要求方法按商品性质选定并在同类义务间一致，进度不能合理确定时有单独口径，流程目录里须有方法选定与变更、进度认定两处落点。（CAS14#履约进度）
- **WIP 与合同资产不能互相代替。** terms.yaml 已区分管理口径 WIP（累计履约收入减累计开票，含无合同部分）与准则口径合同资产；本准则把无合同或合同未成立时的已收款列为负债，度量登记须写清两者差异项。（CAS14#合同成立条件、CAS14#合同资产与合同负债）
- **合同变更须按三种情形留下处理类型。** 销售合同变更（对应 FIDIC Variation）进入核算时要记录归入哪种情形以及对交易价格、履约进度的影响。（CAS14#合同变更）
- **分包与转包涉及主要责任人判断。** 对分包合作方提供的服务，本系统是否按总额确认取决于转让前是否控制该服务，这影响收入与成本的列示口径。（CAS14#主要责任人与代理人）
- **投标、商务费用的资本化有门槛。** 只有取得合同的增量成本可资本化，投标人员工时等无论是否中标都会发生的成本不属此类。（CAS14#合同取得成本）

## 我们的取舍

- **采纳：中文用语以本准则原文为准。** 理由：terms.yaml 原则 1 已规定准则用语优先（合同、履约义务、交易价格、合同资产、合同负债、履约进度、投入法、产出法）；本笔记锚点即按此命名。（CAS14#单项履约义务、CAS14#履约进度）
- **采纳：时段 / 时点判定、履约进度方法、合同变更情形作为合同级可追溯记录进入对象定稿与业务对象界定的双向核对。** 理由：三者都是会计判断的依据，事后须能回答「当时为什么这样确认」。是否成为独立对象由业务对象界定标准裁定，本笔记不预设。（CAS14#时段履约条件、CAS14#合同变更）
- **采纳：合同条款与履约义务的关系送成熟产品对抗关卡与 one-rules 核对。** 理由：G-21 待财务确认；本准则只给判定标准，不给本系统的对象划分。
- **不采纳：把开票、收款或付款节点直接作为收入确认时点。** 理由：本准则以控制权转移为准；开票只引起合同资产转应收或冲合同负债。（CAS14#控制权转移、CAS14#合同资产与合同负债）
- **不采纳：在本笔记中裁定具体合同类型的会计处理。** 理由：属于财务专业判断，归 one-rules 与财务确认；本笔记只提供条款索引与设计启示。
