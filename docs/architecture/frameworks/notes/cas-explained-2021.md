# 《企业会计准则详解与实务》（2021 年版）要点笔记

资料出处：公开资料（不进仓库）《企业会计准则详解与实务：条文解读+实务应用+案例讲解：2021年版》。题名、编著者取扉页，年份与版次取版权信息，出版者为人民邮电出版社，ISBN 978-7-115-55820-6。本资料是解释与案例书籍，不能作为财政部发布的准则原件，也未在本卡核验其后修订或现行政策。

仅阅读第 5 章固定资产相关小节、第 10 章职工薪酬相关小节、第 15 章收入确认和合同成本，以及第 22 章 §22.7 中与应收款项减值相关的部分；不扩展至其他准则主题。书内案例只用来理解判断，不照搬案例数值、科目或税率。EPUB 无可核印刷页和 PDF 页，两列均为「—」，章、节、内部内容文件共同定位。本文自行概括，正文短引 0 处，不构成会计政策或架构决定。

## 核心思想

- **论断：一项承诺能单列履约义务，须同时满足客户可获益及其在合同内可区分两个条件。** 依据：CASD#履约义务。含义：OBJ-05、OBJ-06、OBJ-07 与 OBJ-08 不因金额相同就合并；建议 PRC-47、PRC-48 保留承诺划分与可区分性判断依据。
- **论断：可变对价须估计并受重大转回限制，多项履约义务的交易价格按单独售价相对比例分摊。** 依据：CASD#交易价格、CASD#可变对价。含义：建议为 PRC-53 保留索赔、奖励和折让的估计、重估及分摊依据，OBJ-81 应能追踪所用合同基线与 OBJ-53 证据。
- **论断：合同履约支出须满足资产确认条件，可收回的增量取得支出才可能形成合同取得成本资产。** 依据：CASD#合同履约成本、CASD#合同取得成本、CASD#合同成本摊销。含义：建议 PRC-55、PRC-96 分别记录成本归属、未来履约资源、可收回性与摊销配对，不将全部项目人工或投标成本默认转资产。
- **论断：短期薪酬和设定提存义务在服务期间确认，辞退福利则按不可撤回安排与相关重组成本确认两者孰早确认。** 依据：CASD#短期薪酬、CASD#设定提存计划、CASD#辞退福利。含义：建议 OBJ-73、PRC-124、PRC-126 在 VS-13 分别说明服务期间、结算期间、付款日期与薪酬类别，不用付款月份代替成本归属月份。
- **论断：固定资产后续支出只有符合确认条件才资本化并扣除替换部分，否则计入费用。** 依据：CASD#固定资产后续支出。含义：建议 OBJ-93 与 PRC-99 保留确认和处置依据；残值、寿命等具体数值仍按财务政策，不取教材案例作默认值。
- **论断：预期信用损失须结合历史、当前与前瞻信息，符合特定条件的应收款项和合同资产采用整个存续期口径。** 依据：CASD#预期信用损失、CASD#应收款项。含义：OBJ-85 与 PRC-61 的账龄和催收仅提供输入，建议 （提议补阶段：应收款项信用减值评估）另留适用政策、客户分组、前瞻调整及审批证据，不复制书中账龄比例。

## 对本系统的启示

- **协议结构需保留会计判断的独立落点。** OBJ-05 协议、OBJ-06 合同范围条目、OBJ-07 付款条件项和 OBJ-08 履约义务不能因金额相同就合并。PRC-47 起草并回签协议与 PRC-48 提出并生效协议变更或签证，应为收入侧保留承诺划分、可区分性、价格分摊及变更分类的依据。（CASD#合同、CASD#履约义务、CASD#交易价格）
- **VS-04 的收入确认需要证据与方法。** OBJ-81 收入确认、OBJ-53 证据及 PRC-53 确认收入应可追踪客户价值认可和所用合同基线。书中投入法案例不能使项目成本或完工估算自动成为收入依据，现行产出法口径仍按 ADR-0016 及其后续证据规则执行。（CASD#履约进度、CASD#可变对价）
- **成本结转要能解释哪些支出可资本化。** PRC-55 结转合同履约成本、PRC-96 分配人工成本支持 VS-10 的期末核算；需分别记录成本归属、未来履约资源、可收回性和摊销配对，不能把所有项目人工或全部投标成本默认转资产。（CASD#合同履约成本、CASD#合同取得成本、CASD#合同成本摊销）
- **人员资料、应付薪酬和资金支付是不同依据。** OBJ-56 人员、OBJ-123 人员薪酬档案、OBJ-73 月度薪酬结算支撑 PRC-124 计算、审核并批准月度薪酬及 PRC-126 提交应付薪酬；VS-13 应分清服务期间、结算期间、付款日期和薪酬类别。离职或请假还需核对其独立确认条件。（CASD#职工薪酬、CASD#短期薪酬、CASD#带薪缺勤、CASD#辞退福利）
- **公司资产不能与受检建筑资产混同。** OBJ-93 公司资产与 PRC-99 计提折旧并处置公司资产，应承载确认依据、可使用日期、残值、寿命、已提折旧及处置依据；它不同于客户工程的受检对象。具体数值属于财务政策，不从教材案例取默认值。（CASD#固定资产确认、CASD#固定资产折旧、CASD#固定资产后续支出、CASD#固定资产终止确认）
- **账龄监控不等于减值计量完成。** OBJ-85 往来款项及 PRC-61 检测并催收逾期应收款项提供账龄与催收输入，（提议补阶段：应收款项信用减值评估）还需适用政策、客户分组、前瞻信息和审批证据。合同成本减值与应收减值的计算基础不同，不能共用一个无类型的减值比例。（CASD#预期信用损失、CASD#应收款项、CASD#合同成本减值）

### 供 one-rules 核对

- CASD#履约义务：核对合同范围条目、付款条件项与单项履约义务之间的判定及映射规则，不按节点名称自动划分。
- CASD#合同：核对合同识别、合并及变更分类所需证据，法律上的协议变更不自动决定其会计处理类别。
- CASD#可变对价：核对索赔、奖励与折让的估计、转回限制和报告日重估，记录判断责任与出处。
- CASD#履约进度：核对现行产出法与客户认可证据规则；如拟改为投入法，须待提议，不能由教材案例覆盖 ADR-0016。
- CASD#合同履约成本：逐类核对成本是否增加未来履约资源，避免把已经履行部分的日常服务支出一律资本化。
- CASD#合同取得成本：核对增量条件、可收回性及不超过一年摊销期的处理选择，投标差旅不自动资本化。
- CASD#合同成本摊销：核对摊销与相关收入基础一致，以及收入冲销时成本配对的现行控制。
- CASD#合同成本减值：核对减值测试的剩余对价、预计后续成本和转回上限，不等同应收坏账比例。
- CASD#短期薪酬：核对服务期间确认应付、资产成本或费用归属，不能按付款月份代替归属月份。
- CASD#带薪缺勤：核对可结转假期权利增加和不可结转假期实际使用的确认差别。
- CASD#设定提存计划：核对社保等应缴义务的期间和计量依据，不从教材读取本地最新缴费参数。
- CASD#辞退福利：核对孰早确认条件，并区分继续服务报酬和解除关系补偿。
- CASD#固定资产折旧：核对启停月份、提足折旧与后续支出，残值及寿命按批准政策版本取值。
- CASD#应收款项：先核对整个存续期口径的适用条件与政策选择，再判断是否适用一般信用风险分阶段规则。
- CASD#预期信用损失：账龄准备率须有本企业历史及前瞻调整依据，书中示例百分比不进入本系统默认配置。

## 我们的取舍

- **建议采纳：将上述会计判断整理为带证据、适用范围与版本的规则核对项。** 理由：能把对象、流程与计量依据联系起来，正式规则仍须 one-rules 与财务核对原准则及已定政策。（CASD#履约义务、CASD#合同履约成本、CASD#应收款项）
- **建议采纳：区分应收减值、合同成本减值、薪酬确认和固定资产计量。** 理由：各有确认对象与计量条件，不宜用统一的项目费用或坏账字段替代。（CASD#合同成本减值、CASD#短期薪酬、CASD#固定资产折旧、CASD#预期信用损失）
- **建议不采纳：直接复制案例金额、税率、会计科目或账龄比例。** 理由：案例并非本企业事实和现行政策，且解释性书籍可能存在编校问题。（CASD#交易价格、CASD#预期信用损失）
- **建议不采纳：因书中同时介绍两种履约进度方法就给本系统增加投入法选项。** 理由：与 ADR-0016 的现行产出法决定冲突，改变口径须待提议；本笔记不裁定适用例外。（CASD#履约进度）
