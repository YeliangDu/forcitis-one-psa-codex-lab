# Ajera 实施、会计基础与移动费用资料要点笔记

本笔记保存与 FORCITIS one 相关的阅读要点，不构成架构决定。正文自行概括，短引 0 处。资料均为公开资料（不进仓库），仅核对本地所给版本，未联网核验现行效力或产品现状。

本组全部三份合读。简称：会计基础为《Accounting 101》，末页版权 2011、Axium；实施指南为《Deltek Ajera 9 — Ajera Getting Started: Implementation Guide》，封面 2019-01-23，版权页注明 January 2019；移动费用为《Deltek Mobile Expense for Ajera — User Guide》，封面 July 2021。三者不构成同一版本产品证据。实施指南所引正文印刷页与物理页相同；移动费用正文印刷页 = PDF 页减 4；会计基础两列同值。本文按本卡使用实际页码和章节定位。

## 核心思想

- **论断：Ajera 将项目阶段树、单独出具商业账单的分组和账单内汇总分组分别配置。** 依据：AJE#阶段与账单分组。含义：OBJ-29、OBJ-30、OBJ-31 与 PRC-17、PRC-18、VS-02.0 对照时分别说明交付结构、计费分组、预算和排期用途，不把产品 phase 直接等同我方阶段类型字典。
- **论断：Ajera 的计费费率表可按人员、活动及供方等选择费率或成本加价，并支持多个生效日期区间。** 依据：AJE#计费费率卡。含义：成熟产品关卡核对计费类型与费率有效期，但不能由项目开票设置推定已有完整协议模型。
- **论断：资源可先按未具名或人员类型提出需求，再安排具名人员，排期调整不影响合同计费和会计。** 依据：AJE#资源需求到安排。含义：PRC-20 对照 OBJ-44 到 OBJ-45 的安排，PRC-23、OBJ-66 的实际记录与计划分开；排期变化不视为 PRC-48 的协议变更。
- **论断：Ajera 的商业账单可配置复核阶段，移动费用则区分已提交、单级已批和全部处理完成。** 依据：AJE#商业账单复核、AJE#移动费用状态、AJE#移动费用提交。含义：借鉴账单复核链，并在 OBJ-88、PRC-87、VS-08.2 核对状态与编辑权限，不把单级批准当作全部处理完成。
- **论断：Ajera 以费率计投入的 earned value 进入其 WIP 和收入，项目累计展示不因开商业账单解除。** 依据：AJE#产品计价完成值。含义：OBJ-81、OBJ-83、OBJ-85 在 VS-04 中仍按本系统政策管理；若拟采用该计价入收入做法，须正式比对 ADR-0016、ADR-0047，保留待提议状态。
- **论断：期初控制科目明细须与试算余额一致，差异清零并经会计审阅后才结束期初工作。** 依据：AJE#期初明细、AJE#期初核对锁定。含义：OBJ-97、OBJ-98、PRC-167 与 VS-10.1 可参考明细差异清零的核对方法，不照搬产品重新打开期初录入的权限方式。

## 对本系统的启示

- 项目 OBJ-29、WBS 节点 OBJ-30、交付计划 OBJ-31 与 PRC-17、PRC-18、VS-02.0 对照时，把交付结构、计费分组、预算和排期用途说清；来源资料中的 phase 不能直接等于我方阶段类型字典。（AJE#阶段与账单分组）
- PRC-20 资源需求 OBJ-44 到分配 OBJ-45 可借鉴先岗位需求后具名安排；PRC-23 工时单 OBJ-66 的实际记录与计划分开，排期改变不是 PRC-48 的协议变更。（AJE#资源需求到安排、AJE#工时多层复核）
- 收入确认 OBJ-81、增值税发票 OBJ-83、往来款项 OBJ-85 在 VS-04 中仍按本系统政策管理。产品商业 invoice、earned value 和 WIP 的例子不足以证明与这些对象同义；若拟采用其按投入计价入收入的做法，与 ADR-0016、ADR-0047 需正式比对，属于待提议。（AJE#产品计价完成值、AJE#商业账单复核）
- 费用报销 OBJ-88、证据 OBJ-53 对应 PRC-87、VS-08.2，可核对状态权限、凭据和复制后的重填校验；识别结果只是辅助输入，不自动证明票据有效或业务费用成立。（AJE#移动费用状态、AJE#费用复制限制、AJE#费用凭据识别）
- 会计期间 OBJ-97、会计分录 OBJ-98 对应 PRC-167 期初签字及 VS-10.1，可参考控制科目与辅助明细差异清零思路；不能照搬产品允许重新打开期初录入的权限方式。（AJE#期初明细、AJE#期初核对锁定）

### 供成熟产品关卡

- 协议：实施指南展示项目阶段、计费类型与费率表，未展示独立协议签署及多项目关系，不能以项目开票设置替代完整合同模型。（AJE#阶段与账单分组、AJE#计费费率卡）
- 履约义务：任务、阶段、计费完成值用途不同，未给出会计义务识别与价格分摊；特别核对其按投入计价逻辑与本系统政策差异。（AJE#任务与阶段成本、AJE#产品计价完成值）
- 变更：排期可调整且不直接改变合同和会计，说明需分离计划变动与协议变更；完整范围价款工期变更程序未见。（AJE#资源需求到安排）
- 全过程咨询服务范围：阶段和费率支持人工、费用、顾问服务组合计费，但未证明统筹责任、专项资质和全过程咨询清单管理。（AJE#阶段与账单分组、AJE#计费费率卡）

## 我们的取舍

- **建议采纳：** 借鉴独立计划与实际、费率有效期、账单复核、费用状态及期初明细对账。理由：这些提供可操作的核对链。（AJE#计费费率卡、AJE#期初核对锁定、AJE#商业账单复核）

- **建议不采纳：** 把产品 earned value、美国薪税及账户代码移入本系统财务规则。理由：术语和会计适用环境不同，不能改变既有收入及过账决定；变更须待提议。（AJE#产品计价完成值、AJE#借贷平衡示例）
