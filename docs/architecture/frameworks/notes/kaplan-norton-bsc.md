# 《平衡计分卡：化战略为行动》要点笔记

本笔记保存与 FORCITIS one 相关的阅读要点，不构成架构决定。正文自行概括，短引 0 处。信息栏据 PDF 第 3–4 页：广东经济出版社，2013 年 11 月中文第 2 版；原著版权为 1996 年，中文译本版权为 2004 年，未将其当作本版年份。资料为扫描 PDF，以下页码逐页目读核对，所列正文 PDF 页比印刷页大 22。阅读聚焦第 1–7、11 章所列页，未逐页通读全书；作者术语和案例指标用于解释原书，不自动成为本系统正式用语或已批准口径。

## 核心思想

- **论断：只把财务和非财务指标分成四组，还不足以构成能够说明战略的平衡计分卡。** 依据：BSC#战略管理系统、BSC#因果关系链、BSC#结果与驱动因素。含义：OBJ-100 经营计划不能只挂四栏数字；PRC-88 应写目标、预期驱动关系和行动，PRC-181 再检验这些关系是否成立。
- **论断：同一个通用财务目标不适合直接套用于成长、保持和成熟三种业务阶段。** 依据：BSC#业务生命周期、BSC#财务战略主题。含义：贡献毛利率、新签合同额、回款率的选用须说明所服务的经营目标和适用组织，不能用一个固定权重考核全部业务；本卡不代替业务决定分组与权重。
- **论断：客户满意、客户留存和客户盈利回答不同问题，不能互为替代。** 依据：BSC#客户核心指标、BSC#目标客户细分、BSC#客户价值主张。含义：OBJ-106、PRC-37 的调查结果与客户收入、成本应分别取证；贡献毛利率不能充当客户满意程度，满意度也不能证明项目获利。
- **论断：内部流程度量应覆盖客户价值形成的全程，而不能只奖励局部速度或投入利用。** 依据：BSC#内部价值链、BSC#流程质量时间成本、BSC#诊断指标制衡。含义：OBJ-35、PRC-28 的交付观察应同时考虑客户认可、返工率与相关成本；缩短内部签发时间不能以延长对外承诺或牺牲质量为代价。
- **论断：结果指标必须与战略特定的驱动因素一起观察，并最终回到经营成果验证。** 依据：BSC#结果与驱动因素、BSC#战略专属动因、BSC#财务联系。含义：度量清单把贡献毛利率等结果与工时有效性、质量和交付过程的候选驱动关系分别记录；KPI／派生指标／基础指标的计算依赖另列，不能将领先等同于基础、滞后等同于派生。
- **论断：复盘若只问是否照计划执行，就无法发现战略假设本身已经失效。** 依据：BSC#双循环学习、BSC#战略学习机制。含义：PRC-181 除解释目标偏差，还应检查客户、流程和能力与经营结果之间的关系；需要调整时形成 OBJ-100 新版本，不追改旧版计划与原观测数据。

## 对本系统的启示

- **经营计划应说明指标之间的假设关系。** 对 OBJ-100、PRC-88 和 PRC-181，建议把经营目标、拟改善的流程结果、所需能力及行动连接起来，并说明验证方式。指标元数据不恢复为 OBJ-102 业务对象；信息图已将该行保留为非对象，后续在度量设计中承接。（BSC#战略管理系统、BSC#因果关系链）
- **财务结果和客户反馈分别保留证据。** terms.yaml 的贡献毛利率、新签合同额、回款率具有各自业务口径；OBJ-106、PRC-37 和 VS-02.7 提供另一组客户反馈证据。建议按目标客户群体比较结果，不能把利润好解释为客户满意。书中的客户获利指标也不能直接替换本系统贡献毛利率公式。（BSC#目标客户细分、BSC#客户核心指标）
- **交付速度需与承诺及质量一起核查。** OBJ-35、PRC-28 既有签发也有送达和客户认可，建议业务库保留原承诺、变更依据及实际状态时间；OBJ-38 不符合项提供另一类质量证据。返工率、质量缺陷率与交付时效分别展示，不能以内部签发快就认定客户价值提高。（BSC#内部价值链、BSC#流程质量时间成本、BSC#诊断指标制衡）
- **人员与技术投入要有结果验证。** OBJ-66 工时单及 PRC-91 可供有效工时等指标原料；离职率和平均在册人数已有 metric 词条。建议讨论这些结果与交付、经营成果的关系，不能按培训时数或系统上线数量直接认定能力改善；本书完整员工满意度口径，本系统暂无对应已核定度量。（BSC#员工核心指标、BSC#信息系统能力、BSC#财务联系）
- **复盘可以推翻原来认为正确的关系。** PRC-181 应区分目标未达、执行不足和战略假设不成立；PRC-90 的期间结果作为观察证据，必要时由 PRC-88 形成 OBJ-100 新版计划。本书的因果图用于提出问题，不是本系统因果已证实的证明。（BSC#双循环学习、BSC#战略学习机制）

### 供度量设计

- **度量选择**：从经营目标沿因果假设找到流程和能力方面的候选指标，给每个候选指标写明服务的结果及验证方式。（BSC#因果关系链、BSC#战略专属动因）
- **KPI分级**：书中结果／驱动因素按战略关系分类，不能对应为本系统派生／基础指标；度量清单另列管理用途与公式依赖。（BSC#结果与驱动因素）
- **指标口径**：客户获得、保持、满意和获利分开定义，标明目标客户群、统计期间及分母；具体本系统字段按 BI_SCOPE.md §3.3 补齐。（BSC#客户核心指标、BSC#目标客户细分）
- **适用范围**：同一财务主题按成长、保持、成熟阶段选择不同重点，范围和比较对象必须可识别，不能把差异业务混成一个无解释的排名。（BSC#业务生命周期、BSC#财务战略主题）
- **承诺原料**：检查 OBJ-35 的原约定、变更及实际交付时间是否留存，避免通过延长承诺而提高表面及时率。（BSC#诊断指标制衡）
- **质量原料**：流程时间、质量与成本并查，分别保留交付状态、不符合项及成本来源，不能只统计办理速度。（BSC#流程质量时间成本）
- **客户原料**：调查量表、客户选择的评价特征及权重应能回查，具体统一或定制方案尚待业务批准，不能直接平均不同量表得分。（BSC#客户定制评价）
- **总线矩阵**：内部价值链提示应覆盖哪些业务过程，但不是业务过程乘维度的矩阵；本系统按 BI_SCOPE.md §3.2 映射过程事实，不能直接把四层面当事实表行。（BSC#内部价值链、BSC#四层面）
- **粒度**：客户群体、业务单位及项目评价提供观察对象的线索，未规定一行事实的粒度；建模仍须按 BI_SCOPE.md §3.1 明确事件、对象及时间单位。（BSC#目标客户细分、BSC#客户定制评价）
- **事实表类型**：结果与驱动因素不是交易事实／累积快照／期间快照的选型规则；按 BI_SCOPE.md §3.1–3.2 分别设计事实与快照。（BSC#结果与驱动因素）
- **维度一致性**：比较必须限定相同业务范围与客户群体，但所核章节未提供维度键和历史生效期方法；本系统按 BI_SCOPE.md §3.1 统一期间、法人、组织、项目等维度。（BSC#业务生命周期、BSC#目标客户细分）
- **效果复核**：按同口径结果检查流程改善是否带来客户及财务成果，并允许修订关系假设，不能以过程数字改善代替经营效果。（BSC#财务联系、BSC#双循环学习）

## 我们的取舍

- **建议采纳：在度量清单记录结果、驱动关系与验证安排。** 理由：能解释选指标的目的，并为经营复盘提供待验证的问题。（BSC#因果关系链、BSC#战略学习机制）
- **建议采纳：用质量、承诺变更和成本信息检查时效指标失真。** 理由：单一指标容易被局部优化做高。（BSC#诊断指标制衡）
- **建议不采纳：四层面各放相同数量指标、采用固定权重或直接合成一个总分。** 理由：所读原文强调战略关系与业务差异，没有给出适用于本系统的数量、权重和合成规则。（BSC#战略管理系统、BSC#业务生命周期）
- **建议不采纳：把领先／滞后指标与基础／派生指标或事实表类型混用。** 理由：前者是战略关系，后者需要独立的计算与数据模型声明。（BSC#结果与驱动因素）
- **建议不采纳：将书中案例因果链当作FORCITIS one已验证结论。** 理由：本系统仍须通过实际观测检验关系，复盘也可能推翻原假设。（BSC#双循环学习）
