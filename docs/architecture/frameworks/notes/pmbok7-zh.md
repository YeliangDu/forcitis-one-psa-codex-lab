# 《PMBOK 指南》第七版要点笔记

资料出处：公开资料（不进仓库）《项目管理标准和项目管理知识体系指南（PMBOK® 指南）》第七版。题名与版次取题名页，作者机构、年份取版权页（PDF 2–4）。本笔记为自行概括，短引 0 处，不构成架构决定。

本件共 369 个 PDF 物理页；《项目管理标准》和《PMBOK 指南》两部分各自编正文页码，以下原文位置先注明部分，物理页从 1 起。阅读聚焦价值交付、开发与交付、规划、测量、不确定性及裁剪的指定章节，并非全书通读。

## 核心思想

- **论断：项目与运营等组件共同支持战略和干系人价值，战略要求向下传达，绩效与运营反馈向上回流。** 依据：PMB7#价值交付系统、PMB7#信息反馈。含义：OBJ-100 经营计划和 PRC-88 可接收项目绩效，VS-02 与 VS-04 仍通过明确业务事实核对，不混加项目 EV、预算和客户收益。
- **论断：交付物、开发方法和交付频率共同影响生命周期，方法与工件须按目标、治理和环境持续裁剪。** 依据：PMB7#开发方法与交付节奏、PMB7#情境裁剪。含义：OBJ-24 服务产品和 OBJ-25 阶段类型提供默认要求，PRC-17 按实际协议范围、项目级别和交付节奏实例化并留存调整原因，不将书中方法直接视为已批准配置。
- **论断：预算是已批准的估算，EAC、ETC 是基于当前假设的预测，范围、进度和成本基准提供获批比较依据。** 依据：PMB7#规划与预算、PMB7#完工估算、PMB7#基线组合。含义：OBJ-31 交付计划、OBJ-32 项目预算和 OBJ-33 完工估算分别更新，PRC-18、PRC-19 确定批准版本，更新预测不重写预算。
- **论断：需求须可核实且有唯一标识，增加范围须评估时间、资源和预算影响，质量要求须明确成果完成标准。** 依据：PMB7#需求可追踪性、PMB7#范围变更控制、PMB7#质量标准。含义：在 OBJ-05 协议、OBJ-30 WBS 与 OBJ-35 交付物之间追踪需求，分别核对 PRC-48 协议变更及 PRC-18、PRC-19 修订，不以管理层批准范围证明客户认可。
- **论断：可靠度量应促成纠偏，提前指标与滞后指标须配合使用，虚荣指标和短期优化可能扭曲判断。** 依据：PMB7#测量服务决策、PMB7#提前与滞后指标、PMB7#测量陷阱。含义：VS-02 联看 OBJ-35 认可、OBJ-106 客户满意度调查与 OBJ-108 项目风险与问题，以 PRC-27、PRC-28 的处置和认可补足投入度量，不以工时量推定价值实现。

## 对本系统的启示

- **保留计划、预算与预测的分别更新。** OBJ-31 交付计划、OBJ-32 项目预算和 OBJ-33 完工估算分别承担进度基线、成本基线与预测；PRC-18、PRC-19 的批准应确定比较版本。更新预测不应顺带重写预算。（PMB7#规划与预算、PMB7#完工估算、PMB7#基线组合）
- **把范围变化追到协议和交付物。** OBJ-05 协议、OBJ-30 WBS 与 OBJ-35 交付物之间应能追踪新增需求及影响，PRC-48 的协议变更与 PRC-18、PRC-19 的计划预算修订分别核对。管理层批准范围并不自动证明客户已认可成果。（PMB7#需求可追踪性、PMB7#范围变更控制、PMB7#质量标准）
- **服务产品模板保留裁剪依据。** OBJ-24 服务产品、OBJ-25 阶段类型可以提供默认交付要求，PRC-17 立项时按协议范围、项目级别和交付节奏实例化；所选模板及调整原因需要留痕。书中方法选择不等于本系统已批准的模板配置。（PMB7#开发方法与交付节奏、PMB7#情境裁剪、PMB7#裁剪过程）
- **用客户结果补足投入度量。** 在 VS-02 获得交付成果中，OBJ-35 的认可、OBJ-106 客户满意度调查与 OBJ-108 项目风险与问题提供不同信息；PRC-27 负责风险处置，PRC-28 记录成果交付与认可，不以工时量推定价值实现。（PMB7#信息反馈、PMB7#提前与滞后指标、PMB7#测量陷阱、PMB7#风险应对）
- **经营反馈与交付绩效各有粒度。** OBJ-100 经营计划及 PRC-88 可接收项目绩效，但项目 EV、预算和客户收益不能直接混加；VS-02 与 VS-04 的连接应通过明确业务事实核对，挣值并非收入确认依据。（PMB7#价值交付系统、PMB7#测量服务决策、PMB7#挣值）

## 我们的取舍

- **建议采纳：为计划、预算、预测和实绩注明版本与状态日。** 理由：可解释偏差来源，避免用新预测覆盖原承诺。（PMB7#完工估算、PMB7#基线组合）
- **建议采纳：以可追踪需求、质量标准和变更影响核对服务范围。** 理由：专业服务的交付批次和验收证据需要具体落点。（PMB7#需求可追踪性、PMB7#范围变更控制、PMB7#质量标准）
- **建议不采纳：将全书工件和绩效域逐项转为系统实体或必填审批。** 理由：本书要求按环境裁剪，本系统已有对象与流程目录，不以阅读框架扩大实现范围。（PMB7#情境裁剪、PMB7#裁剪过程）
- **建议不采纳：用挣值、工时完成率或 EAC 公式驱动收入确认。** 理由：与 ADR-0016 的成本预测与收入确认边界冲突；若拟改变须待提议，本笔记不变更该决定及其后续修订。（PMB7#挣值、PMB7#完工估算）
