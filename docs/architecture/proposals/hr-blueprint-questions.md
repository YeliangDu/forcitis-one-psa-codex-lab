# 人力资源子域蓝图：待用户决定的 10 道题（ADR-0079 第 8 条，卡 #975）

**已答（2026-11-02）**：1A 2A 3A 4A 5A 6B 7A 8A 9A 10A，附条件见 ADR-0079 第 8 条（intent `2026-11-02-141959`）。下文为提问时的题面，保留原样。

只列真正的业务取舍；技术与边界已在 ADR-0079 自定。每题标推荐。答法：一行写完，例如「1A 2A 3A 4A 5C 6B 7A 8A 9A 10A」，有补充写在后面。答复记为 intent，ADR-0079 采纳时引入。

1. **跨法人调动时劳动合同怎么处理**（原 P07-05）
   - A（推荐）原法人终止合同、新法人重新签订，工作年限依法合并计算，调动时不付经济补偿（劳动合同法实施条例第十条）。每个法人各管自己的合同，最简单。
   - B 三方协议变更合同主体，原合同延续。合同不中断，但新法人承接原合同的全部条款与期限。
   - C 原法人解除并支付经济补偿，新法人重新签订，工作年限不再合并。员工拿到补偿，新法人从零起算年限。
2. **外勤要不要进系统**（P13-03；老系统外勤 37,797 次，是最大的人事流程）
   - A（推荐）进：外勤作为考勤的一种在请假考勤模块登记、审批，当天免打卡、算出勤；差旅费用另走报销。
   - B 不进：外勤只在线下，系统里按缺卡处理后补卡。
3. **离职结算项进不进薪资**（P13-12）
   - A（推荐）进：离职当月工资、年假折算、经济补偿、代通知金、竞业限制补偿都在薪资里算、在离职后的月份也能发，个税一并处理。
   - B 金额与个税都在薪资里算，但补偿类不随工资发放，由财务按单独付款发出。
   - 竞业限制约定本身记在劳动合同里（人事模块）。
4. **公司单方解除时系统管到什么程度**（新；无论选哪项，解除依据都要记录）
   - A（推荐）系统要求选择解除依据，并勾选「已核实不属于法定不得解除情形、已通知工会」后才能登记；核实在线下，系统不存健康、孕产信息。
   - B 系统只记录解除依据，不做核实确认。
5. **停薪留职期间继续缴社保公积金时，费用谁承担**（新；老系统 14 次；能否停缴另交法务）
   - A（推荐）公司继续缴单位部分，个人部分由员工按月交回。
   - B 单位与个人部分都由员工承担（是否合法先经法务确认）。
6. **月度考勤由谁确认**（关联 P13-06；老系统月度考勤确认累计 1,078 次，近 180 天只有 12 次）
   - A 每位员工每月在系统里确认自己的考勤，确认后锁定。
   - B（推荐）部门负责人或人力每月统一确认锁定，员工可在锁定前提出异议。
7. **社保公积金与个税怎么申报**（P13-08、P13-09）
   - A（推荐）系统算出增减员、缴费明细与个税（累计预扣），导出申报文件；人力在经办平台、自然人电子税务局扣缴端办理后把回执导入；专项附加扣除从扣缴端下载后导入。
   - B 系统直接对接政府平台自动申报（需另批外部调用，且各城市接口不一）。
8. **劳动合同怎么签**（新）
   - A（推荐）线下签字，系统记合同台账（期限、类型、续签、到期提醒）并存扫描件。
   - B 在系统里电子签署（需选电子签名服务，另批外部调用；签章服务已依赖人事模块，选 B 须另立 ADR 调整依赖方向）。
9. **招聘做到哪里**（新；老系统累计：应聘登记 2,360、面试评估 1,108（2021-12 后未用）、录用审批 450、用人申请 211）
   - A（推荐）用人申请、应聘登记、面试评估、录用审批，审批都是单级（申请单位负责人）；不对接招聘网站。
   - B 另加多级审批或招聘网站对接。选 B 时招聘须另立 ADR 移出人事模块。
10. **绩效做到哪里**（P13-15、P13-16 的上位题；老系统累计：月度评估 3,479、管理层一对一 1,738（2025-07 后未用）、试用期评估 209）
    - A（推荐）记录月度评估、管理层一对一、试用期评估的结果，由部门负责人单级确认；结果供转正与奖金使用。
    - B 目标设定、自评、多级评分与校准全流程。选 B 时绩效须另立 ADR 移出人事模块。

## 第二批（2026-11-02 重读草稿后新增，待答）

答法同上，例如「11A 12A」。

11. **规章制度与违纪做到哪里**（劳动合同法第四条：规章须经民主程序并公示；第三十九条：严重违反规章可解除）
    - A（推荐）系统登记规章制度的版本、民主程序与公示证据；以违纪为由解除时，必须引用所依据的规章条款与违纪证据。不做日常违纪处分流程。
    - B 规章与违纪都在线下，系统只在解除时记录解除依据。
    - C 完整的违纪处分管理（警告、记过等逐级处分与审批）。选 C 时须另行评估审批层级是否移出人事模块。
12. **工伤做到哪里**（工伤保险条例第十七条：单位应自事故伤害之日起三十日内申请工伤认定；工伤信息属敏感个人信息）
    - A（推荐）系统记录事故日期、提醒三十日内申请认定、记录认定结论与停工留薪期起止，薪资按停工留薪期计发；不存病历与诊断内容。
    - B 工伤全在线下，系统只在请假里记相应假期。
