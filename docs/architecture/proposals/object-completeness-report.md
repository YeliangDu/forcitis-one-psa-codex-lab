## 1. 方法与来源

**① 产品手册对照。** 逐条读八条产品线手册（公建、地产、景观、照明、造价、品控、大公建、超高层）的正文、流程图与矩阵页，把其中的阶段、子阶段、门、交付物、表单、角色逐项落到信息图 OBJ、阶段稿或信息图 §3 非对象出口表，落不下的记「悬空」，能挂但定义或取值要补的记「弱」。手册为内部资料，本报告只写抽象项名并注出处（如「产品手册·幕墙流程（公建）」），不抄正文。不涉及生产库。

**② 覆盖矩阵。** 以生产只读统计 `docs/legacy/runtime-usage/prod-usage.tsv`（2026-10-14，370 张表）排除框架与系统表后的 225 张老系统业务表、A8 125 个在用流程模板、103 张非空档案、10 个空表单定义，共 463 项，逐项判「覆盖 / 不迁 / 未覆盖」。结果：覆盖 294、不迁 140、未覆盖 29。量级用已有的近 365 天、累计、在途实例数；未为本项新增取证（所用统计的取证已按 ADR-0037 登记）。

**③ 端到端追踪。** 按「已完成或已关闭、合约已回、有商机、有开票、有回款、有已通过工时、立项于 2023–2024」各抽一个设计顾问（幕墙）、品控、照明项目（确定性哈希，代号 P1–P3），从线索走到回款，只取计数、状态值与相对天数，不取明细与个人信息。取证已在 `phase1a/infra/LEGACY_READ_REGISTER.md` 登记一行（ADR-0037）。样本每类 1 个，只用于找结构性遗漏，不作比例结论。

**④ 盲审与比对。** 另一子代理不看信息图，仅凭手册、干系人目录、GF-2015-0209、CAS 14、税务与社保实务独立列出 AEC 专业顾问公司的对象清单（一级 21、次级 46、非对象 15 类），再与信息图逐项比对，分「盲审有草案无」「草案有盲审无」「层级或定义不同」三类。不涉及生产库。

交叉规则：一项被两项以上独立检出，或一项检出且生产量级在百单/年以上，记为「强」；两项检出无生产量或一项检出有生产量记「中」；一项检出且无生产量记「弱」。
