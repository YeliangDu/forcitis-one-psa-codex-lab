## 接缝问题

1. **报价发出前实际用印：依赖结构已同步**。33e28272 的 AGG-113、REF-04 / B-32 与 ARCH_VS14 一致：REF-04（报价发出编排，暂名，无聚合流程模块，B-32 仅为图节点）经 api 读取 B-31 的实际用印登记，核对同一报价版本、用印法人、拟发文件及盖章凭据。已用印和关闭后保留的实际登记可核验，仅已批准/来源审批通过/申请登记不够。读不到、未用印、对应不符、凭据缺失、超时或核验失败均拒绝发出并告警；核验和审计留痕成功后才调用 B-03 发出命令。B-03 不依赖 B-31，不订阅用印事件或持本地用印投影；B-31 → B-24 资产卡片读取边保留，不改收入组入口。
2. **权威快照与批准边界**。以 33e28272 取代本片旧快照的冲突表述，聚合稿已删除 B-03 事件投影方案，api 与事件边仍全部参与查环；本卡在相同快照复跑改前→改后。事件名按 AGG-113 同步为「用印已办理」，只用于分析，REF-04 经 api 核验、不订阅事件；「已用印」只表示状态。ADR-0057 是提议稿待用户批，模块正式名称、标识与命名空间待 one-glossary；查环无环不代表 ADR 已批、发出入口或运行时已实现。ARCH-B31-materials 8 仍缺，不能因此撤销硬门槛。
3. **人员与调度**。B-31 → B-13 api 读取法人/员工/入职日期/有效人员事实，事件订阅 Separated 仅用于离职已生效后的资产归还。B-31 → platform.scheduling api 仅用于离职生效后 7 个日历日提醒和入职周年业务日触发；不再用于 IT 受理提醒或系统代关。归还完成取消；聚合 ID + 到期时点幂等；事件晚到/重试不重置期限。手工归还不套离职期限，不订阅离职登记已撤销，不把资产归还列为 VS-13.6 出口条件。平台调度任务及周年触发器尚未实现。
4. **维修无法修复及盘点**。维修 AGG-121 只记结果，报废及卡片、折旧、账务在 B-24。维修待处置/盘点需要读使用记录的承载仍待架构与财务组确定，不新增 B-24 → B-31 业务边或反向通知事件。B-31 → B-24 仅按卡片 ID 读取。
5. **审批回调**。仅 PRC-139 与 PRC-142 保留 platform.approval 结果回调，B-31 依赖平台，不能让平台 api 反向依赖 B-31。重提创建新轮，旧实例回调不得写新轮。领用和活动无审批任务、AR 绑定、批准/驳回/审批期撤回现行命令。
