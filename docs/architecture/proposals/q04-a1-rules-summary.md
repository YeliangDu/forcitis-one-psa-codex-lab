**题面**：设计服务对外财务报表按「时点」还是「时段」确认收入？检查服务、咨询、设计是否不同？「每期估进度」只用于管理产值，还是已进财务报表？（事实题，用户本人答；W-1 并入。）先答 W-7（适用哪套准则）。

| 选项 | 代价 |
|---|---|
| A 维持 A1（设计成果按时点，进度估计只管理产值） | A7、FD-11、FD-34 与合同履约成本不动；须审计师书面确认 |
| B 全部按时段 | A1、GL-026、A7、FD-34 重议；履约成本基本不再挂账；进度估计入账、可冲销重估；合同资产逐期变动；关账多一步估计与审批 |
| C 分类别（检查、按月咨询按时段；设计成果按时点） | 履约义务带「履行方式」属性；各类各自判断、各自审计师确认 |
| D 暂不定，系统先建能按期存进度估计的结构 | 不影响上线，避免返工 |

**one-rules 推荐**：先答事实题；只是管理产值选 A；已进报表则在 B、C 中按 W-7 与审计师意见选，C 可能是最终答案；无论选哪项，系统先能存每期进度估计。小企业会计准则下跨年劳务通常按完工进度，A1 多半要改（原文未取到，待财务核对）。

**连带**：Q-04「只存过账事实」在时段下不够，须加计量记录；合同资产、A7、第 13 期（估计变更未来适用，差错更正才进第 13 期）随之变；FD-40 基本不变。

**条文核对**：CAS 14 第十一、十二、十三、四十一条已按财政部官方 PDF 逐字核对（kjs.mof.gov.cn 201707 路径；是否确为财会〔2017〕22 号附件未核实）。第十一条（三）须同时满足「不可替代用途」与「客户或其他方原因终止合同时有权收取补偿已发生成本加合理利润的款项，且该权利具有法律约束力」；「解约按工作量付款要协商」只是线索，须看各类合同条款（法务 P-015）、（二）成果权属、（一）检查与按月咨询。进规格两点：第十二条兜底（进度不能合理确定且成本预计可补偿时按已发生成本确认）；类似履约义务须用同一方法。第十三条「客户已接受」只是六项迹象之一。未核实：审计准则 1321 原文、CAS 28 条号（二手）、小企业会计准则原文。
