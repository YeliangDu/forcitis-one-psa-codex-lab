## 判据

- 一级 = 不依附其他对象而存在；次级 = 依附其他对象（BIZBOK v11 §2.5，第 194–195、198 页）。
- 同物异型不拆对象，用类型区分（第 195 页）；单据、属性、估值、派生度量、设计构件不是对象（第 197–199 页）。
- 例外：外部权威登记的法律事实算对象（用户 i221201）；外部引用对象只记录、无自有规则，予以豁免。
