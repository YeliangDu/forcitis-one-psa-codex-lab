## 三、价值流阶段与能力对照

仓库价值流（`ssot/value-streams/value-streams.yaml`，提议态）：VS-07 完成人员任用（提出用人需求 C1、C2；完成录用 C2；入职上岗 C3、C4、C6、C11、C14、C15）；VS-13 获得报酬（月度考勤确认 C9–C12；绩效与奖金 C8、C17；薪资核算 C14、C16；申报缴纳 C15、C16；发放 C14；离职结算 C11、C14、C15、C18、C19）；VS-14 内部服务（离职资产归还 C18）。

仓库价值流缺的、草稿有的：调动（C5、C6、C7、C14）、请假安排（C11、C12）、能力与资质发展（C7）、结束用工（C6、C11、C14、C15、C18、C19）、设立岗位（C1）、绩效（C8）。C13、C20、C21 两边都没有阶段，作为在职中的事件挂在 VS-07 之后、VS-13 之内。补价值流（`value-streams.yaml`）是后续事项，不在本卡。

## 五、草稿与已采纳决定冲突处（卡不得照抄）

1. 一人至多一份生效合同、无例外：ADR-0079 第 3 条允许非全日制多单位。
2. 结算后差错用新的差额批次：ADR-0079 第 3 条用后续月度调整项。
3. 离职按合同→关系→人员三步：ADR-0068 单一离职命令。
4. 六上下文，法人与组织单元作外部事实：ADR-0051、ADR-0079 第 2 条。
5. 日历发布事件驱动额度：工作日历经 api 读，不订阅。
6. 逐人应付事件发给财务：ADR-0051 第 7 条第 2.7 项（法人×月一笔总额）。
7. 读模型由事件喂存储：ADR-0058（从状态转换投影）。
8. 人员状态「候选→试用→在职→离职」把在职当作转正后：ADR-0068 试用属在职。
9. 规章制度与违纪当外部政策、不建模：按 Q11 答复。
