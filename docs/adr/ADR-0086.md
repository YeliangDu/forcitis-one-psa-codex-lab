## 背景

ADR-0079 把一个人的在职判断、版本和用人单位按员工一条线建模（决定 3 第 1 条、不变量 1 与 4）。用户 2026-11-04 在 issue #1295 答复：一个人可同时受雇于两个法人，目前就存在；社保、个税扣缴与请假权益按雇佣关系各算。需要决定雇佣关系作为独立聚合如何落在 workforce，用人单位如何属于关系。触发出处：卡 #1308、评审笔记 hr-boundary-stability-review.md 7.3 与 8a。
