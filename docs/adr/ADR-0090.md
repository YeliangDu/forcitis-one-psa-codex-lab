# ADR-0090：多种类命令按种类强类型，中央登记表改为模块内声明

## 背景

要决定两件事：一是一个聚合与一个请求承载多种类并带可选字段的命令（人事命令 14 种、组织结构命令 8 种、会签种类 23 种）是否改为每种类一个强类型；二是权限、系统角色、错误码、审计主体种类等每个切片都要追加的中央登记表是否改为模块内声明并由启动或守护收集。现在决定，是因为这两类模式让编译期错误变成运行期或评审期错误，并成为合并冲突与入队失败的集中点，且每个新切片都在加重它。触发出处：用户 2026-11-06 对 lead 代码评审的「开」，工单 #1585。
