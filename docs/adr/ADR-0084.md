## 背景

ADR-0079 把绩效结果与招聘放在 organization.workforce 内分区，并称日后拆分只搬包与表；#1295 的独立复核（无 ADR 理由的评审员）与代码取证显示拆分要改持久化的事件类名、权限码、共享状态转换表与跨表外键，不是搬包。绩效与招聘尚无任何代码，现在定位不花代价。触发出处：用户 2026-11-04 要求复核人事上下文边界稳定性，卡 #1295（复核笔记 docs/architecture/proposals/hr-boundary-stability-review.md）。本稿为提议，正文由 #1295 的 PR 补全。
