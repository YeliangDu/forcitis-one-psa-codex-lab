## A 奖金归期（B03～B12）
- 源码结论：年度奖金（st 9）来自 OA 视图 annual_bonus_detail，`business_date` 恒为当年 12-31，视图无「所属月份」列；挂项目行按「人 × 全年批准工时」拆到项目×条款，基数按年聚合、不分月。计提（st 8）来自 monthly_bonus_accrual，按 business_date 定期间，但应走 OH 池（fee_type 1/2），不挂项目，与「pl 无 st 8」一致。
- psa_pl_ledger.business_date 承接成本行；period_id 是**转出期间**（不是发生期间）。cost/pl 两表均无所属月份/年度列。
- 预期结论（待查询证实）：挂项目奖金按月归期不可能，信息只有「年」；错配有两处：①发生日恒为 12-31，月份信息在入账时已丢；②进损益期间=结转期间，可能晚于 business_date 所在年（B05、B08 的 year_gap 与滞后矩阵给出）。B10 看 OH 池里的 st 8 是否逐月。

## C 年末未结转与跨年（B20～B29）
- 结转流程：成本台账（无 WIP 状态）→ psa_wip_entry（wip_status 0 在制/1 转出/2 终止/3 豁免/9 红冲，wip_stage 1 合同前/2 未完工/3 已完工/4 减值）与 psa_wip_movement（type 0 入、2 转出、3 转出红冲、4 终止、6 豁免）→ psa_pl_ledger。转出只发生在 stage 3（合同已回且 POC=100）、终止项目或手工名单；故未结转含合同前投入与未完工。
- 余额：B21 按 WIP 快照同口径重放 movement（增 0、3；减 2、4、6，取 ABS），并给各类型原值；B24 用 wip_entry 现状与转出/终止时间独立反推；B22、B23 给累计发生、累计结转（逐期间年，本地相加）；B25 用期间快照（全成本类）作上界。2,060 万以 B21 的 lvl=3 行（st 0，及 0+12）对照，B24 的 a+b+c 类交叉验证。
- 项目日期：立项=psa_pm_project.initiation_date；**无完工日期列**。完工代理：状态（已完成/已关闭）且最后确认收入日<2026-01-01（B26、B27），或条款 POC 快照（B28）。B27 的三分类互斥，先按立项年再按完工；要换分法用 B26 网格。
