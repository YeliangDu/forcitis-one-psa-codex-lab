> 冻结（2026-11-04，#1263）：基线口径草稿，不再更新。

依据：用户 2026-10-22（KPI-Q03、KPI-Q02）；METRIC_BASELINE_DRAFT.md M-08、M-24～M-29；词表 net_service_revenue / pass_through_cost / contribution_margin（FD-41）。老系统证据均为源码与迁移脚本，未对生产核对（Q01 先核对）。

## 一、新旧口径

| 项 | 新口径（词表） | 老系统最近的对应物（表.列） | 查询 |
|---|---|---|---|
| 分子 CM | 净服务收入 − 直接人工 − 直接项目费用；两边相同 | 收入 − 项目成本，无现成「CM」 | Q10 − Q20（或 Q22）中除转付外的各类 |
| 老分母 | 收入（不含税）M-08 | `psa_pm_cuvalue.no_tax_amount`，`type IN (0,1)`，期间列 `complete_date` | Q10 |
| 新分母 NR | 收入 − 转付成本 | Q10 − (分包 + 外包 + 可转收代垫) | Q10、Q20 SUB委外、Q30、Q41～Q43 |
| M-24 直接人工 | 有效工时 × 标准费率 | `psa_pl_ledger` / `psa_cost_ledger` 的 `source_type` 0 工时、12 尾差；金额为日薪×人天（`psa_daily_rate`），不是标准费率 | Q20、Q22 的 DL工时 |
| M-25 直接费用 | ODC | `source_type` 1 日常、2 差旅、3 付款申请、4 特殊付款、7 招待 | ODC费用 |
| M-26 分包/外包 | 转付成本 | `source_type` 5 委外（`psa_wip_outsourcing.notax_amount` 是其源单）；3/4 里的分包付款无法区分 | SUB委外、Q30、Q40 |
| 代垫（可转收） | 转付成本 | 未找到可转收标识（见三） | Q41～Q43 |
| 居间费 | 非转付成本，在 CM 中扣减 | `source_type` 6、`psa_wip_commission` | INFO居间、Q31 |
| 区域/BU | 层级变体 | `psa_pm_project.dept_id` → `system_dept.name/parent_id` | Q02 定层级 |
| 期间 | 权责 | 收入 `complete_date`；成本 `period_id` → `mdm_accounting_period.period_year`，或 `business_date` | Q03 |

关系式：老 CMR = CM ÷ Q10；新 CMR = CM ÷ (Q10 − 转付成本)。转付成本只含 SUB委外（+ 能识别的分包/外包付款 + 能识别的可转收代垫），其余类别不进分母扣减，只留在 CM。

## 二、已知口径差异

1. 老系统「项目毛利」（`ProfitReportMapper`）= 产值 − 进损益主营成本 − 商机销售费用 − 分摊四费，不是词表 CM；本草稿只取直接成本，不取分摊与商机费用。
2. 成本有两个时点：进损益（Q20，与收入配比）与已发生（Q22，含仍在 WIP 的）。词表 CM 取哪个未定；两者之差即在途 WIP。
3. 窗口：老读侧是「截止期末累计」，这里按「期间所属年」与「确认日」切窗。收入按确认日，成本按期间年，两侧在年末附近可能错位一个期间。
4. 老读侧收入按 `company_code` 等值过滤，本草稿不过滤（该列存量可能为 NULL）；Q11 报告 NULL 行数。
5. 红冲：收入 `type=1` 与损益 `pl_type=9` 本身为负额，直接相加；成本台账红冲行的有效性由 Q23 决定。
6. 税：用 `no_tax_amount`（单据实际税率），不用 1.06（METRIC_BASELINE M-08）；NULL 行见 Q11，可能低估老分母。
7. 币种：未见币种列，按单币种。

## 三、找不到 / 无法识别

- 可向客户转收的代垫费用：老系统源码与设计文档未见标识列或类别；`代垫/垫付` 只在日常报销的「员工垫付」语义里出现（员工垫付后报销，与向客户转收无关）。先看 Q41～Q43；全无命中则代垫无法分出，NR 只能按「收入 − 分包/外包」算，并在口径变更记录里写明缺这一项。
- 分包与外包的区分：老系统只有「委外」一个概念，不分分包、外包；两者合并算转付成本，与词表「分包成本、外包成本」并列，不能分别出数。
- 付款申请（3）、特殊付款（4）里是否有分包付款：只能靠 Q40 的费用类别名猜。

## 四、未决点（须口径负责人或财务定）

- U1：区域/BU 取交付部门还是其上级（Q02 后定）；项目换过部门时按当前部门还是发生时部门。
- U2：成本取进损益（Q20）还是已发生（Q22）；奖金计提与年度奖金（source_type 8/9）是否计入直接人工。
- U3：付款申请/特殊付款里的分包付款是否并入转付成本，按什么类别名判。
- U4：直接人工金额是日薪×人天，新规格是有效工时 × 标准费率，两者对不上时前后值只能说明分母变化，不能当 CM 新值。
- U5：2026 年「至今」截止日以执行当天为准，要在结果里写明；2026 期间若尚未关账，数值会变。
