# The POST endpoints whose answer may be stored for 24 hours under an Idempotency-Key (ADR-0043 section 4, DATA-REPAIR-timesheet-audit TB-02).
# Only these accept the header and have it in the OpenAPI contract; every other endpoint runs the request without storing an answer.
# An endpoint belongs here only when its answer carries no personal direct identifier and no SENSITIVE or RESTRICTED column, and has a bounded size
# (the stored text is at most 32768 characters). IdempotentEndpointGuardTest keeps this file equal to the endpoints the code lists, checks every
# type of every answer against data-classification.txt and the direct-identifier names, and needs each answer type named in the comment.
# Format: METHOD path-template  # answer type(s); what was checked. Adding a line needs design review.
