# Handlers that may be called without a login session (@PublicEndpoint). Snapshot of the reviewed set (SECURITY_INVARIANTS I-3,
# REIMAGINED_ARCHITECTURE §3.8): ApplicationIntegrationTest fails when the handlers marked @PublicEndpoint differ from this file,
# in either direction, or when a reason differs. Adding a line needs CODEOWNERS review; no line may create a session without
# proof of identity verified by this system (WeCom OAuth, Seeyon server-side ticket check, signed ticket, emergency admin).
# Format: METHOD path  # reason (exactly the reason of the annotation)
