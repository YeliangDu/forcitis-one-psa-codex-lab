# FORCITIS one

老系统的接班系统（one.forcitis.com）。代码将按 `docs/modernization/MODERNIZATION_BRIEF.template.md`（生成的 brief 见 generated-docs 分支）的阶段逐步加入。

- 现代化状态：`docs/modernization/STATUS.md`（不入仓：本地运行 `python3 docs/modernization/build_all.py` 生成，或看 [generated-docs 分支](https://github.com/FORCITIS/forcitis-one-psa/tree/generated-docs)，那里还有 INTENT、SESSION_LOG、ADR 与 brief 的快照）
- 会话管理：`docs/modernization/SESSION_PLAYBOOK.md`
- 架构决策：`docs/modernization/adr/`
- CI 自托管 runner 的维护：`docs/modernization/CI_RUNNERS.md`
